## Code Battle

`tulaan-8.html`-ийг тарааж `my-first-web`-д хуулуул. "Раунд 1 — эхэл!" гэвэл бүгд **зөвхөн тэр картыг** бодно. ✅ гарсан бол гараа өргөнө, багш дэлгэцийг нь хараад баталгаажуулна. **3 · 2 · 1** оноо.

| # | Бодлого | Хариу |
| - | ------- | ----- |
| 1 | Сар → өдөр | `return sar * 30;` |
| 2 | Нэр + нас | `return ner + " " + nas + " настай";` — хоосон зайг мартдаг |
| 3 | Периметр | `return (urt + urgun) * 2;` — хаалтгүй бол буруу |
| 4 | Цалин | `return huls * tsag * 5;` |

## Хариу — js-8.html

```js
function irehNas(nas) {
  let jil = 2030 - 2026;
  let shineNas = nas + jil;
  return shineNas;
}
function mend(ner) { return "Сайн уу, " + ner + "!"; }
function sekund(minut) { return minut * 60; }
function talbai(urt, urgun) { return urt * urgun; }
function hyamdral(une) { return une - une * 20 / 100; }   // эсвэл une * 0.8
function dundaj(a, b, c) { return (a + b + c) / 3; }
function fahrenheit(c) { return c * 9 / 5 + 32; }
function pizza(zusem, hun) {
  let neg = Math.floor(zusem / hun);
  let uldegdel = zusem % hun;
  return "Хүн бүр " + neg + ", үлдэгдэл " + uldegdel;
}
```

## Тэмдэглэл

- `helper.js` нь `input type="number"`-ийг тоо болгож өгдөг. Тиймээс `"5" + 4 = "54"` асуудал гарахгүй.
- Шалгагч нь текстийн эхлэл, төгсгөлийн хоосон зайг тоохгүй. Харин дунд талын зай чухал.
