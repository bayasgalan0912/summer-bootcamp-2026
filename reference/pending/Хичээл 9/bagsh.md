## Debug Battle — tulaan-9.html

Раунд бүрт нэг карт. Засаад ✅ + алдааг нэг өгүүлбэрээр тайлбарлана.

| # | Алдаа | Засвар |
| - | ----- | ------ |
| 1 | `nas > 13` | `nas < 13` — тэмдэг эргэсэн |
| 2 | `n / 2 === 0` | `n % 2 === 0` — хуваах биш, үлдэгдэл |
| 3 | `>= 70`-ийг `>= 90`-ээс өмнө | Дарааллыг соль — 95 ч эхний салаанд орчихно |
| 4 | `kod === 7 \|\| tulhuur === 1` | `&&` — хоёулаа хэрэгтэй |
| 5 | Сүүлийн мөр `return "Хүйтэн"` | `return "Сайхан"` |

## Түгээмэл алдаа

| Алдаа | Засвар |
| ----- | ------ |
| `if (onoo = 80)` | `===` эсвэл `>=` |
| `else (onoo < 80)` | `else`-д нөхцөл бичдэггүй. Хэрэгтэй бол `else if` |
| ⚠️ Кодонд алдаа: Unexpected token `else` | `}` дутуу, эсвэл `}` ба `else`-ийн хооронд илүү мөр |
| `unelgee(95)` → "D" | Жижгээс нь эхэлж шалгасан — ихээс эхэл |
| `"bat123"` ба `"Bat123"` | Том, жижиг үсэг өөр — зөв |
| `kinoTeatr`: (10, 100) → "Мөнгө хүрэхгүй" | Насыг **эхэлж** шалга |

## Хариу — js-9.html

```js
function shagnal(onoo) { if (onoo >= 80) { return "Алтан"; } else { return "Мөнгөн"; } }
function kino(nas) { if (nas >= 13) { return "Үзэж болно"; } else { return "Болохгүй"; } }
function tegsh(n) { if (n % 2 === 0) { return "Тэгш"; } else { return "Сондгой"; } }
function ih(a, b) { if (a > b) { return a; } else { return b; } }
function nuuts(ug) { if (ug === "bat123") { return "Нэвтэрлээ"; } else { return "Буруу нууц үг"; } }
function unelgee(onoo) {
  if (onoo >= 90) { return "A"; }
  else if (onoo >= 80) { return "B"; }
  else if (onoo >= 70) { return "C"; }
  else if (onoo >= 60) { return "D"; }
  else { return "F"; }
}
function hpTuluv(hp) {
  if (hp <= 0) { return "KO"; }
  else if (hp < 30) { return "Аюултай"; }
  else { return "Тулалдана"; }
}
function kinoTeatr(nas, mungu) {
  if (nas < 13) { return "Нас хүрэхгүй"; }
  else if (mungu < 5000) { return "Мөнгө хүрэхгүй"; }
  else { return "Орж болно"; }
}
function undurJil(on) {
  if ((on % 4 === 0 && on % 100 !== 0) || on % 400 === 0) { return "Өндөр жил"; }
  else { return "Энгийн жил"; }
}
```

`kinoTeatr`-ийг `&&`-ээр ч бичиж болно: `if (nas >= 13 && mungu >= 5000) …`. Гэхдээ дараа нь аль нь дутсаныг дахин шалгах хэрэгтэй.
