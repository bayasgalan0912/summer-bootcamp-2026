<details>
<summary><b>1. Дүр сонгох цэс</b></summary>

<br>

AI Studio-д:

```
Тоглоом эхлэхээс өмнө дүр сонгох дэлгэц нэм.
P1 нь A/D, P2 нь ←/→ товчоор дүрээ сонгоно. Хоёулаа Enter дарвал тулаан эхэлнэ.
Дүр бүрийн portrait зургийг sprites.json-оос ав.
```

**Код унш:** AI-н бичсэн кодоос `if`-ийг ол. Аль товч дарахад юу болохыг шийдэж байна вэ?

</details>

---

<details>
<summary><b>2. Best of 3</b></summary>

<br>

```
Тулааныг 3 раунд болго. 2 раунд түрүүлсэн нь ялна.
Раунд бүрийн өмнө "ROUND 1", "FIGHT!" гэж 1 секунд харуул.
Дэлгэцийн дээд талд ялсан раундыг цэгээр харуул.
```

**Код унш:** раундын тоог хадгалж буй **хувьсагч**-ийг ол.

</details>

<details>
<summary><b>3. Leaderboard</b></summary>

<br>

Хичээл 12-ын Firestore-ыг ашиглана.

```
Тулаан дуусахад ялагчийн нэрийг асууж Firestore-ын "fighters" collection-д хадгал.
Нэр бүрийн ялалтыг тоол. Нүүр дэлгэцэд хамгийн их ялалттай 5 тоглогчийг харуул.
```

**Код унш:** 5-ыг хэрхэн эрэмбэлж байна? Хичээл 9-ийн `top3`-тай харьцуул.
