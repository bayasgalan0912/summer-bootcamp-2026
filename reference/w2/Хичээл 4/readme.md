<details>
<summary><b>2. Код хэрхэн ажилладаг</b></summary>

<br>

Компьютер кодыг **дээрээс доош, нэг мөрөөр** уншина.

```js
let coins = 5;
coins = coins + 3;
console.log(coins);
```

| Мөр | Юу болов               | `coins` |
| --- | ---------------------- | ------- |
| 1   | Хайрцаг үүсгэж 5 хийв  | 5       |
| 2   | 5 + 3-ыг буцааж хийв   | 8       |
| 3   | Console-д хэвлэв       | 8       |

**Хувьсагч** = нэртэй хайрцаг. Дотор нь тоо, текст хадгална.

Өөрөө алхам алхмаар хар: **[pythontutor.com](https://pythontutor.com/javascript.html)** → кодоо paste → **Visualize**.

<details>
<summary>Өнөөдрийн үгс</summary>

<br>

| Код             | Утга                           |
| --------------- | ------------------------------ |
| `let x = 5`     | `x` хайрцаг үүсгэж 5 хийнэ     |
| `x = x + 1`     | Хуучин утга дээр 1 нэмнэ       |
| `"Сайн уу"`     | Текст (хашилтанд)              |
| `+ - * /`       | Нэмэх, хасах, үржих, хуваах    |
| `%`             | Хуваахад үлдэх үлдэгдэл        |
| `console.log()` | Console-д хэвлэнэ              |

</details>
