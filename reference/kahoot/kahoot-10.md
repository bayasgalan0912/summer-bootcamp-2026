<summary><b>1. Дэлгүүрийн сагс</b> · 60 сек</summary>

<br>

```js
let niit = "";   // сагсны нийт үнэ
for (let i = 1; i <= 3; i++) {
  niit = niit + 1000;
}
alert(niit);
```

**1000₮-ийн 3 талх сагсалсан. Кассын дэлгэцэнд юу гарах вэ?**

| #   | Хариулт       |     |
| --- | ------------- | --- |
| 1   | 3000          |     |
| 2   | 100010001000  | ✅  |
| 3   | 1000          |     |
| 4   | Алдаа гарна   |     |

<details><summary>Тайлбар</summary>

`""` — текст. Текст + тоо → наалдана. Тоо нэмэх бол `let niit = 0`.

<summary><b>2. Шатаар өгсөх</b> · 60 сек</summary>

<br>

```js
let alham = "";
for (let i = 1; i < 5; i++) {
  alham = alham + i + " ";
}
alert(alham);
```

**Дүү 5 шаттай шатаар өгсөхдөө тоолж байна. Цонхонд юу гарах вэ?**

| #   | Хариулт      |     |
| --- | ------------ | --- |
| 1   | 1 2 3 4 5    |     |
| 2   | 0 1 2 3 4    |     |
| 3   | 1 2 3 4      | ✅  |
| 4   | 2 3 4 5      |     |

<details><summary>Тайлбар</summary>

`5 < 5` → худал → 5 дээр зогсоно. 5-ыг оруулах бол `i <= 5`.

</details>

<summary><b>3. Алхам тоолуур</b> · 60 сек</summary>

<br>

```js
let alham = 0;
for (let odor = 1; odor <= 3; odor++) {
  alham = 0;
  alham = alham + 5000;
}
alert(alham + " алхам");
```

**Ухаалаг цаг: 3 өдөр, өдөр бүр 5000 алхсан. Нийт хэд гэж гарах вэ?**

| #   | Хариулт       |     |
| --- | ------------- | --- |
| 1   | 5000 алхам    | ✅  |
| 2   | 15000 алхам   |     |
| 3   | 0 алхам       |     |
| 4   | 10000 алхам   |     |

<details><summary>Тайлбар</summary>

`alham = 0` давталтын **дотор** → өдөр бүр тэглэгдэнэ. Зөвхөн сүүлийн өдрийн 5000 үлдэнэ.

| 1   | 6            |     |
| 2   | 5            |     |
| 3   | Алдаа гарна  |     |
| 4   | 51           | ✅  |

<details><summary>Тайлбар</summary>

`prompt` бичсэнийг **текст**ээр авна: `"5" + 1` → `"51"`. Тоо асуувал `Number(prompt(...))`.

<summary><b>6. Микровейвийн таймер</b> · 60 сек</summary>

<br>

```js
let t = "";
for (let sec = 30; sec >= 1; sec++) {
  t = t + sec + " ";
}
alert(t + "Дзинь!");
```

**Хоолоо 30 секунд халаалаа. Хуудсаа нээхэд юу болох вэ?**

| #   | Хариулт                   |     |
| --- | ------------------------- | --- |
| 1   | 30 29 28 … 1 Дзинь!       |     |
| 2   | Дзинь!                    |     |
| 3   | Хуудас гацна              | ✅  |
| 4   | 30 Дзинь!                 |     |

<details><summary>Тайлбар</summary>

`sec++` → 30, 31, 32 … үргэлж 1-ээс их → хэзээ ч зогсохгүй. Буурах бол `sec--`.

</details>

<summary><b>8. Автобусны буудал</b> · 60 сек</summary>

let avtobus = 0;

**Автобус 15 минут тутамд ирнэ. 1 цагт хэдэн автобус ирэх вэ?**

| --- | ------- | --- |
| 1   | 3       |     |
| 2   | 4       | ✅  |
| 3   | 5       |     |
| 4   | 15      |     |

<details><summary>Тайлбар</summary>

15, 30, 45, 60-р минутад л `min % 15 === 0` → 4. 60-р минут ч тоологдоно (`<=`).

<summary><b>9. Лифт</b> · 60 сек</summary>

<br>

```js
// Лифт зогсох давхар: 2 4 6 8 10

A:  for (let i = 2; i <= 10; i++)
B:  for (let i = 2; i < 10; i = i + 2)
C:  for (let i = 0; i <= 10; i = i + 2)
D:  for (let i = 2; i <= 10; i = i + 2)
```

**Лифт зөвхөн тэгш давхарт (2–10) зогсоно. Аль мөр зөв вэ?**

| #   | Хариулт |     |
| --- | ------- | --- |
| 1   | A       |     |
| 2   | B       |     |
| 3   | C       |     |
| 4   | D       | ✅  |

<details><summary>Тайлбар</summary>

A — бүх давхар (2 3 4 … 10). B — 10-ыг алгасна (`10 < 10` худал). C — 0-р давхраас эхэлнэ.

</details>

<summary><b>10. Хичээлийн хуваарь</b> · 60 сек</summary>

<br>

```js
let huvaari = "";
for (let i = 1; i <= 3; i++) {
  huvaari = huvaari + i + "-р цаг: Хичээл";
}
alert(huvaari);
// 1-р цаг: Хичээл2-р цаг: Хичээл3-р цаг: Хичээл
```

**Хуваарь нэг мөрөнд наалдчихлаа. Юу дутуу вэ?**

| #   | Хариулт                          |     |
| --- | -------------------------------- | --- |
| 1   | Мөр бүрийн төгсгөлд "\n"         | ✅  |
| 2   | alert-ийг давталт дотор бичих    |     |
| 3   | i++-ийн оронд i--                |     |
| 4   | Number(...)                      |     |

<details><summary>Тайлбар</summary>

`"\n"` — шинэ мөр. `+ "-р цаг: Хичээл\n"` гэвэл мөр бүр тусдаа. `alert`-ийг дотор бичвэл 3 цонх гарна.

</details>
</details>

<summary><b>12. Суниалтын сорил</b> · 60 сек</summary>

<br>

```js
let udaa = 10;   // эхний өдөр
let niit = 0;
for (let odor = 1; odor <= 3; odor++) {
  udaa = udaa + 5;
  niit = niit + udaa;
}
alert(niit);
```

**10, 15, 20 удаа суниана (нийт 45). Код юу гаргах вэ?**

| #   | Хариулт |     |
| --- | ------- | --- |
| 1   | 45      |     |
| 2   | 60      | ✅  |
| 3   | 50      |     |
| 4   | 75      |     |

<details><summary>Тайлбар</summary>

Эхлээд 5 нэмчихээд дараа нь нийтэд нэмж байна: 15 + 20 + 25 = 60. Мөрийн дараалал чухал — эхлээд `niit`-д нэм.

</details>
</details>
