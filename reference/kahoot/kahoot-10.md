<summary><b>2. Шатаар өгсөх</b> · 60 сек</summary>

<br>

```js
let alham = "";
for (let i = 1; i < 5; i++) {
  alham = alham + i + " ";
}
alert(alham);
```

**Дүү 5 шаттай шатаар өгсөхдөө тоолж байна. Цонхонд юу гарах вэ?**

| #   | Хариулт      |     |
| --- | ------------ | --- |
| 1   | 1 2 3 4 5    |     |
| 2   | 0 1 2 3 4    |     |
| 3   | 1 2 3 4      | ✅  |
| 4   | 2 3 4 5      |     |

<details><summary>Тайлбар</summary>

`5 < 5` → худал → 5 дээр зогсоно. 5-ыг оруулах бол `i <= 5`.

</details>
</details>

<summary><b>3. Гахайн хадгаламж</b> · 60 сек</summary>

<br>

```js
let niit = 0;
for (let i = 1; i <= 3; i++) {
  niit = 0;
  niit = niit + i * 1000;
}
alert(niit + "₮");
```

**1000₮, 2000₮, 3000₮ хийсэн. Хадгаламжид хэд байх вэ?**

| #   | Хариулт  |     |
| --- | -------- | --- |
| 1   | 3000₮    | ✅  |
| 2   | 6000₮    |     |
| 3   | 0₮       |     |
| 4   | 1000₮    |     |

<details><summary>Тайлбар</summary>

`niit = 0` давталтын **дотор** → тойрог бүрт хоосорно. Зөвхөн сүүлийн 3000 үлдэнэ.

</details>

<summary><b>4. Төрсөн өдрийн сандал</b> · 60 сек</summary>

<br>

```js
let naiz = prompt("Хэдэн найз ирэх вэ?");  // 5 гэж бичлээ
alert(naiz + 1);  // найзууд + би
```

**5 найз ирнэ. Хэдэн сандал хэрэгтэй гэж гарах вэ?**

| #   | Хариулт      |     |
| --- | ------------ | --- |
| 1   | 6            |     |
| 2   | 5            |     |
| 3   | Алдаа гарна  |     |
| 4   | 51           | ✅  |

<details><summary>Тайлбар</summary>

`prompt` бичсэнийг **текст**ээр авна: `"5" + 1` → `"51"`. Тоо асуувал `Number(prompt(...))`.

</details>

<summary><b>6. Шинэ жилийн тоолол</b> · 60 сек</summary>

<br>

```js
let t = "";
for (let i = 10; i >= 1; i++) {
  t = t + i + " ";
}
alert(t + "Шинэ жил мэнд!");
```

**Хуудсаа нээхэд юу болох вэ?**

| #   | Хариулт                          |     |
| --- | -------------------------------- | --- |
| 1   | 10 9 8 … 1 Шинэ жил мэнд!        |     |
| 2   | Шинэ жил мэнд!                   |     |
| 3   | Хуудас гацна                     | ✅  |
| 4   | 10 Шинэ жил мэнд!                |     |

<details><summary>Тайлбар</summary>

`i++` → 10, 11, 12 … үргэлж 1-ээс их → хэзээ ч зогсохгүй. Буурах бол `i--`.

</details>

<summary><b>9. Пуужин хөөргөх</b> · 60 сек</summary>

<br>

```js
// Гарах ёстой: 5 4 3 2 1

A:  for (let i = 5; i >= 1; i++)
B:  for (let i = 1; i <= 5; i--)
C:  for (let i = 5; i >= 1; i--)
D:  for (let i = 5; i > 1; i--)
```

**Пуужин хөөргөхөд 5 4 3 2 1 гэж тоолох аль мөр вэ?**

| #   | Хариулт |     |
| --- | ------- | --- |
| 1   | A       |     |
| 2   | B       |     |
| 3   | C       | ✅  |
| 4   | D       |     |

<details><summary>Тайлбар</summary>

A ба B хэзээ ч зогсохгүй (гацна). D нь `1 > 1` худал тул 1-ийг алгасна: 5 4 3 2.

</details>

<summary><b>10. Буузны үнэ</b> · 60 сек</summary>

<br>

```js
let t = "";
for (let i = 1; i <= 3; i++) {
  t = t + i + " бууз: " + i * 1500 + "₮";
}
alert(t);
// 1 бууз: 1500₮2 бууз: 3000₮3 бууз: 4500₮
```

**Үнийн хүснэгт нэг мөрөнд наалдчихлаа. Юу дутуу вэ?**

| #   | Хариулт                          |     |
| --- | -------------------------------- | --- |
| 1   | Мөр бүрийн төгсгөлд "\n"         | ✅  |
| 2   | alert-ийг давталт дотор бичих    |     |
| 3   | i++-ийн оронд i--                |     |
| 4   | Number(...)                      |     |

<details><summary>Тайлбар</summary>

`"\n"` — шинэ мөр. `+ "₮\n"` гэвэл мөр бүр тусдаа. `alert`-ийг дотор бичвэл 3 цонх гарна.

</details>
</details>

<summary><b>12. Шатрын будаа</b> · 60 сек</summary>

<br>

```js
let budaa = 1;
let niit = 0;
for (let i = 1; i <= 3; i++) {
  budaa = budaa * 2;
  niit = niit + budaa;
}
alert(niit + " будаа");
```

**3 нүдэнд 1, 2, 4 будаа (нийт 7) тавих ёстой. Код юу гаргах вэ?**

| #   | Хариулт    |     |
| --- | ---------- | --- |
| 1   | 7 будаа    |     |
| 2   | 15 будаа   |     |
| 3   | 8 будаа    |     |
| 4   | 14 будаа   | ✅  |

<details><summary>Тайлбар</summary>

Эхлээд 2 дахин нэмэгдүүлчихээд дараа нь нэмж байна: 2 + 4 + 8 = 14. Мөрийн дараалал чухал — эхлээд `niit`-д нэм.

</details>
</details>
