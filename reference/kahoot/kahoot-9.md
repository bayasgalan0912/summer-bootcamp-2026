<summary><b>1. Асуултын дүрс</b> · 60 сек</summary>

<br>

**Блок схемд "12 ба түүнээс дээш настай юу?" гэсэн асуултыг ямар дүрсээр зурах вэ?**

| #   | Хариулт                  |     |
| --- | ------------------------ | --- |
| 1   | Тэгш өнцөгт              |     |
| 2   | Налуу                    |     |
| 3   | Ромбо                    | ✅  |
| 4   | Зууван                   |     |

<details><summary>Тайлбар</summary>

Ромбо = асуулт, хариу нь Тийм / Үгүй. Тэгш өнцөгт — үйлдэл, налуу — гаралт, зууван — эхлэл / төгсгөл.

</details>

<summary><b>2. Их ба их буюу тэнцүү</b> · 60 сек</summary>

<br>

```js
let x = 8;
console.log(x >= 8);
console.log(x > 8);
```

**x = 8 үед хоёр мөрөнд юу гарах вэ?**

| #   | Хариулт      |     |
| --- | ------------ | --- |
| 1   | true, true   |     |
| 2   | true, false  | ✅  |
| 3   | false, true  |     |
| 4   | false, false |     |

<details><summary>Тайлбар</summary>

`8 >= 8` — тэнцүү байж болно → true. `8 > 8` — их биш → false.

</details>
</details>

<summary><b>4. Текст ба тоо</b> · 60 сек</summary>

<br>

```js
let too = "5";
console.log(too === 5);
```

**Хашилттай "5"-ийг 5 тоотой === -ээр жишвэл?**

| #   | Хариулт     |     |
| --- | ----------- | --- |
| 1   | true        |     |
| 2   | false       | ✅  |
| 3   | 5           |     |

<details><summary>Тайлбар</summary>

`"5"` — текст, `5` — тоо. Төрөл өөр тул `===` → false.

<summary><b>5. Нэг тэнцүү</b> · 60 сек</summary>

<br>

```js
let x = 4;
if (x = 10) {
  console.log("10 байна");
}
```

**x = 4 байхад if дотор нэг = бичвэл юу болох вэ?**

| #   | Хариулт        |     |
| --- | -------------- | --- |
| 1   | Юу ч гарахгүй  |     |
| 2   | Алдаа гарна    |     |
| 3   | 10 байна       | ✅  |
| 4   | 4              |     |

<details><summary>Тайлбар</summary>

`x = 10` нь асуухгүй, хайрцагт 10 **хийнэ** → нөхцөл үргэлж Тийм. Асуух бол `x === 10`.

</details>
</details>

<summary><b>6. else if-ийн дараалал</b> · 60 сек</summary>

<br>

```js
let temp = 35;
if (temp > 10) {
  console.log("Өмд цамц");
} else if (temp > 30) {
  console.log("Шорт");
} else {
  console.log("Гадуур хувцас");
}
```

**35 градуст юу гарах вэ?**

| #   | Хариулт          |     |
| --- | ---------------- | --- |
| 1   | Шорт             |     |
| 2   | Өмд цамц         | ✅  |
| 3   | Өмд цамц, Шорт   |     |
| 4   | Гадуур хувцас    |     |

<details><summary>Тайлбар</summary>

Дээрээс доош шалгаж, **эхний** Тийм дээр зогсоно. `35 > 10` → Тийм → "Шорт" хүртэл очихгүй.

</details>
</details>

<summary><b>7. else байхгүй</b> · 60 сек</summary>

<br>

```js
let x = 3;
if (x > 5) {
  console.log("Их");
}
console.log("Дууслаа");
```

**else бичээгүй. Console-д юу гарах вэ?**

| #   | Хариулт            |     |
| --- | ------------------ | --- |
| 1   | Дууслаа            | ✅  |
| 2   | Их, Дууслаа        |     |
| 3   | Юу ч гарахгүй      |     |
| 4   | Алдаа: else дутуу  |     |

<details><summary>Тайлбар</summary>

`else` заавал биш. `3 > 5` → Үгүй → `{ }`-г алгасна. `if`-ийн гадна байгаа мөр үргэлж ажиллана.

</details>
</details>

<summary><b>8. Кино театр — &&</b> · 60 сек</summary>

<br>

```js
let nas = 13;
let tasalbar = false;
if (nas >= 12 && tasalbar === true) {
  console.log("Орж болно");
} else {
  console.log("Орж болохгүй");
}
```

**13 настай, тасалбаргүй. Юу гарах вэ?**

| #   | Хариулт                   |     |
| --- | ------------------------- | --- |
| 1   | Орж болно                 |     |
| 2   | Орж болно, Орж болохгүй   |     |
| 3   | Орж болохгүй              | ✅  |
| 4   | Алдаа гарна               |     |

<details><summary>Тайлбар</summary>

`&&` — **хоёулаа** true байх ёстой. Нас OK, тасалбар false → бүхэлдээ false.

</details>
</details>

<summary><b>9. Ромбод юу бичих вэ?</b> · 60 сек</summary>

<br>

```flow
start Эхлэл
op x = 12
dec! ?
| io тэгш | io сондгой
end Төгсгөл
```

**Тэгш тоонд "тэгш" гаргахын тулд шар ромбод юу бичих вэ?**

| #   | Хариулт          |     |
| --- | ---------------- | --- |
| 1   | x / 2 === 0 ?    |     |
| 2   | x % 2 = 0 ?      |     |
| 3   | x % 2 === 2 ?    |     |
| 4   | x % 2 === 0 ?    | ✅  |

<details><summary>Тайлбар</summary>

`%` — үлдэгдэл. Тэгш тоог 2-т хуваахад үлдэгдэл 0. `x / 2` нь 6 гарна, `=` нь асуухгүй.

</details>

<summary><b>10. Амралтын өдөр — ||</b> · 60 сек</summary>

<br>

```js
let odor = "Ням";
if (odor === "бямба" || odor === "ням") {
  console.log("Амралт");
} else {
  console.log("Хичээл");
}
```

**odor = "Ням" (том Н) үед юу гарах вэ?**

| #   | Хариулт         |     |
| --- | --------------- | --- |
| 1   | Амралт          |     |
| 2   | Хичээл          | ✅  |
| 3   | Амралт, Хичээл  |     |
| 4   | Алдаа гарна     |     |

<details><summary>Тайлбар</summary>

`"Ням"` ≠ `"ням"` — том, жижиг үсэг өөр. Хоёр нөхцөл хоёулаа false → `||` false.

</details>
</details>

<summary><b>11. Яг хил дээр</b> · 60 сек</summary>

<br>

```js
let onoo = 80;
if (onoo > 80) {
  console.log("A");
} else if (onoo > 60) {
  console.log("B");
} else {
  console.log("C");
}
```

**Яг 80 оноо авбал ямар дүн гарах вэ?**

| #   | Хариулт |     |
| --- | ------- | --- |
| 1   | A       |     |
| 2   | B       | ✅  |
| 3   | C       |     |
| 4   | A, B    |     |

<details><summary>Тайлбар</summary>

`80 > 80` → false. `80 > 60` → true → B. 80-д A өгөх бол `>=`.

</details>
</details>

<summary><b>13. FizzBuzz — аль нь эхэнд?</b> · 60 сек</summary>

<br>

```js
let n = 15;
if (n % 3 === 0) {
  console.log("Fizz");
} else if (n % 5 === 0) {
  console.log("Buzz");
} else if (n % 3 === 0 && n % 5 === 0) {
  console.log("FizzBuzz");
}
```

**n = 15 үед энэ код юу гаргах вэ?**

| #   | Хариулт        |     |
| --- | -------------- | --- |
| 1   | FizzBuzz       |     |
| 2   | Fizz           | ✅  |
| 3   | Fizz, Buzz     |     |
| 4   | Buzz           |     |

<details><summary>Тайлбар</summary>

`15 % 3 === 0` → Тийм → зогсоно. FizzBuzz гаргах бол `&&`-тэй нөхцөлийг **эхэнд** тавь.

</details>
</details>

<summary><b>14. Нөхцөлийг сонго</b> · 60 сек</summary>

<br>

```js
let x = 7;
if (???) {
  console.log("сондгой");
} else {
  console.log("тэгш");
}
```

**Зөв ажиллахын тулд ??? -ийн оронд аль нь вэ?**

| #   | Хариулт        |     |
| --- | -------------- | --- |
| 1   | x % 2 === 0    |     |
| 2   | x % 2 !== 0    | ✅  |
| 3   | x % 2 = 1      |     |
| 4   | x / 2 !== 0    |     |

<details><summary>Тайлбар</summary>

Тийм зам нь "сондгой" → үлдэгдэл 0 **биш** гэж асууна: `!==`. `=== 0` бол замууд эсрэгээрээ.

</details>
</details>

<summary><b>15. Хөнгөлөлттэй тасалбар</b> · 60 сек</summary>

<br>

```js
let nas = ?;
if (nas < 6 || nas >= 60) {
  console.log("Хөнгөлөлттэй");
} else {
  console.log("Энгийн");
}
```

**Аль насанд "Хөнгөлөлттэй" гарах вэ?**

| #   | Хариулт   |     |
| --- | --------- | --- |
| 1   | nas = 6   |     |
| 2   | nas = 59  |     |
| 3   | nas = 60  | ✅  |
| 4   | nas = 30  |     |

<details><summary>Тайлбар</summary>

`60 >= 60` → true → `||`-д нэг нь true хангалттай. 6 нь `< 6` биш, 59 нь `>= 60` биш.

</details>
</details>
