<summary><b>1. CU-д гоймон</b> · 60 сек</summary>

<br>

```flow
start Эхлэл
op nas = 16
dec nas < 16 ?
| io Гоймон авч болохгүй | io Гоймон авч болно
end Төгсгөл
```

**Бат яг 16 настай. Энэ схемээр юу гарах вэ?**

| #   | Хариулт                                 |     |
| --- | --------------------------------------- | --- |
| 1   | Гоймон авч болохгүй                     |     |
| 2   | Гоймон авч болно                        | ✅  |
| 3   | Хоёулаа гарна                           |     |
| 4   | Юу ч гарахгүй                           |     |

<details><summary>Тайлбар</summary>

`16 < 16` → Үгүй (тэнцүү нь бага биш) → баруун зам. Хоёр замын зөвхөн **нэг** нь ажиллана.

</details>

| #   | Хариулт                      |     |

<summary><b>3. Утасны PIN</b> · 60 сек</summary>

<br>

```js
let pin = "1234";   // хүний дарсан PIN
if (pin === 1234) {
  console.log("Түгжээ нээгдлээ");
} else {
  console.log("PIN буруу");
```

**Сараа зөв PIN 1234-өө дарлаа. Утас нээгдэх үү?**

| #   | Хариулт                        |     |
| --- | ------------------------------ | --- |
| 1   | Нээгдэнэ — Түгжээ нээгдлээ     |     |
| 2   | Нээгдэхгүй — PIN буруу         | ✅  |
| 3   | Алдаа гарна                    |     |
| 4   | Хоёулаа гарна                  |     |

<details><summary>Тайлбар</summary>

`"1234"` — текст, `1234` — тоо. Төрөл өөр тул `===` → false.

```js
let onoo = 40;
```

<summary><b>5. Уралдааны шагнал</b> · 60 сек</summary>

<br>

```js
let bair = 1;   // уралдаанд эзэлсэн байр
if (bair <= 3) {
  console.log("Медаль");
} else if (bair === 1) {
  console.log("Алтан аяга");
} else {
  console.log("Баярлалаа");
}
```

**Тэргүүн байр эзэлсэн хүүхэд юу авах вэ?**

| #   | Хариулт               |     |
| --- | --------------------- | --- |
| 1   | Алтан аяга            |     |
| 2   | Медаль                | ✅  |
| 3   | Медаль, Алтан аяга    |     |
| 4   | Баярлалаа             |     |

<details><summary>Тайлбар</summary>

`1 <= 3` → Тийм → зогсоно. "Алтан аяга" хэзээ ч гарахгүй. Хатуу нөхцөл (`=== 1`) эхэнд байх ёстой.

</details>

```js
let tsag = 21;
```

| --- | ------------------------ | --- |

```js
let nas = 15;
```

<details><summary>Тайлбар</summary>

<br>

```flow
start Эхлэл
op dugaar = 2468

| io Явж болно | io Өнөөдөр явахгүй
end Төгсгөл
```

**Өнөөдөр зөвхөн тэгш дугаартай машин явна. Шар хэсэгт юу бичих вэ?**

| #   | Хариулт               |     |
| --- | --------------------- | --- |
| 1   | dugaar / 2 === 0 ?    |     |
| 2   | dugaar % 2 = 0 ?      |     |
| 3   | dugaar % 2 === 0 ?    | ✅  |
| 4   | dugaar % 2 === 1 ?    |     |

<details><summary>Тайлбар</summary>

Тэгш тоог 2-т хуваахад үлдэгдэл (`%`) 0. `dugaar / 2` нь 1234 болно, `=` асуухгүй, `=== 1` бол сондгой.

<summary><b>10. Аттракцион</b> · 60 сек</summary>

<br>

```js
let undur = 110;   // см
if (undur >= 120); {
  console.log("Сууж болно");
}
```

**110 см өндөр дүү аттракционд сууж чадах уу?**

| #   | Хариулт                    |     |
| --- | -------------------------- | --- |
| 1   | Юу ч гарахгүй              |     |
| 2   | Алдаа гарна                |     |
| 3   | Сууж болно                 | ✅  |
| 4   | 110                        |     |

<details><summary>Тайлбар</summary>

`)`-ын араас `;` → `if` тэнд дуусна. `{ }` нь `if`-тэй холбоогүй болж **үргэлж** ажиллана. Аюултай алдаа!

</details>
</details>

```js
let nuuts = "mongol2026";
```

<summary><b>12. Парк уу, кино уу?</b> · 60 сек</summary>

<br>

```js
let odor = "бямба";
let boroo = true;
if (odor === "бямба" && boroo === false || odor === "ням") {
  console.log("Парк руу!");
} else {
  console.log("Гэртээ кино");
}
```

**Бямба гараг, бороо орж байна. Юу хийх вэ?**

| #   | Хариулт              |     |
| --- | -------------------- | --- |
| 1   | Парк руу!            |     |
| 2   | Хоёулаа              |     |
| 3   | Алдаа гарна          |     |
| 4   | Гэртээ кино          | ✅  |

<details><summary>Тайлбар</summary>

Бямба OK, бороо `true` → `&&` false. Ням биш → `||`-ийн хоёр тал хоёулаа false.

</details>

```js
let nas = ?;
```

**Хэн автобусанд үнэгүй суух вэ?**

| 3   | 60 настай эмээ     | ✅  |
| 4   | 30 настай ах       |     |

<details><summary>Тайлбар</summary>
