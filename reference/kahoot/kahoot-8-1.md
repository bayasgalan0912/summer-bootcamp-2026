<summary><b>1. Буруу дүрс</b> · 60 сек</summary>

<br>

```flow
start Эхлэл
op хоног = 2, цаг = 10
op нийт = хоног × 24 + цаг
op нийт гаргах
end Төгсгөл
```

**Энэ блок схемд нэг дүрс буруу зурагдсан. Аль нь вэ?**

| #   | Хариулт                  |     |
| --- | ------------------------ | --- |
| 1   | хоног = 2, цаг = 10      |     |
| 2   | нийт = хоног × 24 + цаг  |     |
| 3   | нийт гаргах              | ✅  |
| 4   | Эхлэл                    |     |

<details><summary>Тайлбар</summary>

Гаргах (`console.log`) = Оролт / Гаралт → налуу дүрс. Тэгш өнцөгт бол Үйлдэл.

<summary><b>3. Схем → код</b> · 60 сек</summary>

<br>

```flow
start Эхлэл
op ner = "Бат"
io "Сайн уу, " + ner гаргах
end Төгсгөл
```

**Аль код энэ блок схемтэй яг таарах вэ?**

| #   | Хариулт                                           |     |
| --- | ------------------------------------------------- | --- |
| 1   | console.log("Сайн уу, " + ner); let ner = "Бат";  |     |
| 2   | let ner = "Бат"; console.log("Сайн уу, ner");     |     |
| 3   | let ner = "Бат"; console.log("Сайн уу, " + ner);  | ✅  |
| 4   | let ner = Бат; console.log("Сайн уу, " + ner);    |     |

<details><summary>Тайлбар</summary>

Схемийн дараалал = кодын дараалал (дээрээс доош). 1 — дараалал эсрэг, 2 — `ner` хашилтанд, 4 — `Бат` хашилтгүй.

</details>
</details>

<summary><b>10. Хайрцаг солих — алдаа</b> · 60 сек</summary>

<br>

```js
let a = "cola";
let b = "water";
a = b;
b = a;
console.log(a, b);
```

**a, b-г солих гэсэн код. Console-д юу гарах вэ?**

| #   | Хариулт     |     |
| --- | ----------- | --- |
| 1   | water cola  |     |
| 2   | cola water  |     |
| 3   | cola cola   |     |
| 4   | water water | ✅  |

<details><summary>Тайлбар</summary>

`a = b` → a нь water, cola алга болсон. `b = a` → b нь мөн water. Солихын тулд 3 дахь хайрцаг хэрэгтэй.

</details>
</details>

<summary><b>15. CU-д рамён</b> · 60 сек</summary>

<br>

```js
// Бат найзуудтайгаа CU-д рамён авлаа
let une = ?;       // 1 рамёны үнэ
let shirheg = ?;   // хэдэн рамён
let kupon = ?;     // купоны хөнгөлөлт
let tolbor = une * shirheg - kupon;
console.log(tolbor);   // 5000
```

**Бат 5000₮ төлсөн. Аль утгууд байж болох вэ?**

| #   | Хариулт                               |     |
| --- | ------------------------------------- | --- |
| 1   | une = 5000, shirheg = 0, kupon = 0    |     |
| 2   | une = 2500, shirheg = 2, kupon = 100  |     |
| 3   | une = 4500, shirheg = 1, kupon = 500  |     |
| 4   | une = 2500, shirheg = 3, kupon = 2500 | ✅  |

<details><summary>Тайлбар</summary>

`2500 * 3 = 7500`, `7500 - 2500 = 5000`. Бусад нь: 0 ширхэг → 0₮, `5000 - 100` → 4900, `4500 - 500` → 4000 (купоныг хасна, нэмэхгүй).

</details>
