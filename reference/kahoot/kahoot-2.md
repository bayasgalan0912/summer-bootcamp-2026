<summary><b>1. class-ыг CSS-д сонгох</b> · 60 сек</summary>

<br>

```html

  <h2>Миний зорилго</h2>
</div>
```

**Энэ хайрцгийг CSS-д яаж сонгох вэ?**

| # | Хариулт | |
| - | ------- | - |
| 1 | `#goal { }` | |
| 2 | `goal { }` | |
| 3 | `.goal { }` | ✅ |
| 4 | `class=goal { }` | |

<details><summary>Тайлбар</summary>

`#` нь `id`-д. `.` нь `class`-д.

</details>
