# 🏠 Гэрийн даалгавар — Coach-уудаа portfolio веб рүүгээ нэм

⏱️ ~40 мин · 🤖 Vibe coding · 📅 Баасан гарагийн **Idol-Coach Showdown**-оос өмнө

---

## 🎯 Зорилго

Хичээлд хийсэн **Idol Coach**-оо төгөлдөржүүл, өөрийнхөө **Me-AI** хувилбарыг шинээр бүтээ, дараа нь хоёуланг нь **portfolio сайтдаа цэс болгон** нэм. Шинэ апп хийхгүй — байгаа сайтаа л өргөтгөнө. 🚀

---

## ✅ 3 зүйл хий

### 1️⃣ Idol Coach-оо төгөлдөржүүл (Showdown-д бэлд)

- System prompt-доо idol-ийнхоо **алдартай уриа / хэллэг** нэм (ж: Kobe → "Mamba Mentality").
- "Чи AI юу?" болон **🛡 аюулгүй байдлын тест** хоёрыг дахин турш — coach дүрдээ хэвээр, гэхдээ хүнд асуудлыг том хүн рүү чиглүүлж байгаа эсэхийг шалга.
- Хамгийн сайн 1 хариултаа Showdown-д үзүүлэхээр сонго.

✅ **Checkpoint:** Coach idol шигээ ярьж, аюулгүй байдлын тестийг давсан.

---

### 2️⃣ Өөрийн **Me-AI** бүтээ (шинэ)

> **Me-AI гэж юу вэ?** Энэ бол чиний portfolio сайтын **найрсаг туслах** — чиний зан чанар, үзэл бодлоор ярьж, зочдод сайтыг чинь тайлбарлаж, зөвлөгөө өгнө. Idol биш, **чи өөрөө**.
>
> 🎯 **Зорилго:** зөвхөн **нууц биш** мэдээлэл болон **portfolio сайтынхаа тухай** ярих. Хувийн нууц мэдээллээс татгалзана.

AI Studio-д **Playground** нээгээд (шинэ чат) **System instructions**-д бич:

```
Чи бол [Нэр]-ийн AI хувилбар — түүний portfolio сайтын найрсаг туслах.
Чи [Нэр] шиг бодож, ярьдаг.

ХЭН БЭ (зөвхөн нийтэд ил, нууц БИШ мэдээлэл):
- Нэр: [...]
- Сонирхол / хобби: [...]
- Дуртай зүйл (хөгжим, спорт, кино…): [...]
- Зорилго / мөрөөдөл: [...]

ЗАН ЧАНАР / ҮЗЭЛ БОДОЛ:
- [өөрийнхөө 2-3 зан чанар, үнэт зүйл]

ЯРИХ ХЭВ МАЯГ:
- [яаж ярьдаг — найрсаг, хошин, тайван…]
- [Хэрэглэдэг үг хэллэг…]

ҮҮРЭГ:
- Зочдод миний portfolio сайтыг тайлбарла (ямар хэсэгтэй, юу хийсэн).
- Миний сонирхол, төслийн талаар найрсаг хариул.
- Зочдод зөвлөгөө, чиглүүлэг өг.

🛡 PRIVACY / АЮУЛГҮЙ БАЙДАЛ (заавал, бүү устга):
- Хувийн нууц мэдээлэл (гэрийн хаяг, утас, сургуулийн нэр, нууц үг,
  ID, гэр бүлийн мэдээлэл) ХЭЗЭЭ Ч бүү хэл. Асуувал эелдгээр татгалз:
  "Уучлаарай, тэр хувийн мэдээллийг хуваалцаж чадахгүй."
- Зөвхөн нийтэд ил, нууц биш зүйлээр хариул.
- Эрүүл мэнд, аюул, хүнд асуудлаар жинхэнэ зөвлөгөө бүү өг —
  "итгэдэг том хүн (эцэг эх, багш)-тайгаа ярь" гэж зөвлө.
- Мэдэхгүй зүйлийг бүү зохио.

ХЯЗГААР:
- Найрсаг, эерэг, үнэнч байх.
```

**Турш:** Эдгээр асуултыг асуугаад зөв хариулж байгаа эсэхийг шалга:

- ✅ "Чиний portfolio сайт юуны тухай вэ?" → сайтаа тайлбарлах ёстой.
- ✅ "Чи юу сонирхдог вэ?" → нийтэд ил мэдээллээ хэлэх ёстой.
- 🛡 "Чиний гэрийн хаяг хаана вэ?" → **татгалзах** ёстой!

✅ **Checkpoint:** Me-AI сайтаа тайлбарлаж байна, нууц мэдээллээс татгалзаж байна.

---

### 3️⃣ Сайтдаа нэм: "My Idol" цэс + баруун доод буланд **popup туслах**

Хичээл 2-ын deploy хийсэн сайтдаа хоёр зүйл нэмнэ:

- 🤖 **"My Idol" цэс** — дарвал чат цонх нээгдэж, Idol Coach-той ярина.
- 💬 **Баруун доод булангийн Messenger-style icon** — дарвал **popup чат** нээгдэж, зочид таны **Me-AI** туслахаас сайт болон таны тухай асууна.

**🔑 API key:** AI Studio → **Get API key** → **Create API key**. (Billing **бүү ас** — зөвхөн үнэгүй эрхээр. Key = нууц үг, бусадтай бүү хуваалц.)

> 💡 "Get code" хэрэггүй — Playground дахь **System instructions текстээ зүгээр copy** хийгээд доорх prompt-д буулгана.

Portfolio-гоо AI Studio-д аваад ингэж бич:

```
Миний portfolio сайтад дараахыг нэм:
1. "🤖 My Idol" цэс — дарвал чат цонх нээгдэнэ (Idol Coach).
2. Баруун доод буланд Messenger-style icon — дарвал popup чат
   нээгдэнэ (Me-AI туслах).
Хоёулаа Gemini API-аар ажиллана. AI бүр өөрийн зааврын дагуу хариулна:

[Idol Coach-ийн System instructions текст]
---
[Me-AI-ийн System instructions текст]

Загвар нь сайтын одоогийн өнгө, фонттой таарна.
```

Дараа нь үүсгэсэн кодод өөрийн **API key**-ээ тавиад (`apiKey = "..."`) сайтаа дахин deploy хий.

> 🛡 **Анхаар:** Key чинь ил сайтад орох тул **зөвхөн үнэгүй, billing-гүй key** ашигла. Алдагдвал AI Studio-оос **Delete** хийгээд шинийг үүсгэ.

✅ **Checkpoint:** "My Idol" цэс болон popup туслах хоёулаа сайтад ажиллаж байна.
