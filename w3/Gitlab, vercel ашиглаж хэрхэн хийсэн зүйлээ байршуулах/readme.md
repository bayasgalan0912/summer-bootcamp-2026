# 1. AI Studio дээрээс ZIP файл татаж авах

AI Studio дээр хийсэн төслөө GitLab руу оруулахын өмнө эхлээд компьютер дээрээ **ZIP файл** болгон татаж авна.

---

## 1. Төслөө ZIP файл болгон татаж авах

1. AI Studio дээр төслөө нээнэ.
2. Дээд хэсэгт байрлах **Code** таб дээр дарна.
3. Баруун дээд буланд байрлах **Export** товчийг дарна.
4. Гарч ирэх цэснээс **Download as .zip file** сонголтыг дарна.

![Зургийн тайлбар](images/ff.png)

5. Ингэснээр таны төслийн бүх файл нэг **ZIP файл** болж компьютерт татагдана.
---

## 2. ZIP файлаа задлах

⚠️ GitLab руу ZIP файлыг өөрийг нь биш, **задалсан файлуудыг** оруулах шаардлагатай.

1. ZIP файл дээр хулганын **баруун товч** дарна.
2. **Extract All...** (эсвэл Extract Here) сонгоно.
3. Шинээр хавтас үүсэх бөгөөд төслийн бүх файлууд дотор нь байна.

Жишээ:

```text
my-ai-website/
│
├── index.html
├── package.json
├── src/
├── public/
└── ...
```

Одоо ZIP файлаа задалсан тул дараагийн алхам болох **GitLab дээр Repository үүсгэж файлуудаа Upload хийх** хэсэг рүү шилжинэ.


# 2. AI Studio дээрээс татаж авсан ZIP файлаа GitLab руу оруулцгаая

## 1. GitLab гэж юу вэ?

GitLab нь програмын код хадгалах, хувилбар удирдах болон хамтран ажиллах боломжтой онлайн платформ юм.

AI Studio дээр хийсэн веб сайтаа GitLab дээр хадгалснаар дараа нь Vercel ашиглан маш амархан интернетэд байршуулж болно.

### GitLab-ийн давуу талууд

- Кодоо онлайнаар аюулгүй хадгална.
- Өөрчлөлтийн түүх хадгалагдана.
- Багийн ажиллагаанд тохиромжтой.
- Vercel-тэй шууд холбогддог.

---

# 2. GitLab бүртгэл үүсгэх

1. https://gitlab.com/ сайт руу орно.
2. **Sign up** товчийг дарна.
3. И-мэйл болон нууц үгээ ашиглан бүртгэлээ үүсгэнэ.
4. Бүртгэлээ баталгаажуулж **Sign in** хийнэ.

> 📷 **Зураг:** `images/gitlab-signup.png`

---

# 3. AI Studio-оос төслөө ZIP хэлбэрээр татаж авах

1. AI Studio дээр төслөө нээнэ.
2. **Share** товчийг дарна.
3. **Download ZIP** сонголтыг дарна.
4. ZIP файл компьютер дээр хадгалагдана.

> 📷 **Зураг:** `images/download-zip.png`

---

# 4. ZIP файлаа задлах

1. Татаж авсан ZIP файл дээрээ хулганын баруун товч дарна.
2. **Extract All...** (эсвэл Extract Here) сонгоно.
3. Шинээр хавтас үүсэх бөгөөд дотор нь вебийн бүх файлууд байна.

Жишээ:

```text
my-ai-website/
│
├── index.html
├── package.json
├── src/
├── public/
└── ...
```

> 📷 **Зураг:** `images/extract-zip.png`

---

# 5. GitLab дээр шинэ Repository үүсгэх

1. GitLab руу орно.
2. **New project** товчийг дарна.

> 📷 **Зураг:** `images/new-project.png`

---

3. **Create blank project** сонгоно.

> 📷 **Зураг:** `images/blank-project.png`

---

4. Repository-ийн нэрээ бичнэ.

Жишээ:

```text
my-ai-website
```

5. Visibility хэсгийг **Public** болгоно.

6. **Create project** товчийг дарна.

> 📷 **Зураг:** `images/create-project.png`

---

# 6. Компьютер дээрээс файлуудаа GitLab руу оруулах

Шинээр үүсгэсэн Repository дотроо орно.

Дараа нь

**+** товч → **Upload file**

эсвэл

**Upload file** товчийг дарна.

> 📷 **Зураг:** `images/upload-file.png`

---

# 7. ZIP-ээ биш задалсан файлуудаа сонгоно

⚠️ Анхаараарай

ZIP файлыг өөрийг нь оруулахгүй.

Задалсан хавтас доторх бүх файлыг сонгоно.

Жишээ:

```
index.html
package.json
src
public
README.md
```

Эдгээрийг бүгдийг нь чирж (Drag & Drop) GitLab дээр оруулна.

> 📷 **Зураг:** `images/drag-files.png`

---

# 8. Commit хийх

Файлууд бүгд орсны дараа доош гүйлгэн

**Commit changes**

товчийг дарна.

Ингэснээр таны веб GitLab дээр хадгалагдана.

> 📷 **Зураг:** `images/commit.png`

```text

README.md
```
