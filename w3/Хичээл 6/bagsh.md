## Тэмцээн

**Раунд 1 — Юу хэвлэх вэ?**

| #   | Код                                                           | Хариу         |
| --- | ------------------------------------------------------------- | ------------- |
| 1   | `for (let i = 0; i < 3; i++) { console.log(i) }`              | `0 1 2`       |
| 2   | `let s = 0; for (let i = 1; i <= 4; i++) { s = s + 2 } console.log(s)` | `8`  |
| 3   | `for (let i = 10; i > 0; i = i - 3) { console.log(i) }`       | `10 7 4 1`    |
| 4   | `let x = 1; while (x < 20) { x = x * 3 } console.log(x)`      | `27`          |
| 5   | `for (let i = 1; i <= 5; i++) { if (i % 2 === 0) { console.log(i) } }` | `2 4` |

**Раунд 2 — Код бич**

1. 7-ийн үржих хүснэгтийг хэвлэ: `7 x 1 = 7` ... `7 x 10 = 70`
2. 1-ээс 50 хүртэл **7-оор төгссөн** тоонуудын нийлбэр: 7+17+27+37+47 → `135`
3. FizzBuzz 1–15: 3-т → "Fizz", 5-д → "Buzz", хоёуланд → "FizzBuzz", бусад → тоо
