<details>
<summary><b>1. Код хэрхэн ажилладаг</b></summary>

<br>

```js
let total = 0;

for (let i = 1; i <= 3; i++) {
  total = total + i;
}

console.log(total);
```

| Удаа | `i` | `i <= 3`? | `total`       |
| ---- | --- | --------- | ------------- |
| 1    | 1   | тийм      | 0 + 1 = **1** |
| 2    | 2   | тийм      | 1 + 2 = **3** |
| 3    | 3   | тийм      | 3 + 3 = **6** |
| —    | 4   | **үгүй**  | зогсоно       |

**for** = "эхлэх; хэзээ болих; алхам бүрт юу өөрчлөх".

[pythontutor](https://pythontutor.com/javascript.html)-д хийгээд **Next** дарж `i`, `total` хэрхэн өөрчлөгдөхийг хар.

<details>
<summary>while</summary>

<br>

Хэдэн удаа давтахаа **мэдэхгүй** үед хэрэглэнэ:

```js
let money = 1000;
let years = 0;
while (money < 5000) {
  money = money * 2;
  years++;
}
console.log(years); // 3
```

⚠️ Нөхцөл хэзээ ч худал болохгүй бол **эцэс төгсгөлгүй** давтана → хуудас гацна.
