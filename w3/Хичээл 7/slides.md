### Слайд 11 — 📦 sprites.json (Хичээл 5-ын JSON дахин!)

```json
{
  "arena": "https://…/arena-1.png",
  "p1": {
    "name": "ГАЙА",
    "idle": ["https://…/p1-idle-1.png", "https://…/p1-idle-2.png"],
    "punch": ["https://…/p1-punch-1.png"],
    "hit": ["https://…/p1-hit-1.png"]
  }
}
```

| `{ }` object | НЭГ тулаанчны бүх мэдээлэл  |
| ------------ | --------------------------- |
| `[ ]` array  | frame-ийн **дараалал**      |
| 🪆 nested     | object дотор array          |

🟢 **JSONLint дээр Valid болтол цаашаа явахгүй!**

→ "Яагаад 1 зурагтай `punch` ч array вэ? Хичээл 8-д frame нэмэхэд **кодоо өөрчлөхгүй, зөвхөн дата нэмнэ**. 🧠 **Код = дүрэм, дата = агуулга.**"

### Слайд 12б — 🎚️ AI-тай ТЭМЦЭХГҮЙ (ангийг зогсоо)

```js
export const POS = {
  fighterHeight: 45, // тулаанчны өндөр (%)
  groundLine: 88, // газрын шугам (%)
  p1Start: 20,
  p2Start: 75,
  bgScale: 1.4,
};
```

🎈 хөвж байна → `groundLine` **88 → 92** → refresh → **болоо** ✅
