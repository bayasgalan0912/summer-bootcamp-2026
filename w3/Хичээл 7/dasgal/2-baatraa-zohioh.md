# 🧝 ХЭСЭГ 2 — Баатраа сонгох & зохиох · ⏱️ ~14 мин

> 🎯 **Зорилго:** 2 тулаанчнаа шийдэж, **дүрийн карт** бөглөх. Энэ карт нь дараа шууд **зургийн промпт** болно.

<summary>🚪 <b>Дасгал 2.1 — 3 замын аль нэгийг сонго</b> · ⏱️ ~2 мин</summary>

**Ямар түвшний дүр гаргах вэ?** Жишээ багц ([`w3/assets`](../../assets/readme.md)) дахь 3 дүр — гурвуулаа өөр өнгө, өөр биеийн хэлбэр, өөр тулааны сургуультай:

> 🔑 **Анзаар:** гурвуулаа **өнгөөрөө шууд ялгагдана**. P1, P2-оо сонгохдоо яг үүнийг бод.

Тулаанчнаа **3 өөр аргаар** гаргаж болно. Хосоороо ярилцаад сонго:

| Зам                        | Хэн сонгох вэ                                | Хугацаа |
| -------------------------- | -------------------------------------------- | ------- |
| 🥷 **А. Дуртай дүр**       | "Naruto, Goku-гаараа тулалдмаар байна!"      | ⚡ хурдан |
| 🤳 **Б. ӨӨРӨӨ**            | "Би өөрөө тоглоомын дүр болмоор байна!" 🔥    | ⚡ хурдан |
| ✏️ **В. Өөрөө зохиох**     | "Дэлхийд байхгүй шинэ дүр гаргамаар байна"    | 🐢 удаан  |

> 💡 **Хамгийн гоё хослол:** P1 = **чи өөрөө** (Зам Б) · P2 = **дуртай дүр** (Зам А). Чи Naruto-той тулалдана! 😎

> 🎯 **Хоёулаа өөр зам сонгож болно** — P1 нэг замаар, P2 өөр замаар.

<summary>🥷 <b>ЗАМ А — Дуртай дүрээ хэрэглэх</b> · ⏱️ ~4 мин</summary>

Naruto, Goku, Luffy, Tanjiro, Spider-Man, Sung Jin-Woo… — дуртай дүрээ шууд тулаанчин болго.

**Юу бичих вэ:** Дүрийн нэрийг бичээд, **гол шинжүүдийг** нь өөрөө нэрлэ. AI дүрийг мэддэг ч, шинжийг нь бичвэл **хамаагүй тогтвортой** гарна.

```
ДҮРИЙН НЭР:                  Naruto
ХУВЦАС (2–3 зүйл):           улбар шар–хар костюм, духны protector
ГОЛ ӨНГӨ:                    улбар шар + шар (үс)
ТАНИХ ШИНЖ (2–3):            хатгамал шар үс, хацрын 3 зураас, цэнхэр нүд
ОНЦЛОГ ХӨДӨЛГӨӨН:            Rasengan 🌀
```

> ⚠️ **P2 нь P1-ээс өнгөөрөө БҮРЭН ялгаатай** байх ёстой — тоглоом дундаа хэн хаана байгааг харахгүй бол сонирхолгүй болно. Naruto (улбар шар) vs Sasuke (цэнхэр–хар) ✅ · Naruto vs Goku (хоёулаа улбар шар) ⚠️

### 📌 Мэдэж авах — эдгээр дүр бол **бусдын өмч**

Naruto, Goku нар бол студийн **зохиогчийн эрхтэй** (copyright) дүрүүд. Тиймээс:

| ✅ Болно                                     | ❌ Болохгүй                            |
| -------------------------------------------- | -------------------------------------- |
| Ангидаа тоглох, найзууддаа үзүүлэх            | **Мөнгө** олох, зарах                  |
| Гэртээ, гэр бүлдээ үзүүлэх                    | "Би зохиосон" гэж хэлэх                |
| Хичээлийн даалгавар болгож ашиглах            | Албан ёсны тоглоом мэт зарлах          |

> 🛡️ **Публиш хийхдээ (ХЭСЭГ 6-ын Bronze quest):** дэлгэцийн доод талд **_"Fan-made — дүрүүд нь эх зохиогчдынх"_** гэж бич. Энэ бол интернэтийн энгийн ёс — fan art хийдэг бүх хүн ингэдэг.

<details>
<summary>🤳 <b>ЗАМ Б — ӨӨРИЙГӨӨ тоглоомын дүр болгох</b> · ⏱️ ~4 мин · 🔥 хамгийн хөгжилтэй</summary>

Өөрийн зургаа AI-д өгөөд **pixel art тулаанчин** болгуулна. Ангийнхан чинь чамайг таних болно! 😄

### 📸 Ямар зураг тохирох вэ?

| ✅ Сайн зураг                       | ❌ Муу зураг                        |
| ----------------------------------- | ----------------------------------- |
| Нүүр тод харагдана                  | Бүдэг, харанхуй                     |
| **Бүтэн бие** эсвэл бүсэлхийнээс дээш | Зөвхөн нүд, ойрын зураг             |
| Энгийн дэвсгэр                      | Олон хүн, замбараагүй дэвсгэр       |
| Хувцас нь тод харагдана             | Filter, эффект их                   |

> 📱 **Хамгийн хялбар:** зогсоод бүтэн биеэрээ 1 selfie ав (найзаараа авахуул) — тэр л хангалттай.

### 🪄 Промпт (зургаа хавсаргаад бич)

```text
[Өөрийн зургаа хавсарга 📎]

Хавсаргасан зураг дээрх хүнийг 2D тулааны тоглоомын дүр (game sprite)
болго.

ХАДГАЛАХ ЗҮЙЛ:
- үсний өнгө, засалт
- арьсны өнгө
- хувцасны өнгө, төрөл
- ерөнхий бие галбир
→ ангийнхан нь таних ёстой!

СТИЛЬ:
- pixel art, 16-bit retro arcade fighting game
- ЖИНХЭНЭ зураг биш, ЗУРСАН дүр шиг

ЗААВАЛ:
- fighting stance (тулаанд бэлэн байрлал), хоёр гараа өргөсөн
- side view — хажуу тийш харсан
- full body — толгойноос хөл хүртэл бүтэн
- single solid color code bright green screen background
- no drop shadow
- зургийн хэлбэр 4:3
```

<summary>🎮 Stretch — өөрийгөө "супер хувилбар" болгох</summary>

...дээрх бүх зүйлийг хадгалаад, дүрд тулааны тоглоомын өнгө нэм:

😎 Чи өөрөө — гэхдээ **ниндзя** хувилбар!

</details>

### 🛡️ Зургийн хилийн дүрэм (заавал унших)

| ✅ Болно                                       | ❌ Болохгүй                                            |
| ---------------------------------------------- | ------------------------------------------------------ |
| **Өөрийн** зураг                               | Найз, ангийнхны зургийг **зөвшөөрөлгүй** 🚨            |
| Найзын зураг — **өөрөө нь зөвшөөрсөн бол**     | Багш, гэр бүл, танихгүй хүний зураг                     |
| Гэр бүлийн зураг — **зөвшөөрөл авсан бол**     | Интернэтээс олсон танихгүй хүний зураг                  |

> 🚨 **Хамгийн чухал:** Хэн нэгний зургийг тоглоомд оруулахын өмнө **өөрөөс нь асуу**. "Хөгжилтэй байх байх" гэж бодох нь хангалтгүй — тэр хүн нь шийднэ.

> 📤 **Публиш хийхээсээ өмнө бод:** Тоглоом чинь Vercel дээр **интернэтэд ил** байршина. Өөрийн pixel art дүр бол асуудалгүй (жинхэнэ зураг биш, зурсан дүр). Гэхдээ **жинхэнэ selfie-гээ тоглоомд бүү тавь** — зөвхөн AI-ийн зурсан хувилбарыг л хэрэглэ.

</details>
