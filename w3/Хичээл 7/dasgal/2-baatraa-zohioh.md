# 🧝 ХЭСЭГ 2 — Баатраа зохиох · ⏱️ ~15 мин

> 🎯 **Зорилго:** Өөрийн **ӨӨРИЙН** тулаанчныг зохиож, дүрийн картаа (character sheet) бөглөх. Энэ карт нь дараа шууд **зургийн промпт** болно.

> ⚠️ **Ryu, Chun-Li, Goku, Naruto — БОЛОХГҮЙ.** Тэд бусдын дүр (copyright). Өөрийн дүр зохио — бас илүү гоё болно, учир нь ангид өөр хэн ч тийм дүртэй байхгүй.

<summary>💡 <b>Дасгал 2.1 — Санаа: Монголоос авах</b> · ⏱️ ~3 мин</summary>

Хамгийн сайн тулаанчид **хаанаас нэгээс** гардаг. Чи Монголоос ав — ангид хэн ч давхардахгүй.

| 🇲🇳 Санаа            | Дүр төрх                                | Онцлог хөдөлгөөн                  |
| ------------------- | --------------------------------------- | --------------------------------- |
| 🤼 **Бөх**          | зодог, шуудаг, гутал                    | Даяа авах, барьж шидэх            |
| 🏹 **Морьт харваач** | дээл, бүс, годил · нуруундаа саадаг     | Хурдан харвах                     |
| 🥁 **Бөө / шаман**  | толь, шүүр, өдтэй малгай                | Хэнгэрэг цохиж долгион гаргах     |
| 🎤 **Хөөмийч**      | дээл, тэрлэг                            | Хөөмийн долгион (sound wave)      |
| 🐺 **Чонын дүр**    | арьс, ясан гоёл                         | Хурдан хумсалж цохих              |
| 🚀 **Кибер номад**  | неон дээл, LED бүс, hoverboard          | Электрон цохилт                   |

<details>
<summary>🌍 Монгол биш санаа ч болно</summary>

Кофе шоптой barista 🧋 · робот сантехникч 🔧 · ниндзя-мэргэжлийн үсчин ✂️ · сагсан бөмбөгчин 🏀 · хоолны шеф 🍳 · математикийн багш 📐

> 💡 **Хамгийн хөгжилтэй = хамгийн санаанд оромгүй.** "Кибер ааруул нийлүүлэгч" гэсэн дүр ангийг үхтэл инээлгэнэ.

</details>

<summary>📋 <b>Дасгал 2.2 — Дүрийн карт бөглөх (2 дүр)</b> · ⏱️ ~8 мин · 🔑 гол дасгал</summary>

Хоёр тулаанчин хэрэгтэй: **P1 (чиний баатар)** ба **P2 (өрсөлдөгч)**. Хоёуланг нь бөглө.

> 🎨 **Өнгө хамгийн чухал:** P1 ба P2 нь **бүрэн өөр өнгөтэй** байх ёстой — тоглоом дундаа хэн хаана байгааг харагдахгүй бол тоглоом сонирхолгүй болно.

### 🥋 P1 — Миний баатар

```
НЭР (богино, хүчтэй):            _________________
ХЭН/ЮУ (1 өгүүлбэр):             _________________
ХУВЦАС (2–3 зүйл):               _________________
ГОЛ ӨНГӨ (1–2):                  _________________
ГАРТАА / БИЕДЭЭ ЮУ БАЙНА:        _________________
ОНЦЛОГ ХӨДӨЛГӨӨНИЙ НЭР:          _________________
```

### 👹 P2 — Өрсөлдөгч

```
НЭР:                             _________________
ХЭН/ЮУ:                          _________________
ХУВЦАС:                          _________________
ГОЛ ӨНГӨ (P1-ээс ӨӨР!):          _________________
ГАРТАА / БИЕДЭЭ ЮУ БАЙНА:        _________________
ОНЦЛОГ ХӨДӨЛГӨӨНИЙ НЭР:          _________________
```

<details>
<summary>💡 Бөглөсөн жишээ харах</summary>

**P1 — ГАЙА**

```
НЭР:                  ГАЙА
ХЭН/ЮУ:               Говь цөлийн залуу бөхчин, аадар бороо дуудаж чадна
ХУВЦАС:               хөх зодог, шуудаг, урт монгол гутал
ГОЛ ӨНГӨ:             хөх + алт
ГАРТАА:               буржгар бүс, гарын боолт
ОНЦЛОГ ХӨДӨЛГӨӨН:     "АЯНГАН ДААЯА" ⚡
```

**P2 — ТӨМӨР ЧОНО**

```
НЭР:                  ТӨМӨР ЧОНО
ХЭН/ЮУ:               Хотын кибер махчин, төмөр гартай
ХУВЦАС:               хар савхин дээл, неон улаан бүс
ГОЛ ӨНГӨ:             хар + неон улаан
ГАРТАА:               төмөр хумс, нүдэн дээр visor
ОНЦЛОГ ХӨДӨЛГӨӨН:     "ТӨМӨР ХУМС" 🔴
```

> 🔑 Ажигла — жишээнд **өнгө бүрэн өөр** (хөх+алт vs хар+неон улаан). Тоглоом дээр шууд ялгагдана.

<details>
<summary>🛡️ <b>Дасгал 2.3 — Хилийн дүрэм (унших заавал)</b> · ⏱️ ~2 мин</summary>

Тоглоомоо интернэтэд байршуулна — **хэн ч харж болно**. Тиймээс хил бий:

| ✅ Болно                                   | ❌ Болохгүй                                          |
| ------------------------------------------ | ---------------------------------------------------- |
| Өөрөө зохиосон дүр                         | Ryu, Goku, Naruto — **бусдын дүр** (copyright)        |
| Уран зөгнөлт мангас, робот, тэнгэр         | **Жинхэнэ хүн** — найз, багш, ангийнхан, гэр бүл 🚨   |
| ⭐💥 arcade эффект (од, гялбаа)             | Цус, шарх, бэртэл — хэт хүчирхийлэл                   |
| Хөгжилтэй, инээдтэй дүр                    | Хэн нэгнийг **шоолсон** дүр (жишээ: сул дорой багш)   |
| Монгол соёлыг **хүндэтгэсэн** дүр          | Соёл, шашныг шоолсон агуулга                          |

> 🚨 **Хамгийн чухал:** Найзынхаа зургийг тулаанчин болгож **цохиулж БОЛОХГҮЙ**. Хөгжилтэй санагдаж болох ч тэр хүнд гомдол болдог, интернэтээс мөн арилахгүй.

</details>
