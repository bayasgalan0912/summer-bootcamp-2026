<summary>🆘 <b>Гацвал — түгээмэл 5 асуудал</b></summary>

**🎭 Дүр минь frame тутам ӨӨР ХҮН болчихлоо** → Шинээр үүсгэсэн байна. **Тэр л ярианд** засуул: _"Яг ижил дүр, ижил хувцас, ижил өнгө байлга. ЗӨВХӨН хөдөлгөөнийг өөрчил."_ (ХЭСЭГ 3.6)

**⬛ Sprite-ын ард цагаан / ногоон дөрвөлжин** → Дэвсгэр цэвэрлэгдээгүй. **[remove.bg](https://www.remove.bg)** руу зургаа хая → Download. AI-аас "transparent" гуйж цаг үрэхгүй — **ногоон дэвсгэр** гуйгаад арилга (ХЭСЭГ 3.3).

**🏃 Дүр анимаци дунд "гулсаж" байна** → Frame бүрт дүр өөр цэгт байна. Засуул: _"Дүр яг тэр л цэгтээ, ижил өндөрт байхаар дахин гарга."_ (ХЭСЭГ 4.2, дүрэм №4)

**🖼️ Зураг тоглоомд гарахгүй** → Хаягаа шинэ tab-д турш. Зөвхөн зураг гарах ёстой. `github.com/.../blob/...` бол **буруу** — `Raw` дарж `raw.githubusercontent.com` хаяг ав. Файлын нэрэнд **кирилл эсвэл зай** байвал зас. (ХЭСЭГ 5.2)

**🎈 Тулаанчин агаарт хөвж байна / хэт том** → ⭐ AI-д хэлэхгүй! `positions.js` файлын `groundLine`, `fighterHeight` тоог **өөрөө** зас (ХЭСЭГ 6.2б).

**🚦 AI "limit" гэж байна** → Зураг үүсгэлт **их зарцуулдаг**. Хичээл 4-ийн дүрэм: шаардлагаа **1 мессежид нэгтгэ** · гарсан зургаа **тэр даруй хадгал** · "дахин үзье" 10 удаа дарахгүй.

<summary>🛡️ <b>AI Smart &amp; Safe</b></summary>

- **🥷 Дуртай дүрээ хэрэглэж БОЛНО — гэхдээ шударгаар.** Naruto, Goku нар бол студийн өмч. ✅ ангидаа тоглох, найзууддаа үзүүлэх · ❌ мөнгө олох, "би зохиосон" гэх. Publish хийвэл доор нь **_"Fan-made — дүрүүд нь эх зохиогчдынх"_** гэж бич.
- **📎 Стиль vs Дүр** — Хуучин тоглоомын зургийг хавсаргаж **АРТ СТИЛЬ** зээлэх нь чөлөөтэй (стилийг хэн ч эзэмшдэггүй). Дүрийн тухай дүрэм нь дээрх мөрөнд. (ХЭСЭГ 3.4)
- **🤳 Өөрийн зураг ✅ · бусдынх зөвшөөрөлгүй ❌** — Өөрийгөө дүр болгох нь супер. Гэхдээ найз, багш, гэр бүлийнхээ зургийг оруулахын өмнө **өөрөөс нь асуу**. "Хөгжилтэй байх байх" гэж бодох нь хангалтгүй — тэр хүн нь шийднэ.
- **📤 Жинхэнэ selfie-гээ тоглоомд бүү тавь** — зөвхөн AI-ийн зурсан **pixel art хувилбарыг** хэрэглэ. Тоглоом интернэтэд ил байршина.
- **🩸 Цус, шарх, бэртэл байхгүй** — arcade эффект (⭐💥 од, гялбаа) хэрэглэ. Тоглоом хөгжилтэй байх ёстой, эмээх юм биш.
- **🎨 Кредит өг** — тоглоомын доод талд _"Sprites: AI (Gemini) + миний дизайн"_ гэж бич.
- **🇲🇳 Соёлыг хүндэтгэ** — бөх, бөө, дээл гоё сэдэв. Гэхдээ шоолсон биш, **хүндэтгэсэн** дүр байг.
- **🤖 AI эндүүрдэг** — "transparent" гэж хэлсэн ч цагаан дэвсгэр гаргаж мэднэ. **Өөрөө шалга.**

</details>

<details>
<summary>📚 <b>Glossary — шинэ үгс</b></summary>

| Үг                     | Тайлбар                                                    |
| ---------------------- | ---------------------------------------------------------- |
| **Sprite**             | Тоглоомд хэрэглэдэг дэвсгэргүй нэг дүрсний зураг            |
| **Transparent PNG**    | Дэвсгэргүй зураг — ард шалмаг дөрвөлжин харагдана           |
| **Green screen**       | Ногоон дэвсгэр — дараа нь арилгахад хялбар (кино ч ингэдэг)   |
| **Chroma key**         | Тодорхой өнгийг (ногоон) зургаас арилгах арга                |
| **Reference image**    | Стиль зээлэхээр хавсаргах жишээ зураг                        |
| **Aspect ratio**       | Зургийн хэлбэр — 16:9 өргөн · 4:3 зайтай · 21:9 маш өргөн     |
| **Frame**              | Анимацийн НЭГ зураг                                        |
| **ms (миллисекунд)**   | 1000ms = 1 секунд. Frame тутам ~150ms                       |
| **Төлөв (state)**      | Дүр одоо юу хийж байна: idle / punch / hit                   |
| **Idle**               | Юу ч дараагүй үеийн "бэлэн зогсоо" төлөв                     |
| **Side view**          | Хажуугаас харсан — тулааны тоглоомын үзэх зүг                 |
| **Asset**              | Тоглоомд хэрэглэх файл — зураг, дуу, дэвсгэр                  |
| **Raw линк**           | Зургийн жинхэнэ интернэт хаяг (HTML хуудас биш)               |
| **Mirror / flip**      | Зургийг толин ойлгох — `scaleX(-1)`                          |
| **Knockback**          | Цохиулсан дүр хойш түлхэгдэх                                 |
| **Screen shake**       | Цохилтын үед дэлгэц бага зэрэг чичрэх                        |
| **Parallax**           | Дүр явахад дэвсгэр эсрэг тал руу гүйх — хөдөлгөөний хуурмаг    |
| **Character consistency** | Frame тутамд дүр **ижил хүн** байх (өнөөдрийн гол ур чадвар) |

</details>
