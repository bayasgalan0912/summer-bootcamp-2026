## Тэмцээн

**Раунд 1 — Юу хэвлэх вэ?**

| #   | Код                                                                        | Хариу    |
| --- | -------------------------------------------------------------------------- | -------- |
| 1   | `let x = 5; if (x > 3) { console.log("A") } else { console.log("B") }`     | `A`      |
| 2   | `let x = 50; if (x > 10) { console.log(1) } else if (x > 40) { console.log(2) }` | `1` — эхнийх нь л ажиллана |
| 3   | `console.log(5 > 3 && 2 > 4)`                                              | `false`  |
| 4   | `console.log(5 > 3 \|\| 2 > 4)`                                            | `true`   |
| 5   | `let t = "10"; if (t === 10) { console.log("тийм") } else { console.log("үгүй") }` | `үгүй` — текст ≠ тоо |

**Раунд 2 — Код бич**

1. Температур `t`: 0-оос доош "Хүйтэн", 25-аас дээш "Халуун", бусад "Сайхан". `t = -5` → `"Хүйтэн"`
2. Гурван тооны хамгийн ихийг ол: `4, 19, 11` → `19`
3. Нууц үг `"abc123"` бөгөөд урт нь 6+ бол `"Нэвтэрлээ"`. (Зөвлөгөө: `.length`)
