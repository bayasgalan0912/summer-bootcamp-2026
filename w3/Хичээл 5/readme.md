# Хичээл 5 — Нөхцөл: if / else

### Өнөөдөр код **шийдвэр гаргадаг** болно: "Хэрэв ... бол ..., үгүй бол ...".

| Цаг  | Юу хийнэ              |
| ---- | --------------------- |
| 0:00 | Давтлага (Хичээл 4)   |
| 0:10 | Код хэрхэн ажилладаг  |
| 0:35 | Бодлого бодох (6)     |
| 1:10 | Завсарлага            |
| 1:20 | Багийн тэмцээн 🏆     |
| 1:50 | Дүгнэлт               |

---

<details>
<summary><b>1. Код хэрхэн ажилладаг</b></summary>

<br>

```js
let hp = 20;

if (hp <= 0) {
  console.log("Game over");
} else if (hp < 30) {
  console.log("Анхаар!");
} else {
  console.log("Бүх юм зүгээр");
}
```

Компьютер **дээрээс нь** асуулт бүрийг шалгана. Эхний **тийм** хариутай хэсгийг ажиллуулаад **бусдыг алгасна**.

| Асуулт      | `hp = 20` үед | Юу болов       |
| ----------- | ------------- | -------------- |
| `hp <= 0`   | үгүй          | алгасна        |
| `hp < 30`   | **тийм**      | "Анхаар!" ✅   |
| `else`      | —             | шалгахгүй      |

`hp`-г 0, 50 болгож [pythontutor](https://pythontutor.com/javascript.html)-д туршаад ялгааг хар.

<details>
<summary>Өнөөдрийн үгс</summary>

<br>

| Код            | Утга                   |
| -------------- | ---------------------- |
| `===`          | тэнцүү                 |
| `!==`          | тэнцүү биш             |
| `> < >= <=`    | их, бага               |
| `&&`           | **ба** — хоёулаа үнэн  |
| `\|\|`         | **эсвэл** — аль нэг нь |
| `true / false` | үнэн / худал           |

⚠️ `=` бол **хийх**, `===` бол **харьцуулах**.
