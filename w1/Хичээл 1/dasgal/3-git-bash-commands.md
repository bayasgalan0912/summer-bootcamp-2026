# ⌨️ ХЭСЭГ 3 — Терминалын 4 үндсэн команд · ⏱️ ~20 мин

> 🎯 **Зорилго:** `pwd`, `ls`, `mkdir`, `cd` дөрвөн командаар терминалд **чөлөөтэй явж**, фолдер үүсгэж, дотор нь орж-гарч чаддаг болох. Апп үүсгэхэд яг энэ 4 команд хэрэгтэй.

🛠️ Хэрэгсэл: ХЭСЭГ 1-д нээсэн **терминал**

> 💡 **Багшид:** Windows дээр эдгээр командыг ажиллуулах бол Antigravity-ийн терминалд **Git Bash**-ыг сонго (эсвэл дотоод терминал дээр ажиллана). Mac дээр шууд ажиллана.

<details open>
<summary>🗺️ <b>Дасгал 3.1 — 4 команд = чиний луужин</b> · ⏱️ ~3 мин</summary>

> 🖼️ _(зураг: `../images/` — фолдерын мод + 4 командын зурагт тайлбар)_

Терминал бол **фолдеруудын лабиринт** дундах явган зуучлагч. Дөрвөн команд бол чиний **луужин**:

| Команд      | Асуулт / Үйлдэл                | Зүйрлэл                              |
| ----------- | ------------------------------- | ------------------------------------ |
| 📍 `pwd`    | **Би одоо хаана байна?**        | Газрын зураг дээрх "Та энд байна" цэг |
| 📂 `ls`     | **Энд юу байна?**               | Өрөөгөө тойрч харах                   |
| 🆕 `mkdir`  | **Шинэ фолдер үүсгэ**           | Шинэ өрөө барих                       |
| 🚪 `cd`     | **Фолдер руу ор / гар**         | Хаалгаар орох (`cd ..` = ухрах)      |

> 💡 **Ажигла:** `pwd` = _print working directory_, `ls` = _list_, `mkdir` = _make directory_, `cd` = _change directory_. Англи үгнийхээ товчлол — цээжлэхэд амар!

</details>

---

<details>
<summary>📍 <b>Дасгал 3.2 — `pwd` ба `ls` — "хаана байна? юу байна?"</b> · ⏱️ ~5 мин</summary>

Терминалдаа дараахыг **нэг нэгээр** бич (тус бүрийн дараа Enter):

```text
pwd
```

→ Одоо байгаа **бүтэн замаа** харуулна (жишээ: `/Users/nэр` эсвэл `C:\Users\нэр`). Энэ бол чиний "гэр".

```text
ls
```

→ Тэр фолдер дотор байгаа **бүх зүйлийг** жагсаана (`Desktop`, `Documents`, `Downloads` …).

> 💡 **Ажигла:** `pwd` **хаана** байгааг, `ls` тэнд **юу** байгааг хэлнэ. Төөрвөл энэ 2-ыг дараад л байрлалаа мэдэж авна.

**🎯 30 секундын даалгавар:** `ls` бичээд гарсан фолдеруудаас **нэгийг** сонго. Дараагийн дасгалд түүн рүү орно.

</details>

---

<details>
<summary>🚪 <b>Дасгал 3.3 — `cd` — фолдер руу орох ба гарах</b> · ⏱️ ~5 мин</summary>

`cd` дараа нь **фолдерын нэрийг** бичээд түүн рүү ордог.

```text
cd Desktop
```

→ Одоо чи Desktop **дотор** орлоо. Батал: `pwd` бичээд замд `Desktop` нэмэгдсэнийг хар. `ls` бичээд Desktop дээрх зүйлсээ хар.

**Ухрах (гарах)** бол хоёр цэг:

```text
cd ..
```

→ Нэг шат **ухарлаа**. `pwd`-ээр шалга — `Desktop` замаас алга болсон.

<details>
<summary>💡 3 алтан зөвлөгөө (гацвал энд хар)</summary>

- ⭐ **Tab товч** — фолдерын нэрийн эхний үсгийг бичээд **Tab** дар → нэрийг автоматаар гүйцээнэ. Алдаа бага гарна!
- 📁 Зайтай нэртэй фолдер бол хашилтад ав: `cd "My Folder"`.
- 🏠 `cd` дангаар нь (нэргүй) бичвэл шууд **гэр** рүүгээ буцна.

</details>

> ⚠️ **Ажигла:** `cd` фолдер руу л **ордог**, файл руу ордоггүй. `ls` бичихэд гарсан **фолдерын** нэрийг л `cd`-ийн ард бич.

</details>

---

<details>
<summary>🆕 <b>Дасгал 3.4 — `mkdir` — шинэ фолдер үүсгэх</b> · ⏱️ ~4 мин</summary>

Одоо шинэ фолдер бариад дотор нь орцгооё. Эхлээд гэр рүүгээ буцаад Desktop дээр ажиллая:

```text
cd Desktop
```

```text
mkdir my-apps
```

→ Юу ч харагдахгүй байвал — **энэ зөв!** Терминал чимээгүй бол "болсон" гэсэн үг. Батлая:

```text
ls
```

→ Шинэ **`my-apps`** фолдер жагсаалтад гарсан байх ёстой. ✅ Одоо дотор нь орж, хаана байгаагаа шалга:

```text
cd my-apps
```

```text
pwd
```

→ Замын төгсгөлд `my-apps` бичигдсэн байх ёстой. 🎉 **Чи фолдер үүсгэж, дотор нь орлоо!**

> 💡 **Ажигла:** Фолдерын нэрэнд **зай бүү тавь** — `my-apps` эсвэл `myApps` гэж бич, `my apps` биш. Терминал зайг өөрөөр ойлгодог.

</details>

> 🏁 Зөвхөн терминалаар дараах даалгаврыг **дарааллаар нь** гүйцэтгэ. Курсороо хулганаар бүү хөдөлгө — **зөвхөн команд!**

| Үе   | Даалгавар                                                 | Команд (гацвал нээ)              |
| ---- | --------------------------------------------------------- | -------------------------------- |
| 🥊 1 | Гэр рүүгээ буц                                            | <details><summary>💬</summary>`cd`</details> |
| 🥊 2 | Desktop руу ор                                            | <details><summary>💬</summary>`cd Desktop`</details> |
| 🥊 3 | `treasure` нэртэй фолдер үүсгэ                             | <details><summary>💬</summary>`mkdir treasure`</details> |

| 🥊 5 | `gold` руу ор, **хаана** байгаагаа `pwd`-ээр баталгаажуул | <details><summary>💬</summary>`cd gold` → `pwd`</details> |

> 🏆 5/5 гүйцэтгэсэн хос → 🧭 **Terminal Navigator** цол!
