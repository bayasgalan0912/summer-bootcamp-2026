# 🛠️ ХЭСЭГ 4 — Анхны Expo төслөө үүсгэх · ⏱️ ~20 мин

> 🎯 **Зорилго:** ХЭСЭГ 3-ын командуудаа **хэрэглэж** зөв газраа очих → `create-expo-app`-аар жинхэнэ апп-ын араг ясыг үүсгэх → Antigravity-д нээж бүтцийг нь ойлгох.

🛠️ Хэрэгсэл: **Терминал** · **npx** (Node.js-тэй хамт суусан)

> 🛡️ **ГОЛ ДҮРЭМ:** Нэг команд → Enter → үр дүнгээ **уншаад** ойлго → дараагийнх. Заримыг нь хүлээх хэрэгтэй болно — **бүү сандар.**

---

<details open>
<summary>📂 <b>Дасгал 4.1 — Зөв газраа очих</b> · ⏱️ ~3 мин</summary>

Апп-аа ХЭСЭГ 3-т үүсгэсэн `my-apps` фолдерт хийе. Тийш очицгооё:

```text
cd
```

```text
cd Desktop
```

```text
cd my-apps
```

**Батал:**

```text
pwd
```

→ Замын төгсгөлд `my-apps` гарвал зөв газартаа байна. ✅

> 💡 **Ажигла:** Хэрэв `my-apps` олдохгүй бол ("no such file or directory") — өмнөх хэсэгт үүсгээгүй байна. Зүгээр л `mkdir my-apps` бичээд дахин `cd my-apps` хий.

</details>

<details>
<summary>✨ <b>Дасгал 4.2 — Төслөө үүсгэх команд</b> · ⏱️ ~8 мин</summary>

> 🖼️ _(зураг: `../images/` — create-expo-app ажиллаж байгаа терминал)_

Одоо **нэг команд** бичээд Expo апп-ын бүх файлыг автоматаар үүсгэнэ:

```text
npx create-expo-app@latest my-first-app
```

**Enter** дар. Одоо:

- ⏳ Асуулт гарвал (жишээ: "Ok to proceed?") → **`y`** бичээд Enter.
- ⏳ Терминал олон мөр текст урсгана — интернэтээс файл татаж байна. **1–3 минут** хүлээ.
- 🟢 Төгсгөлд нь **"Your project is ready!"** гэх мэт ногоон мессеж гарвал болсон!

> ⚠️ **Ажигла — бүү зогсоо:** Урсаж байгаа текст удаан ч, зогссон ч харагдвал энэ **хэвийн.** `Ctrl + C` бүү дар. Хүлээх нь ажлын нэг хэсэг.

<details>
<summary>🆘 <b>"command not found: npx" гэвэл?</b></summary>

Node.js суугаагүй эсвэл Antigravity дахин нээгдээгүй байна.

→ ХЭСЭГ 2.2 руу буц, `node -v` шалга. Node.js суулгасны дараа **Antigravity-гаа бүрэн хааж дахин нээх**-ээ мартав уу? Дахин нээгээд, `cd`-ээр `my-apps` руугаа буцаж очоод командаа дахин бич.

</details>

<details>
<summary>💬 <code>npx</code>, <code>@latest</code> гэж юу вэ?</summary>

- **`npx`** — програмыг суулгалгүйгээр **шууд ажиллуулах** команд.
- **`create-expo-app`** — Expo апп-ын бэлэн загварыг татаж өгдөг хэрэгсэл.
- **`@latest`** — "хамгийн сүүлийн хувилбарыг ашигла" гэсэн үг.
- **`my-first-app`** — үүсэх фолдер / апп-ын **нэр**. Дуртайгаа өг (зайгүй!).

</details>

</details>

<details>
<summary>📁 <b>Дасгал 4.3 — Төслөө нээж, бүтцийг нь харах</b> · ⏱️ ~6 мин</summary>

Апп үүслээ. Одоо түүн рүү орж, дотор нь юу байгааг харцгаая:

```text
cd my-first-app
```

```text
ls
```

→ Олон файл, фолдер гарна. Гол хэдийг нь таньж ав:

| Файл / фолдер      | Юу вэ                                                     |
| ------------------ | -------------------------------------------------------- |
| 📁 `app/`          | **Апп-ын дэлгэцүүд** энд байна — чи гол төлөв энд ажиллана |
| 📄 `package.json`  | Төслийн "паспорт" — нэр, ашигласан багцууд                |
| 📁 `assets/`       | Зураг, icon зэрэг файлууд                                 |
| 📁 `node_modules/` | Автоматаар суусан багцууд (**бүү гар хүр**)               |

**Antigravity-д нээе:** дээд цэсээр **File → Open Folder** → `my-first-app` фолдероо сонго. Зүүн талд файлын мод гарч ирнэ. 🎉

> 💡 **Ажигла:** Terminal (команд) болон Editor (файлын мод) хоёр **ижил төслийг** харж байна — нэг нь командаар, нэг нь нүдээр. Энэ бол IDE-ийн гоо сайхан.

</details>
