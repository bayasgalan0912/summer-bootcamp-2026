## 2. Гоё болгох — CSS

`<style>` дотор нэм:

```css
body {
  background: linear-gradient(pink, skyblue); /* 2 өнгө холилдоно */
}
img {
  border-radius: 50%; /* дугуй зураг */
  border: 5px solid white; /* хүрээ */
  box-shadow: 0 4px 12px gray; /* сүүдэр */
}
h1 {
  text-shadow: 2px 2px 0 yellow; /* текстийн сүүдэр */
}
```
