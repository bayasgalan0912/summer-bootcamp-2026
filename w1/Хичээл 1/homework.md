## 1. Хуудсаа дахин бич

Ангид хийсэн хуудсаа **хуулахгүйгээр**, өөрөө бичиж үз. Мартсан бол [readme](readme.md)-ээс хар.

Заавал байх зүйлс: `h1` нэр · `img` зураг · `p` мэдээлэл · `h2` хоёр асуулт · `iframe` YouTube · `<style>` өнгө

---

## 2. Гоё болгох — шинэ таг

| Таг                              | Юу хийдэг          |
| -------------------------------- | ------------------ |
| `<b>тод</b>`                     | **Тод** үсэг       |
| `<i>налуу</i>`                   | _Налуу_ үсэг       |
| `<mark>тодруулга</mark>`         | Шар тодруулга      |
| `<hr />`                         | Хэвтээ зураас      |
| `<ul><li>...</li></ul>`          | Цэгтэй жагсаалт    |
| `<a href="https://...">Линк</a>` | Дарахад өөр хуудас |
| `<button>Дар!</button>`          | Товч               |

```html
<p>Би <b>сагс</b> тоглох <mark>маш</mark> дуртай!</p>
<hr />
<h2>Дуртай хоол</h2>
<ul>
  <li>Пицца</li>
  <li>Бууз</li>
</ul>
<a href="https://www.youtube.com">YouTube руу очих</a>
```

## 3. Гоё болгох — шинэ CSS

`<style>` дотор нэм:

```css
body {
  background: linear-gradient(pink, skyblue); /* 2 өнгө холилдоно */
}
img {
  border-radius: 50%; /* дугуй зураг */
  border: 5px solid white; /* хүрээ */
  box-shadow: 0 4px 12px gray; /* сүүдэр */
}
h1 {
  text-shadow: 2px 2px 0 yellow; /* текстийн сүүдэр */
}
button {
  background: #7c3aed;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 10px;
}
button:hover {
  transform: scale(1.1); /* хулгана очиход томорно */
}
```
