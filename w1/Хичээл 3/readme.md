## 🔑 Өнөөдрийн түлхүүр үгс

| Үг | Утга |
|---|---|
| **Auth** | Нэвтрэх систем — хэн болохыг батлах |
| **uid** | Хэрэглэгч бүрийн давтагдашгүй дугаар |
| **Collection** | Хайрцаг (`users`, `chats`) |
| **Document** | Хуудас — нэг бичлэг |
| **onSnapshot** | "Чагнаж суух" — өөрчлөгдөнгүүт шууд мэдэгдэнэ ⭐ |
| **members** | Чатад хэн байгаа — uid-уудын жагсаалт |
| **Rules** | Хэн юу хийж болох дүрэм |
| **Dev build** | Expo Go-д байхгүй модултой апп (Модул 4) |

---

## 🆘 Гацвал

| Асуудал | Шийдэл |
|---|---|
| `Missing or insufficient permissions` | Rules → Publish хийгээгүй, эсвэл нэвтрээгүй байна |
| `auth/invalid-api-key` | `firebaseConfig` буруу хуулагдсан |
| `auth/email-already-in-use` | Тэр и-мэйл бүртгэлтэй → нэвтрэх дэлгэц рүү ор |
| `The query requires an index` | Алдаан доторх **линкийг дар** → Create → 1-2 мин хүлээ |
| Улаан дэлгэц | Улаан текстээ AI-д бүтнээр хуул → _"Энэ алдааг засаад өгөөч"_ |

## 🛡️ Safe

- 📍 **Байршил бол хувийн мэдээлэл.** Зөвхөн гэр бүл, ойрын найздаа.
- 🔴 Хуваалцахаа **зогсоох товч** заавал байх ёстой. Хэрэггүй бол унтраа.
- 🔑 Нууц үгээ хэнд ч бүү хэл. Тестийн и-мэйл ашигла.
- 💬 Чатад жинхэнэ хаяг, утас, сургуулийн нэрээ бүү бич.
