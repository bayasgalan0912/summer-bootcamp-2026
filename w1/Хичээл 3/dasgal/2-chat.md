# 💬 Модул 2 — Чат · ~45 мин

> 🎯 **Групп чат** (гэр бүл, найзууд) + **хувийн чат**. Мессеж шууд ирнэ.

---

## 🔑 Түлхүүр үгс

| Үг | Утга |
|---|---|
| **chat** | Нэг ярианы өрөө |
| **members** | Тэр өрөөнд хэн байгаа — uid-уудын **жагсаалт** |
| **subcollection** | Хайрцаг доторх хайрцаг (`chats/x/messages`) |
| **onSnapshot** | Шинэ мессеж ирэнгүүт **өөрөө** шинэчилнэ ⭐ |
| **array-contains** | "Энэ жагсаалтад миний uid байна уу?" гэсэн хайлт |

---

## 🗂️ Өгөгдлийн бүтэц

```text
chats/{chatId}
  ├─ type         "group" | "direct"
  ├─ name         "Гэр бүл"
  ├─ members      ["uid1", "uid2", "uid3"]     ← жагсаалт
  ├─ lastMessage  "Хаана байгаа юм бэ?"
  └─ lastAt       serverTimestamp()

chats/{chatId}/messages/{msgId}      ← subcollection
  ├─ senderId    "uid1"
  ├─ senderName  "Бат"
  ├─ type        "text"
  ├─ text        "Сайн уу"
  └─ createdAt   serverTimestamp()
```

> 🧠 **Гол санаа:** Групп чат ба хувийн чат бол **ижил бүтэц** — ялгаа нь зөвхөн `members` дотор хэдэн хүн байгаад л байна.

---

## 💬 Промпт 1 — Чатын жагсаалт

```text
"Чат" таб нэм.

- chats цуглуулгаас query(where('members','array-contains', myUid),
  orderBy('lastAt','desc')) ашиглан миний чатуудыг л татна
- onSnapshot ашигла — шинэ мессеж ирэхэд жагсаалт өөрөө шинэчлэгдэнэ
- Мөр бүрд: чатын нэр, сүүлийн мессеж, цаг
- Групп бол 👥, хувийн бол ярилцагчийн эможи/зураг харуул
- Дээд баруун буланд ➕ товч — шинэ чат үүсгэх дэлгэц рүү
```

> ⚠️ Эхлээд **`The query requires an index`** гэсэн алдаа гарна. Алдаан доторх **линкийг дар** → Create index → 1-2 мин хүлээ. Энэ хэвийн!

---

## 💬 Промпт 2 — Шинэ чат үүсгэх

```text
"Шинэ чат" дэлгэц нэм — дээд талд 2 таб: "Групп" ба "Хувийн".

Групп:
- Группын нэр оруулах (жишээ: "Гэр бүл", "Найзууд")
- users цуглуулгаас бүх хэрэглэгчийг жагсааж, checkbox-оор олныг сонгоно
- "Үүсгэх" → chats-д шинэ баримт: type="group", name, members=[миний uid + сонгосон уид-ууд]

Хувийн:
- users цуглуулгаас нэг хүн сонгоно
- Тэр хүнтэй чат аль хэдийн байвал ШИНЭ үүсгэхгүй, байгаа руу нь ор
  (members-д хоёулаа байгаа type="direct" чатыг эхлээд хай)
- Байхгүй бол: type="direct", members=[миний uid, түүний uid], name=түүний нэр
```

---

## 💬 Промпт 3 — Мессеж бичих дэлгэц

```text
Чат дээр дарахад мессежийн дэлгэц нээгдэнэ.

- chats/{chatId}/messages-ийг onSnapshot + orderBy('createdAt','asc')-аар
  ШУУД чагна — шинэ мессеж өөрөө гарч ирнэ
- Миний мессеж баруун талд (өнгөт), бусдынх зүүн талд (саарал)
- Групп чатад бусдын мессежийн дээр илгээгчийн НЭР жижигхэн харагдана
- Доод талд оруулгын талбар + илгээх товч
- Илгээхэд:
  1) messages-д addDoc (senderId, senderName, type:"text", text, createdAt)
  2) эх чатын lastMessage, lastAt-г updateDoc-оор шинэчил
- Шинэ мессеж ирэхэд жагсаалт автоматаар доошоо гүйнэ
- Гар утасны гар (keyboard) талбарыг халхлахгүй байг (KeyboardAvoidingView)
```

## 🆘 Гацвал

| Алдаа | Шийдэл |
|---|---|
| `The query requires an index` | Линкийг дар → Create → хүлээ |
| Чат жагсаалт хоосон | `members`-д өөрийн uid ороогүй |
| Мессеж давхар гарна | `onSnapshot` олон удаа бүртгэгдсэн — цэвэрлэлт (unsubscribe) хийгээгүй |
| Шинэ мессеж өөрөө гарахгүй | `getDocs` ашиглажээ → `onSnapshot` болго |
| Гар бичих талбарыг халхална | `KeyboardAvoidingView` нэм |
