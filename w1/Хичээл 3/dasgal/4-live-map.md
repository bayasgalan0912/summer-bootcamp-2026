# 🗺️ Модул 4 — Амьд газрын зураг · ~40 мин

> 🎯 Бүгд байршлаа хуваалцаж, **нэг газрын зураг дээр** бие биенээ хөдөлж байхад нь харна.

---

## 🚨 ЭХЛЭХИЙН ӨМНӨ УНШ

**`expo-maps` нь Expo Go дээр АЖИЛЛАХГҮЙ.** Тусдаа **development build** (өөрийн апп) хийх шаардлагатай.

```text
Expo Go        ❌  газрын зураг гарахгүй
Dev build      ✅  ажиллана
```

> 👩‍🏫 **Багшид:** Build 10–20 минут ордог. **Хичээлээс өмнө** нэг удаа хийж, APK-г бэлэн болгоод анги дээр тараавал цаг хэмнэнэ. Мөн **Google Maps API key**-г урьдчилан үүсгэж, сурагчдад өгөх нь зүйтэй.
>
> ⏱️ **Цаг хүрэхгүй бол:** Модул 4-ийг алгасаад, Модул 3-ын Google Maps линкийг л ашиглаж болно. Апп бүрэн ажиллана.

---

## 🔑 Түлхүүр үгс

| Үг | Утга |
|---|---|
| **Dev build** | Expo Go биш, өөрийн суулгасан апп |
| **EAS** | Expo-ийн build хийдэг үүлэн үйлчилгээ |
| **API key** | Google Maps-ыг ашиглах зөвшөөрлийн түлхүүр (Android) |
| **watchPosition** | Байршлыг **тасралтгүй** хянах |
| **Marker** | Газрын зураг дээрх тэмдэглэгээ |

## 1️⃣ Багц суулгах

```bash
npx expo install expo-maps expo-location expo-dev-client
```

---

## 2️⃣ Google Maps API key (зөвхөн Android)

Firebase төсөл чинь **аль хэдийн Google Cloud төсөл** — тэрийгээ ашиглана.

```text
console.cloud.google.com → дээд талд oirkhon төслөө сонго
APIs & Services → Library → "Maps SDK for Android" → Enable
APIs & Services → Credentials → Create credentials → API key → хуулж ав
```

`app.json` дотор:

```json
{
  "expo": {
    "android": {
      "config": { "googleMaps": { "apiKey": "AIzaSy...ЧИНИЙ_KEY" } }
    }
  }
}
```

> 🍎 **iOS-д key хэрэггүй** — Apple Maps-ыг ашиглана.

---

## 3️⃣ Dev build хийх

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build --profile development --platform android
```

→ Build дуусахад **линк / QR** өгнө → утсандаа суулга.

Дараа нь ажиллуулахдаа:

```bash
npx expo start --dev-client
```

> ⏳ Build 10–20 мин. Хүлээж байхдаа Модул 1–3-аа сайжруул.

---

## 🗂️ Өгөгдлийн бүтэц

```text
locations/{uid}          ← нэг хүнд НЭГ баримт (хуучин нь дарагдана)
  ├─ name       "Бат"
  ├─ emoji      "🐯"
  ├─ lat        47.9184
  ├─ lng        106.9177
  ├─ sharing    true          ← унтраахад false
  └─ updatedAt  serverTimestamp()
```

> 🧠 Баримтын **id нь uid** — тиймээс шинэ байршил бүр хуучныг **дарж бичнэ.** 1000 баримт хуримтлагдахгүй.

## 💬 Промпт 1 — Байршлаа хуваалцах

```text
"Газрын зураг" таб нэм. Эхлээд хуваалцах хэсгийг хий.

- Дэлгэцийн дээд талд том switch: "Байршлаа хуваалцах"
- Асаахад:
  - expo-location-оос зөвшөөрөл асууна
  - watchPositionAsync-аар байршлыг тасралтгүй хянана
    (timeInterval: 5000, distanceInterval: 10)
  - өөрчлөгдөх бүрд setDoc(doc(db,'locations',myUid), {...}) -оор
    name, emoji, lat, lng, sharing: true, updatedAt-г бичнэ
- Унтраахад: хяналтыг зогсоож (remove), sharing: false болгоно
- Дэлгэцээс гарахад ч хяналтыг заавал зогсооно (цэвэрлэлт)
- Switch-ийн доор жижгээр "Сүүлд шинэчилсэн: 14:32" гэж харуул
```

> 🔋 **Батерей:** Байнга GPS ажиллуулах нь батерей идэнэ. Тиймээс **унтраах товч заавал** байх ёстой.

---

## 💬 Промпт 2 — Бүгдийг нэг map дээр

```text
Тэр таб дээр expo-maps ашиглан газрын зураг харуул.

- expo-maps-ийн GoogleMaps.View (Android), AppleMaps.View (iOS)
  ашигла. Platform-оор нь салга.
- locations цуглуулгыг onSnapshot-оор чагна — хэн нэгэн хөдлөхөд
  тэмдэглэгээ нь ӨӨРӨӨ шилжинэ
- sharing: true байгаа хүмүүсийг л харуул
- Marker бүр дээр: тухайн хүний нэр
- Marker дээр дарахад доороос жижиг цонх гарч: нэр, эможи,
  "Сүүлд шинэчилсэн: 14:32", "💬 Чат руу" товч
- Дэлгэц нээгдэхэд бүх хүн багтахаар zoom тохируул
- Өөрийн байршлыг өөр өнгөөр ялгаж харуул
```

## 🆘 Гацвал

| Асуудал | Шийдэл |
|---|---|
| Газрын зураг **саарал/хоосон** | Android API key байхгүй эсвэл `Maps SDK for Android` идэвхжээгүй |
| Expo Go дээр улаан алдаа | expo-maps Expo Go-д ажиллахгүй → dev build ашигла |
| `eas build` алдаа | `eas login` хийсэн эсэх, `app.json` дотор JSON зөв бичигдсэн эсэхийг шалга |
| Тэмдэглэгээ хөдлөхгүй | `getCurrentPosition` ашиглажээ → `watchPositionAsync` болго |
| Апп хаахад хуваалцсаар байна | Дэлгэцээс гарахад цэвэрлэлт (remove + sharing:false) хийгээгүй |
| Байршил маш ойрхон биш газар харуулна | Дотор GPS сул. Гадаа турш |
