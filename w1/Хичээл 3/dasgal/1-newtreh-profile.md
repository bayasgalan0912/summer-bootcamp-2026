# 🔑 Модул 1 — Нэвтрэх + Профайл · ~35 мин

> 🎯 Бүртгүүлэх · нэвтрэх · гарах + өөрийн **зураг, нэр** хадгалах.

---

## 🔑 Түлхүүр үгс

| Үг | Утга |
|---|---|
| **Sign up** | Шинээр бүртгүүлэх |
| **Sign in** | Нэвтрэх |
| **uid** | Хэрэглэгчийн давтагдашгүй дугаар — Firebase өөрөө өгнө |
| **users/{uid}** | Профайл хадгалах хаяг |
| **onAuthStateChanged** | "Нэвтэрсэн үү?" гэдгийг байнга чагнадаг |

---

## 🗂️ Өгөгдлийн бүтэц

```text
users/{uid}
  ├─ name       "Бат"
  ├─ emoji      "🐯"
  ├─ photo      "data:image/jpeg;base64,..."   (сонголт)
  └─ createdAt  serverTimestamp()
```

---

## 💬 Промпт 1 — Нэвтрэх дэлгэц

```text
Firebase Auth ашиглан нэвтрэх систем нэм.

- Нэвтрээгүй бол: "Нэвтрэх" дэлгэц харагдана
  (и-мэйл, нууц үг + "Нэвтрэх" товч + "Бүртгүүлэх" рүү шилжих холбоос)
- Бүртгүүлэх дэлгэц: и-мэйл, нууц үг, нэр
  → createUserWithEmailAndPassword
  → дараа нь users/{uid} баримт үүсгэж name, createdAt хадгална
- Нэвтэрсэн бол: аппын үндсэн таб-ууд руу шууд орно
- onAuthStateChanged ашиглан төлөвийг чагна
- Алдааг МОНГОЛООР ойлгомжтой харуул:
  "Нууц үг дор хаяж 6 тэмдэгт байх ёстой", "Энэ и-мэйл бүртгэлтэй байна"
- Апп хаагаад дахин нээхэд нэвтэрсэн хэвээр байна
```

> ✅ **Шалга:** Аппаа бүрэн хааж дахин нээ → нэвтрэх дэлгэц **гарч ирэх ёсгүй.**

## 💬 Промпт 2 — Профайл

```text
"Профайл" таб нэм.

- users/{uid} баримтаас нэр, эможи-г уншиж харуул
- Дээд талд том дугуй аватар — дотор нь сонгосон эможи
- "Нэр солих" — оруулгын талбар + Хадгалах товч → updateDoc
- Эможи сонгох мөр: 🐯 🐼 🦊 🐨 🐸 🐵 🐧 🦁 — дарахад солигдож хадгалагдана
- Доод талд улаан "Гарах" товч → signOut
```

---

## 💬 Промпт 3 — Профайл зураг

```bash
npx expo install expo-image-picker
```

```text
Профайлд зураг нэмэх боломж нэм.

- Аватар дээр дарахад галерейгаас зураг сонгоно (expo-image-picker)
- ЧУХАЛ: зургийг base64 болгож users/{uid} баримтын photo талбарт хадгал.
  Firebase Storage БҮҮ ашигла.
- Зургийг жижигрүүл: allowsEditing: true, aspect: [1,1], quality: 0.3,
  base64: true — файл 200KB-аас бага байх ёстой
- photo байвал аватарт зургийг, байхгүй бол эможи-г харуул
```

> ⚠️ **Яагаад base64?** Firebase Storage шинэ төслүүд дээр **төлбөртэй план** шаарддаг. Firestore-т жижиг зураг хадгалбал үнэгүй ажиллана.
> 📏 Нэг баримтын хязгаар **1MB** — тиймээс `quality: 0.3` заавал.

## 🆘 Гацвал

| Алдаа | Шийдэл |
|---|---|
| `auth/operation-not-allowed` | Console → Authentication → Email/Password **Enable** хийгээгүй |
| `auth/weak-password` | Нууц үг 6+ тэмдэгт |
| Апп хаахад гарчихдаг | AsyncStorage persistence тохироогүй → AI-д: _"auth persistence-ийг AsyncStorage-аар тохируулаад өгөөч"_ |
| Зураг хадгалахад алдаа | Зураг хэт том. `quality: 0.3`, `allowsEditing: true` эсэхийг шалга |
