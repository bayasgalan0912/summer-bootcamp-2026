# 📍 Модул 3 — Чатанд байршил илгээх · ~25 мин

> 🎯 Чатанд **📍 товч** → байршлаа илгээнэ → дарахад **Google Maps** нээгдэнэ.

---

## 🔑 Түлхүүр үгс

| Үг | Утга |
|---|---|
| **GPS** | Хиймэл дагуулаар байрлал олох |
| **latitude / longitude** | Өргөрөг / уртраг — газрын хоёр тоо |
| **permission** | Зөвшөөрөл — хэрэглэгч "за" гэж хэлэх ёстой |
| **Linking** | Аппаас гадагш линк нээх |

---

## 📦 Суулгах

```bash
npx expo install expo-location
```

---

## 🗂️ Шинэ мессежийн төрөл

```text
messages/{msgId}
  ├─ type       "location"      ← "text" биш!
  ├─ lat        47.9184
  ├─ lng        106.9177
  ├─ senderName "Бат"
  └─ createdAt  serverTimestamp()
```

> 🧠 Нэг талбар (`type`) нэмээд л мессеж **хоёр өөр байдлаар** харагддаг болж байна.

---

## 💬 Промпт 1 — Байршил илгээх

```text
Чатын доод талд илгээх товчны хажууд 📍 товч нэм.

- Дарахад expo-location-оос зөвшөөрөл асууна
  (requestForegroundPermissionsAsync)
- Зөвшөөрвөл getCurrentPositionAsync-аар одоогийн байршлыг авна
- messages-д шинэ баримт нэм:
  type: "location", lat, lng, senderId, senderName, createdAt
- Эх чатын lastMessage-г "📍 Байршил" болго
- Зөвшөөрөл өгөөгүй бол: "Байршлын зөвшөөрөл хэрэгтэй" гэсэн
  ойлгомжтой мессеж харуул
```

---

## 💬 Промпт 2 — Google Maps руу үсрэх

```text
type: "location" мессежийг тусгай картаар харуул:

- Карт дээр: 📍 emoji, "Байршил" гэсэн бичиг, доор нь координат жижгээр
- Карт дээр ДАРАХАД Google Maps нээгдэнэ.
  React Native-ийн Linking.openURL ашиглаж дараах линк рүү ор:
  https://www.google.com/maps/search/?api=1&query=LAT,LNG
  (LAT, LNG-г тухайн мессежийн утгуудаар сольж бич)
- Карт нь ердийн мессежээс өөр өнгөтэй, ялгарч харагдана
```

---

## 🆘 Гацвал

| Асуудал | Шийдэл |
|---|---|
| Байршил `null` буцаана | Симулятор дээр GPS байхгүй → **жинхэнэ утсаар** турш |
| Зөвшөөрөл асуухгүй | Утасны Тохиргоо → Апп → Байршил → гараар зөвшөөр |
| Google Maps нээгдэхгүй | Линкийн формат буруу. `?api=1&query=47.91,106.91` эсэхийг шалга |
| Байршил маш удаан ирнэ | Гадаа / цонхны дэргэд турш. Эсвэл `accuracy: Balanced` болго |
