# Апп 3 — Flappy Bird + Leaderboard

> **Түвшин:** Дунд-ахисан · **Хугацаа:** 3 хичээл (~4.5 цаг) · **Database:** Supabase

---

## Зорилго

- Тоглоомын мөчлөг (game loop) гэж юу вэ
- Таталцал, хурд, хурдатгал — энгийн физик
- Мөргөлдөөн шалгах (collision detection)
- Дэлгэцийн төлөв (эхлэх / тоглох / дуусах)
- Утсанд хадгалах (AsyncStorage) vs серверт хадгалах (Supabase) — ялгаа
- Leaderboard буюу эрэмбэлсэн жагсаалт

---

## Supabase бэлтгэл

SQL Editor дээр:

```sql
create table flappy_scores (
  id uuid primary key default gen_random_uuid(),
  player_name text not null,
  score int not null,
  created_at timestamptz default now()
);

alter table flappy_scores enable row level security;

create policy "anyone can read" on flappy_scores
  for select using (true);

create policy "anyone can insert" on flappy_scores
  for insert with check (true);

-- Хурдан эрэмбэлэхийн тулд index
create index flappy_scores_score_idx on flappy_scores (score desc);
```

> **Заах цэг:** Index гэж юу вэ? Номын сангийн каталог гэж зүйрлэ — 10,000 ном дундаас нэгийг олоход бүх номыг харах уу, эсвэл цагаан толгойн жагсаалтаас харах уу?

## Алхам 1 — Суурь тоглоом

### Prompt 1

```
Expo React Native дээр Flappy Bird маягийн тоглоом хий.

- Дэлгэцийн зүүн талд жижиг дүрс (шувуу) байна.
- Дэлгэц дарах бүрд шувуу дээшээ үсэрч, дараа нь таталцлаар доошоо унана.
- Баруун талаас хоолой (дээд + доод хэсэг, дунд нь нүхтэй) тогтмол хурдаар
  зүүн тийш хөдөлнө. Нүхний өндөр санамсаргүй байна.
- Хоолой давах бүрд оноо +1.
- Шувуу хоолойд эсвэл дэлгэцийн дээд/доод ирмэгт хүрвэл тоглоом дуусна.
- Оноог дэлгэцийн дээд хэсэгт том үсгээр харуул.

Кодыг тодорхой хэсгүүдэд хуваа:
1) физик (шувууны байрлал, хурд)
2) хоолой үүсгэгч ба хөдөлгөгч
3) мөргөлдөөн шалгах функц
4) дэлгэц зурах хэсэг

Тогтмолуудыг (таталцал, үсрэх хүч, хоолойн хурд, нүхний хэмжээ)
файлын дээд хэсэгт тусад нь бич, тохируулахад хялбар байг.
```

**Шалгах:** Шувуу унаж байна уу? Дарахад үсэрч байна уу? Хоолой ирж байна уу?

> **Багшид:** Эхний удаад тоглоом бараг заавал хэт хэцүү эсвэл хэт амархан гардаг. Энэ бол **онц сайхан хичээл** — тогтмолуудыг өөрчилж, тоглоомын мэдрэмжийг хэрхэн тохируулахыг үзүүл. Хүүхэд бүр өөрийн "хэцүү байдал"-ыг олтол 15 минут өг.

## Ярилцах сэдэв (заавал орох)

**"Оноог утсанд хадгалах уу, серверт хадгалах уу?"**

Сурагчдаас асуу:

1. Утсандаа хадгалсан оноог найз чинь харж чадах уу? (Үгүй)
2. Утсаа солиход оноо чинь яах вэ? (Алдагдана)
3. Тэгвэл яагаад бид AsyncStorage-г бас ашиглаж байна вэ? (Интернэтгүй үед ажиллана, хурдан)

Хариулт: **хоёуланг нь ашигладаг**. Дотоод нь хурдан, сервер нь хуваалцах боломжтой. Бодит апп бүр ингэж хийдэг.

**"Хэн нэгэн хуурч оноогоо 999999 болгож болох уу?"**

Болно — учир нь бид оноог утсанд тооцоод серверт зүгээр илгээж байна. Бодит тоглоомууд серверт нь дахин шалгадаг. Энэ бол хамгаалалт (security) гэдэг сэдвийн эхлэл.

## Түгээмэл алдаа

| Алдаа | Шийдэл |
|---|---|
| Тоглоом маш удаан / гацна | `setInterval` олон удаа үүссэн. Цэвэрлэх (`clearInterval`) хийгээгүй |
| Шувуу мөргөөгүй ч дуусна | Мөргөлдөөний хайрцаг хэт том. Дүрсээс жижиг тавь |
| Оноо 2 удаа нэмэгдэнэ | Нэг хоолой давахад дахин тоолж байна. Хоолой бүрд `passed` тэмдэг тавь |
| Утас болгон дээр өөр хурдтай | Хугацаанаас (delta time) хамааруулж тооцоолоогүй |
| Топ 10 хоосон | RLS policy, эсвэл `.env` дахин ачаалагдаагүй |
