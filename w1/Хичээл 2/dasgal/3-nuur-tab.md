# 🏠 ХЭСЭГ 3 — Нүүр таб (өөрийнхөө тухай) · ⏱️ ~18 мин

> 🎯 **Зорилго:** Нүүр табаа зураг, нэр, сонирхлын **chip**-үүдээр дүүргэж, апп-ыг **өөрийнхөө** апп болгох.

🛠️ Хэрэгсэл: **AI panel** · өөрийн зураг (сонголт)

> 🔗 **Өмнөх хэсэгт** 3 таб гаргасан. **Одоо** эхний табаа дүүргэнэ.

---

<details open>
<summary>🧠 <b>Дасгал 3.1 — Компонент = апп барих тоосго</b> · ⏱️ ~3 мин</summary>

> 🖼️ _(зураг: `../images/` — карт, товч, текст, chip компонентууд)_

Апп бол LEGO шиг — жижиг **тоосго**-нуудаас бүрдэнэ. Тэр тоосго бүрийг **компонент** гэнэ:

| Компонент      | Юу вэ                       |
| -------------- | --------------------------- |
| 🔤 **Текст**   | Гарчиг, тайлбар             |
| 🖼️ **Зураг**   | Профайл зураг, лого         |
| 🔘 **Товч**    | Дарж болох зүйл             |
| 🏷️ **Chip**    | Булан дугуй жижиг шошго     |
| 🃏 **Карт**    | Хэд хэдэн зүйлийг багласан хайрцаг |

> 💡 **Ажигла:** Промптдоо эдгээр **нэрийг** ашиглавал AI яг юу хүсэж байгааг чинь ойлгоно. "Chip хий" гэвэл AI chip гаргана.

</details>

---

<details>
<summary>💬 <b>Дасгал 3.2 — Промпт 2: Нүүр табаа дүүргэх</b> · ⏱️ ~9 мин · ⭐ гол дасгал</summary>

AI panel-д:

```text
Нүүр таб дээр:
- дээд талд дугуй хэлбэрийн профайл зураг (одоохондоо placeholder зураг)
- доор нь миний нэр том цагаан үсгээр
- түүний доор ангийн нэр жижиг саарал үсгээр
- хамгийн доор миний 3 сонирхлыг chip хэлбэрээр (жишээ: "хөгжим",
  "сагс", "код"). Chip бүр өөр өнгөтэй, булан нь дугуйрсан байг.
```

Утсан дээрээ шалгаад, дараа нь **өөрийнхөөрөө** солино 👇

> ✍️ **Даалгавар:** Промпт доторх нэр, анги, 3 сонирхлыг **өөрийнхөөрөө** солино. Апп чинь одоо чиний тухай боллоо! 🎉

<details>
<summary>🖼️ Өөрийн зургаа нэмэх (сонголт)</summary>

1. Зургаа төслийн `assets/` фолдер руу хий (Antigravity-д чирж оруулж болно).
2. AI-д хэл: _"Профайл зургийг assets доторх [зургийн нэр].png болгож солиод өгөөч."_

> 🛡️ Зөвхөн **өөрийн** зургаа тавь. Бусдын зургийг зөвшөөрөлгүй бүү ашигла.

</details>

</details>

<details>
<summary>✅ <b>Дасгал 3.3 — Шалгах</b> · ⏱️ ~3 мин</summary>

Утсан дээрээ Нүүр табаа хараад:

- [ ] Дугуй профайл зураг гарч байна
- [ ] **Өөрийн** нэр том үсгээр
- [ ] Анги жижиг саарал үсгээр
- [ ] 3 chip, тус бүр **өөр өнгөтэй**

> 🛡️ **Сана:** Апп-даа жинхэнэ хаяг, утасны дугаар, сургуулийн бүтэн нэрээ **бүү бич** — зөвхөн нэр хангалттай. (Дараа нь найзууддаа үзүүлнэ шүү дээ!)

</details>
