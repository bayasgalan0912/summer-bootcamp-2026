# Апп 1 — Гурван табтай апп (Нүүр / Тоглоом / Тухай)

> **Түвшин:** Эхлэгч · **Хугацаа:** 2 хичээл (нийт ~3 цаг) · **Database:** Хэрэггүй

---

## Зорилго

Сурагч энэ аппыг хийж дуусахад дараах зүйлийг ойлгоно:

- Expo Go-гоор өөрийн утсан дээр апп ажиллуулах
- Апп нь "дэлгэц"-ээс бүрддэг, дэлгэц хооронд шилждэг
- Компонент гэж юу вэ (карт, товч, текст)
- State буюу "санаж байгаа утга" гэж юу вэ
- AI-д өгөх prompt-ыг хэрхэн тодорхой бичих

---

## Урьдчилсан бэлтгэл (багш)

| Юу                      | Тайлбар                                        |
| ----------------------- | ---------------------------------------------- |
| Node.js суулгасан байх  | Хамгийн сүүлийн LTS хувилбар                   |
| Утсанд **Expo Go** апп  | App Store / Google Play-с үнэгүй               |
| Wi-Fi нэг сүлжээ        | Компьютер, утас хоёр нэг Wi-Fi дээр байх ёстой |
| Antigravity эсвэл Codex | Сурагч бүрд нэвтэрсэн эрх                      |

**Хичээл эхлэхийн өмнө шалгах:** багш өөрөө нэг удаа шинэ апп үүсгээд утсандаа ажиллуулж үзсэн байх. Wi-Fi асуудал хамгийн их цаг иддэг.

---

## Алхам 1 — Төсөл үүсгэх

Терминал дээр:

```bash
npx create-expo-app@latest my-first-app
cd my-first-app
npx expo start
```

Терминал дээр QR код гарч ирнэ. Утасныхаа камерыг (iPhone) эсвэл Expo Go доторх сканнерыг (Android) чиглүүлээд аппаа нээнэ.

> **Багшид:** Энэ мөч л бүх хичээлийн хамгийн чухал нь. Хүүхэд өөрийн утсан дээр "миний апп" ажиллаж байгааг харах хүртэл сонирхол нь бүрэн нээгдэхгүй. Энд 20-30 минут зарцуулахаас бүү ай.

---

## Алхам 2 — Prompt-ууд

Дараах prompt-уудыг **дараалуулж** өгнө. Нэг дор бүгдийг нь бус, нэгийг нь хийж дуусаад дараагийнх руу шилждэг.

### Prompt 1 — Суурь бүтэц

```
Expo React Native дээр доод талд 3 таб байна: Нүүр, Тоглоом, Тухай.
Expo Router ашигла. Таб бүр дээр одоохондоо зөвхөн гарчиг харуулаад бай.

Өнгө:
- дэвсгэр #1a1a2e
- үсэг цагаан
- идэвхтэй таб алтлаг шар #ffd700

Таб бүрд тохирох icon ашигла.
```

**Шалгах:** Утсан дээр 3 таб гарч ирсэн үү? Дарахад солигдож байна уу?

---

### Prompt 2 — Нүүр таб

```
Нүүр таб дээр:
- дээд талд миний зураг дугуй хэлбэрээр (одоохондоо ямар нэг placeholder зураг)
- доор нь миний нэр том үсгээр
- түүний доор ангийн дугаар жижиг саарал үсгээр
- хамгийн доор "Миний тухай" гэсэн гарчигтай 3 ширхэг жижиг тэмдэглэгээ (chip),
  жишээ нь: "хөгжим", "сагсан бөмбөг", "код бичих"

Chip бүр өөр өнгөтэй, булан нь дугуйрсан байг.
```

**Сурагчийн даалгавар:** Өөрийнхөө нэр, сонирхлоор солих. Зургаа солих (`assets` хавтас руу зургаа хийгээд замыг нь заана).

---

### Prompt 3 — Тоглоом таб (Азын бөмбөг)

```
Тоглоом таб дээр:
- дэлгэцийн голд том дугуй товч, дотор нь "АСУУ" гэсэн бичиг
- дарах бүрд доорх жагсаалтаас санамсаргүй нэг хариулт сонгож,
  товчны доор том үсгээр харуулна
- товч дарагдахдаа бага зэрэг жижгэрч, буцаад томрох анимацитай байг

Хариултууд:
"Тийм ээ!", "Огт үгүй", "Дараа асуу", "Магадгүй", "Гарцаагүй",
"Битгий найд", "Бүх зүйл сайхан болно", "Одоо биш"
```

**Энд заах ойлголт:** `useState` — "апп ямар нэг зүйлийг санаж байх" гэдэг нь энэ. Хариулт солигдоход дэлгэц өөрөө шинэчлэгддэгийг харуул.

---

### Prompt 4 — Тухай таб

```
Тухай таб дээр:
- аппын нэр, хийсэн хүний нэр, огноо
- "Ашигласан багаж" гэсэн жагсаалт: Expo, React Native, AI
- хамгийн доор "Найздаа илгээх" товч. Дарахад утасны share цонх нээгдэж,
  аппын тухай богино текст илгээнэ (expo-sharing эсвэл React Native Share ашигла)
```

## Түгээмэл алдаа ба шийдэл

| Алдаа                                    | Шалтгаан                       | Шийдэл                                               |
| ---------------------------------------- | ------------------------------ | ---------------------------------------------------- |
| QR уншсан ч апп нээгдэхгүй               | Утас, компьютер өөр Wi-Fi дээр | Нэг Wi-Fi-д холбох, эсвэл `npx expo start --tunnel`  |
| Улаан дэлгэц, "Unable to resolve module" | Package суулгаагүй             | AI-д error-г бүтнээр нь хуулж өгөөд "энийг зась" гэх |
| Таб icon гарахгүй                        | Icon library суулгаагүй        | `npx expo install @expo/vector-icons`                |
| Өөрчлөлт харагдахгүй                     | Cache                          | Терминал дээр `r` дарж дахин ачаалах                 |

---

## Хичээлийн төгсгөлд шалгах жагсаалт

- [ ] 3 таб ажиллаж байна
- [ ] Нүүр дээр өөрийн нэр, зураг байна
- [ ] Тоглоом таб дээр товч дарахад хариулт солигдоно
- [ ] Тухай таб бөглөгдсөн
- [ ] Апп утсан дээр ажиллаж байна
- [ ] Найздаа QR уншуулж харуулсан

---

## Нэмэлт даалгавар (хурдан дуусгасан сурагчдад)

1. Тоглоом таб дээр хариулт бүрд өөр өөр өнгө оноож үз
2. Товч дарах бүрд утас чичрэх (`expo-haptics`)
3. Дөрөв дэх таб нэмээд "Тохиргоо" гэж нэрлэ, дотор нь харанхуй/цайвар горим сонголт тавь
4. Нүүр таб дээрх chip-үүдийг дарахад тайлбар гарч ирдэг болго

---

## Дараагийн алхам

Энэ аппыг **бүү устга**. Дараагийн хичээл дээр Тоглоом таб руу монгол шагайн тоглоом суулгах тул энэ нь бүрхүүл болж үлдэнэ.
