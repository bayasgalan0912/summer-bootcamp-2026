# Апп 2 — Шагай: Дөрвөн бэрх

> **Түвшин:** Дунд · **Хугацаа:** 3-4 хичээл (~6 цаг) · **Database:** Supabase

---

## Зорилго

- Санамсаргүй тоо (random) ба тоглоомын логик
- Анимаци (Animated / Reanimated)
- Утасны мэдрэгч (accelerometer) ашиглах
- **Supabase-тэй анх танилцах** — хүснэгт, мөр, багана
- Өгөгдөл хадгалах, буцааж унших, эрэмбэлэх
- Монгол өв соёлыг технологитой холбох

## Тоглоомын дүрэм (сурагчдад тайлбарлах)

Дөрвөн шагайг зэрэг шиднэ. Шагай бүр дөрвөн талын аль нэг дээр буудаг:

| Тал | Эможи | Оноо |
|---|---|---|
| Морь | 🐎 | 4 |
| Тэмээ | 🐫 | 3 |
| Хонь | 🐑 | 2 |
| Ямаа | 🐐 | 1 |

**Дөрвөн бэрх** — дөрвөн шагай дөрвүүлээ өөр өөр тал дээр буухыг хэлнэ (морь, тэмээ, хонь, ямаа тус бүр нэг). Энэ бол ховор, азтай шидэлт. Апп дээр оноог 2 дахин нэмэгдүүлж, тусгай анимаци тоглуулна.

### Бэлгэдлийн тайлбар

- 🐎 **Морь** — хурд, хийморь, урагшлах эрч
- 🐫 **Тэмээ** — тэвчээр, бат бөх, эд хөрөнгө
- 🐑 **Хонь** — өнөр өтгөн, хишиг буян
- 🐐 **Ямаа** — идэвх, авхаалж, өсөлт

> **Багшид анхаарах:** Шагайн бэлгэдлийн тайлбар нутаг нутгаар бага зэрэг ялгаатай байдаг. Хичээл эхлэхийн өмнө нэг эх сурвалж (номын сан, ахмад настан, орон нутгийн музей) дээр тулгуурлаж жигдэлж авбал сайн.
>
> **Санал:** Үүнийг өөрөө гэрийн даалгавар болго — "гэрийнхнээсээ шагайн тухай асууж, 4 талын бэлгэдлийг бичиж ир". Дараа нь ангиараа харьцуулж, хамгийн зөв гэж үзсэн хувилбараа апп руугаа оруулна. Хүүхдүүд өөрсдийн судалсан агуулгыг апп болгож харах нь маш их сэдэл өгдөг.

## Supabase бэлтгэл

### 1. Төсөл үүсгэх

1. [supabase.com](https://supabase.com) → Sign up (үнэгүй)
2. New Project → нэр: `shagai-app` → бүс: Singapore эсвэл Tokyo
3. Database нууц үгээ **хадгалж авах**
4. Settings → API → `Project URL` болон `anon public key`-г хуулж авах

### 2. Хүснэгт үүсгэх

SQL Editor руу орж дараах кодыг ажиллуул:

```sql
-- Шидэлт бүрийн бичлэг
create table throws (
  id uuid primary key default gen_random_uuid(),
  player_name text not null,
  mori int default 0,
  temee int default 0,
  honi int default 0,
  yamaa int default 0,
  score int not null,
  is_durvun_berkh boolean default false,
  created_at timestamptz default now()
);

-- Хичээлийн үед бүх хүн уншиж, бичиж чадна
alter table throws enable row level security;

create policy "anyone can read" on throws
  for select using (true);

create policy "anyone can insert" on throws
  for insert with check (true);
```

> **Багшид:** RLS (Row Level Security) гэдэг нь "хэн юу хийж болох вэ" гэсэн дүрэм. Эхлээд бүгдэд нээлттэй болгож байна. Сүүлийн хичээл дээр "яагаад бодит апп дээр ингэж болохгүй вэ" гэдгийг ярилцана.

### 3. Аппад холбох

```bash
npx expo install @supabase/supabase-js @react-native-async-storage/async-storage react-native-url-polyfill
```

`.env` файл үүсгэж:

```
EXPO_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...
```

#### Сэгсрэх анимацийн жор

Анимаци "гоё" харагдах эсэх нь дараах 6 зүйлээс шалтгаална. Сурагчдын анимаци уйтгартай харагдвал энэ хүснэгтээс аль нь дутуу байгааг хай:

| Хэсэг               | Утга                    | Яагаад хэрэгтэй вэ                                    |
| ------------------- | ----------------------- | ----------------------------------------------------- |
| Санамсаргүй чиглэл  | `Math.random() * 2π`    | Шагай бүр өөр тийш нисэх ёстой. Дөрвүүлээ нэг тийш явбал цэс нээгдэж байгаа юм шиг харагдана |
| Тарах зай           | 70–140 px               | Хэр өргөн тарах вэ                                     |
| Дээш үсрэлт         | Y тэнхлэгт `-70 px`     | "Дээш шидэгдлээ" гэсэн мэдрэмж өгнө                    |
| Эргэлт              | 540–1080°               | Хурдан эргэлт нь үр дүн урьдчилж мэдэгдэхээс нуудаг    |
| Ээлжлэх завсар      | `дугаар × 55ms`         | Дөрвүүлээ нэг цул юм шиг хөдлөх ёсгүй                  |
| Timing → Spring     | эхлээд `withTiming`, дараа нь `withSpring` | Timing = шидэлт, spring = буух үеийн үсрэлт |

Reanimated дээрх бүх жор ердөө энэ хоёр функц:

```js
// withSequence = нэгийг нь дуустал нөгөөг нь хий
// withDelay    = эхлээд хүлээ
tx.value = withDelay(delay, withSequence(
  withTiming(targetX, { duration: 300, easing: Easing.out(Easing.cubic) }), // тарлаа
  withSpring(0, { damping: 9 }),                                            // буулаа
));
```

> **Ярилцах:** Яагаад буцаж ирэхдээ `withTiming` биш `withSpring` вэ? (Хариу: жинхэнэ шагай хатуу шал дээр бууж байгаад бага зэрэг үсэрдэг. Spring яг тэр үсрэлтийг хийдэг.)

#### Сэгсрэлтийг яаж мэдэрдэг вэ?

Accelerometer нь `x`, `y`, `z` гэсэн 3 тоо өгнө. Нэгж нь **g** (таталцлын хүч). Гурвуулангийнх нь "урт" нь нийт хүч:

```js
const force = Math.sqrt(x * x + y * y + z * z);
```

> **Ярилцах — хамгийн сонирхолтой асуулт:** Ширээн дээр хөдөлгөөнгүй хэвтэж байгаа утасны `force` хэд байх вэ? Хүүхдүүд ихэвчлэн **0** гэж хариулдаг. Гэтэл **~1.0** байдаг — учир нь таталцал утсыг тасралтгүй татсаар л байна. Мэдрэгч "хөдөлгөөн" биш **хүч** хэмждэг. Сэгсэрвэл 2–4 хүртэл үсэрнэ.

| `threshold` | Үр дүн                                     |
| ----------- | ------------------------------------------ |
| 1.5         | Маш мэдрэмтгий — халаасанд ч шидэгдэж магадгүй |
| **1.8**     | **Санал болгох** — зөөлөн сэгсрэхэд ажиллана |
| 2.5         | Хүчтэй сэгсрэхийг шаардана                  |

> **Багшид — жишээ код (сурагчид AI-гаар бичүүлнэ, та зөвхөн шалгана):**
>
> ```js
> import { useEffect, useRef } from 'react';
> import { Accelerometer } from 'expo-sensors';
>
> export function useShake(onShake, { threshold = 1.8, cooldownMs = 2000 } = {}) {
>   const lastShakeAt = useRef(0);
>   const callback = useRef(onShake);
>   callback.current = onShake;
>
>   useEffect(() => {
>     Accelerometer.setUpdateInterval(80); // секундэд ~12 удаа хэмжинэ
>     const sub = Accelerometer.addListener(({ x, y, z }) => {
>       const force = Math.sqrt(x * x + y * y + z * z); // хөдөлгөөнгүй үед ~1.0
>       if (force < threshold) return;
>
>       const now = Date.now();
>       if (now - lastShakeAt.current < cooldownMs) return; // завсарлага
>       lastShakeAt.current = now;
>
>       callback.current();
>     });
>     return () => sub.remove(); // ЗААВАЛ — эс бөгөөс мэдрэгч асаалттай үлдэж батарей иднэ
>   }, [threshold, cooldownMs]);
> }
> ```

**Хоёр зүйлийг заавал шалга** — сурагчид энэ хоёрыг үргэлж мартдаг:

1. **Завсарлага (cooldown).** Нэг удаа сэгсрэхэд listener 5–10 удаа дуудагдана. Завсарлагагүй бол нэг сэгсрэлтэд 10 удаа шидэгдэнэ.
2. **`sub.remove()`.** Дэлгэцээс гарахад мэдрэгчийг унтраах ёстой. Үгүй бол ард нь ажилласаар батарей барна.

#### Үр дүнг хэзээ шийдэх вэ?

Шидэлтийн үр дүнг **анимаци эхлэхийн өмнө** шийдэж, **дууссаны дараа** харуулна:

```js
const next = rollFour();      // үр дүн ЭНД шийдэгдэнэ
setRoll(next);
setRevealed(false);           // текстийг нуу
// ... анимаци явна ...
setTimeout(() => setRevealed(true), 1100);  // буусны дараа харуул
```

> **Ярилцах:** Яагаад анимаци дуусахад биш, эхлэхэд random-оо гаргах вэ? (Хариу: анимаци болон үр дүн нэг шидэлтэд харьяалагдах ёстой. Хурдан эргэлт нь үр дүн аль хэдийн шийдэгдсэнийг нуудаг — жинхэнэ казино машин ч яг ингэдэг.)

**Шалгах:**

- [ ] Нэг удаа сэгсрэхэд **яг нэг** удаа шидэгдэж байна уу? (8 удаа биш)
- [ ] 4 шагай өөр өөр чиглэлд тарж байна уу?
- [ ] Үр дүнгийн бичиг шагай буусны **дараа** гарч ирж байна уу?
- [ ] Анимаци явж байхад товч идэвхгүй болж байна уу?

> **Багшид — заавал жинхэнэ утсан дээр турш.** Симулятор дээр accelerometer байхгүй тул сэгсрэлт хэзээ ч ажиллахгүй. Тийм учраас **"ШИДЭХ" товчийг хэвээр үлдээнэ** — хөгжүүлэлтийн явцад зөвхөн түүгээр л шалгана.

| "Invalid API key" | `.env` файлын нэр буруу. `EXPO_PUBLIC_` угтвар заавал байх ёстой |
| `.env` өөрчилсөн ч ажиллахгүй | Серверийг бүрэн унтрааж дахин асаах (`Ctrl+C` → `npx expo start -c`) |
| Анимаци гацна | `react-native-reanimated` babel plugin нэмээгүй. AI-д error-г өгөөд засуул |
| Accelerometer ажиллахгүй | Симулятор дээр мэдрэгч байхгүй. Жинхэнэ утсан дээр турш |
| Нэг сэгсрэхэд 5-10 удаа шидэгдэнэ | Завсарлага (cooldown) тавиагүй. Сүүлийн шидэлтээс хойш 2 секунд өнгөрсөн эсэхийг `Date.now()`-оор шалга |
| Сэгсрэхэд огт хариу өгөхгүй | `threshold` хэт өндөр байна. 1.8 болгож үзэх. Утсаа хүчтэй, богино цохилтоор сэгсэр |
| 4 шагай дөрвүүлээ нэг тийш нисэх | Чиглэл нь санамсаргүй биш. Шагай бүрт **тус тусад нь** `Math.random()` чиглэл өгөх ёстой |
| Апп хаагаад ч батарей хурдан дуусах | `sub.remove()` бичээгүй тул мэдрэгч асаалттай үлдсэн |

- [ ] 4 шагай санамсаргүй буудаг

- [ ] Утсаа сэгсрэхэд шидэгдэнэ

- [ ] Supabase-д өгөгдөл хадгалагдана (dashboard дээр нүдээр шалгасан)
- [ ] Тэргүүлэгчид жагсаалт зөв эрэмбэлэгдэнэ

## Нэмэлт даалгавар

1. Шидэлтийн түүх дэлгэц — сүүлийн 20 шидэлтээ огноотой нь харах
2. Дуу оруулах — шагай шидэгдэх, дөрвөн бэрх буух үед өөр өөр дуу (`expo-av`)
3. Шагайн жинхэнэ зураг ашиглах (эможи биш)
4. "Хамгийн азтай өдөр" — өдрөөр нь бүлэглээд, дундаж оноо хамгийн өндөр өдрийг олох
5. Хоёр хүн ээлжлэн шидэх горим — 5 шидэлтийн дараа хэн их оноотой нь ялна
