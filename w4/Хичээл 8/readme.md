<details>
<summary><b>1. Алгоритм гэж юу вэ</b></summary>

<br>

**Алгоритм** = асуудлыг шийдэх **алхмуудын жор**.

**Тоглоом — тоо таах.** Багш 1–100 хооронд тоо бодно. Чи таана, багш "их" / "бага" гэнэ.

| Арга          | Яаж                   | Хамгийн муудаа |
| ------------- | --------------------- | -------------- |
| Нэг нэгээр    | 1, 2, 3, 4...         | 100 удаа       |
| Хагаслах      | 50 → 25 → 37...       | **7 удаа**     |

Хоёулаа зөв. Гэхдээ нэг нь **14 дахин** хурдан. Сайн алгоритм = хурдан алгоритм.

</details>

<details>
<summary><b>2. Функц хэрхэн ажилладаг</b></summary>

<br>

**Функц** = нэр өгсөн машин. **Оролт** хийнэ → **гаралт** гарна.

```js
function double(n) {
  return n * 2;
}

let a = double(4);
let b = double(10);
console.log(a, b);
```

| Мөр          | Юу болов                           |
| ------------ | ---------------------------------- |
| `double(4)`  | `n = 4` → `4 * 2` → **8** буцаана  |
| `double(10)` | `n = 10` → `10 * 2` → **20** буцаана |

Нэг удаа бичээд **хэдэн ч удаа** дуудна. [pythontutor](https://pythontutor.com/javascript.html)-д функц руу "орж гарахыг" хар.

</details>
