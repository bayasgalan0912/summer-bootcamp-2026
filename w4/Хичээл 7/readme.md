**Массив** = дугаартай хайрцагнууд. Дугаар **0**-ээс эхэлнэ.

```js
let scores = [70, 95, 80];
```

| Дугаар (index) | 0   | 1   | 2   |
| -------------- | --- | --- | --- |
| Утга           | 70  | 95  | 80  |

```js
let best = scores[0];

for (let i = 1; i < scores.length; i++) {
  if (scores[i] > best) {
    best = scores[i];
  }
}

console.log(best);
```

| `i` | `scores[i]` | `> best`? | `best` |
| --- | ----------- | --------- | ------ |
| —   | —           | —         | 70     |
| 1   | 95          | тийм      | **95** |
| 2   | 80          | үгүй      | 95     |

[pythontutor](https://pythontutor.com/javascript.html) массивыг **зургаар** харуулдаг — заавал турш.
