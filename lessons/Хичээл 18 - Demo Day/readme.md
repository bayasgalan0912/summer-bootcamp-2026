<details>
<summary><b>Тайз — Хүүхдийн баатрууд</b></summary>

<br>

Багш дэлгэцэнд хүүхэд бүрийн **баатрыг** (сонгох дэлгэц / portrait) дугаарын дарааллаар үзүүлнэ. Хүүхэд зогсоод 20 сек:

```text
Би [НЭР]. Миний баатар — [НЭР]. Special нь [...].
```

</details>

<details>
<summary><b>Ширээ — эцэг эхдээ үзүүлэх (35 мин)</b></summary>

<br>

Science fair шиг: сурагч бүр суудал дээрээ, эцэг эхчүүд ширээгээр явна.

| Хүүхэд (эцэг эх бүрд 2–3 мин) | Adult 16+ |
| ----------------------------- | --------- |
| 1. **Аялал** — timeline-аа гүйлгэж "Би ... хийсэн" | Постер + QR ширээн дээр |
| 2. **Тоглуул** — товчоо заагаад эцэг эхтэйгээ тулалд | Ирсэн хүнээр захиалга илгээлгэ |
| 3. **Хамгийн хэцүү / гоё мөч** | Сайтаа үзүүл |

- Эцэг эх **өөрийн хүүхэд + 2 өөр ширээ** үзнэ.
- Эцэг эх нь ирээгүй хүүхдийн ширээнд багш эцэг эхчүүдийг дагуулна.
- Интернэт тасарвал 30 сек бичлэгээ үзүүлнэ.

</details>

<details>
<summary><b>Тайз — Эцэг эх vs хүүхэд</b></summary>

<br>

Ширээн дээр хожсон 3 эцэг эх **эсвэл** сайн дураараа гарсан 3 хос. Том дэлгэцэнд, 1 раунд.

| Дүрэм    |                                                 |
| -------- | ----------------------------------------------- |
| Дүр      | Хүүхэд — **өөрийнхөөрөө**, эцэг эх — дуртайгаа  |
| Удирдлага | Хүүхэд эцэг эхдээ товчоо 30 секундэд заана     |

</details>
