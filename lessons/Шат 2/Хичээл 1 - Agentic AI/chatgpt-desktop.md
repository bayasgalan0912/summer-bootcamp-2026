<summary><b>2. Утаснаас компьютерт даалгавар өгөх</b> · 15 мин</summary>

<br>

**Зорилго:** Гадуур явж байхдаа утаснаасаа "компьютер дээрх файлаа цэгцэл" гэх мэт даалгавар өгнө. Ажил **компьютер дээр** хийгдэнэ.

1. Компьютер, утсан дээрээ ChatGPT-д **нэг account**-аар нэвтэр.
2. Компьютерийн ChatGPT → Settings → **Connections** → **Control this Mac** (Windows-д **PC**) → **Set up**.
3. Гарч ирсэн **QR код**-ыг утасныхаа ChatGPT-ээр уншуул → компьютераа сонго.
4. Утаснаас турш:

```text
Миний компьютерийн ai-lab хавтсанд байгаа файлуудыг жагсаагаад,
"өнөөдөр.md" нэртэй файл үүсгэж өнөөдрийн огноог бич.
```

5. Компьютер дээр файл үүссэн эсэхийг шалга.

<details>
<summary>Ажиллахгүй байвал</summary>

- Компьютер **унтсан**, интернэт тасарсан, апп хаагдсан бол Remote зогсоно. Тэжээлд залгаж, унтахгүй болго.
- Хоёр төхөөрөмж өөр account / workspace-д нэвтэрсэн байж магадгүй.
- Сургууль, ажлын account бол админ нь Remote-ийг асаах шаардлагатай.
- Дэлгэц дээрх апп-уудыг удирдуулах бол Settings → **Computer use**-ийг тусад нь асаана.

</details>
