# Deal Finder

## Оролт
- Барааны нэр (заавал)
- Дээд үнэ ₮ (заавал биш)

## Алхам
1. Хаанаас хайхаа жагсааж, хэрэглэгчээс зөвшөөрөл ав.
2. Онлайн дэлгүүрийн вэб сайт → Facebook page → Instagram дарааллаар хай.
3. Олдсон мэдээллийг доорх хүснэгтээр гарга.

## Гаралт

| Бараа | Хуучин үнэ | Хямд үнэ | Хямдрал % | Дэлгүүр | Линк | Огноо |
| ----- | ---------- | -------- | --------- | ------- | ---- | ----- |

## Дүрэм
- Линкгүй мэдээллийг бүү оруул.
- Үнийг зохиож болохгүй — олдохгүй бол "тодорхойгүй".
- Дээд үнэ өгсөн бол түүнээс үнэтэйг хас.
- Хамгийн хямдыг дээр нь тавь.
- Төгсгөлд: "Үнийг линкээр нь шалгаарай" гэж сануул.
