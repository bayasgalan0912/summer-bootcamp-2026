<details>
<summary><b>1. Claude-ийн боломжууд</b> · 20 мин</summary>

<br>

Claude = чатлах хэрэгсэл биш, таны өмнөөс ажилладаг **дижитал ажилтан**. Багш [claude.com/download](https://claude.com/download)-аас суулгасан desktop app дээр үзүүлнэ (Claude 18+).

| Боломж | Юу хийдэг | Жишээ |
| ------ | --------- | ----- |
| **Chat** | Энгийн чат | Асуулт, тайлбар |
| **Cowork** | Компьютер дээрх файлтай ажилладаг агент | Хавтас цэгцлэх, Excel-ээс dashboard |
| **Code** | Кодын агент | Вэб сайт, апп барих |
| **Connectors** | Gmail, Calendar, Drive-тай холбогдоно | "Өнөөдөр ямар уулзалттай вэ?" |
| **Skills** | Дахин ашиглах заавар | `ai-stylist`, `deal-finder` |
| **Projects, Memory** | Контекст, шийдвэрээ санана | Төслийн дүрэм, нэр томъёо |
| **Artifacts, Design** | Харагдах бүтээл: вэб, постер, слайд | Social постер |
| **Scheduled tasks** | Тогтсон цагт өөрөө ажиллана | Өглөө 07:00-д Daily Digest |
| **Dispatch** | Утаснаасаа компьютер дээрх Claude-д даалгавар өгнө | Автобусанд сууж байхдаа |
| **Chrome** | Browser tab-тай ажиллана | Сайтаас мэдээлэл цуглуулах |

<details>
<summary>Багшид — demo санаа (5 мин)</summary>

- Connectors: Calendar холбоод "Энэ 7 хоногийн хуваарийг хүснэгтээр гарга".
- Artifacts: "Хичээл 1-ийн Black Friday хүснэгтийг гоё вэб хуудас болго".
- Global instructions-ээ харуул (Монголоор, эргэлзвэл асуух, товч).

</details>

Codex, Antigravity-д ч ижил ойлголтууд байдаг — **нэрс нь л өөр**.

</details>

<summary><b>2. Skill хэрхэн үүсгэх</b> · 10 мин</summary>

<br>

| Алхам | Claude | Codex |
| ----- | ------ | ----- |
| Үүсгэх | Нэр → **Customize** → **Skills** → **+** → **Create Skill** → Skill Creator-той ярилцана | Чатад "... skill үүсгэ" гэж хэлнэ |
| Хадгалах | **Save Skill** | Codex өөрөө файл болгож хадгална |
| Дуудах | Чатад **/** → skill сонгох | Skill-ийн нэрээр дуудна |
| Хуваалцах | **Download** → `.skill` файл → **Upload Skill** | `SKILL.md` файл |

Skill = **тайлбар** (хэзээ ашиглах) + **заавар** (юу хийх, дүрэм).

</details>

<details>
<summary><b>4. Дасгал 4: <code>ai-stylist</code> skill</b> · 30 мин</summary>

<br>

Хичээл 1-ийн үсний prompt + өнөөдрийн өнгөний prompt → **нэг skill**.

1. Codex-д 2 prompt файлаа өгөөд:

```text
hair.md, color.md-г ашигладаг "ai-stylist" skill үүсгэ.
- Эхлээд надаас асуу: үс уу, өнгө үү, хоёулаа юу? Хүйс, одоогийн үсний урт.
- Миний хариултаар бэлэн prompt гарга, хаана ажиллуулахыг хэл.
- Зөвшөөрөлгүй хүний зургийг ашиглахгүй гэсэн дүрэм нэм.
```

2. Skill-ийн файлыг уншаад, асуулт нь ойлгомжтой эсэхийг шалга.
3. Турш: `ai-stylist: надад богино үс зохих уу?`

Жишээ skill: [skills/ai-stylist/SKILL.md](skills/ai-stylist/SKILL.md) · Үсний prompt: [Хичээл 1 prompts/hair.md](../Хичээл%201%20-%20Agentic%20AI/prompts/hair.md)

**Adult бонус:** Claude дээр Skill Creator-оор ижил skill хийж, Codex-ийнхтэй харьцуул. Мөн "нүүрний хэлбэрээр 3 үс засалт санал болгох" алхам нэм.

</details>

<details>
<summary><b>5. Найз дээрээ турших</b> · 20 мин</summary>

<br>

1. Хосоороо: найзынхаа зургаар (зөвшөөрөлтэй) `ai-stylist`-ийг ажиллуул.
2. Найз чинь "энэ би байна" гэж хэлэв үү? 1–5 оноо өг.
3. Ангиараа: хамгийн бодит гарсан 3 зургийг дэлгэцэнд үзүүлнэ.

</details>

<details>
<summary><b>6. Skill хуваалцах</b> · 10 мин</summary>

<br>

1. `ai-stylist` skill-ийн файлаа найздаа өг.
2. Найз өөрийн Codex-д нэмээд ажиллуулна.
3. Ижил форматаар гарч байна уу? Skill = **нэг удаа заагаад, хэн ч ижлээр ашиглана**.

</details>

<details>
<summary><b>7. Дүгнэлт, гэрийн даалгавар</b> · 10 мин</summary>

<br>

- Сайн prompt = **дүрэмтэй** (юуг хийх, юуг бүү хийх).
- Урт prompt → skill → нэг үгээр дуудна.

**Гэрийн даалгавар:** `ai-stylist`-ийг **аав эсвэл ээж** дээрээ турш (зөвшөөрөлтэй). Өмнө / дараа зургийг авчир — тохирсон үс засалт, өнгийг нь хэл.

</details>
