# Өнгөний prompt (Personal color)

Хавсаргах: өөрийн нүүрний зураг (урдаас, өдрийн гэрэлд, будалтгүй).

```text
Create a high-quality personal color analysis graphic using the provided portrait.

Layout:
- Split the image into a clean, modern side-by-side comparison grid.
- Show the subject wearing different clothing color palettes (warm vs cool, bright vs muted, light vs deep).
- Include at least 6–8 color variations.

Visual Style:
- Minimalist, aesthetic, Instagram-friendly design.
- Soft neutral background (white, beige, or light gray).
- Focus on the subject's face and how each color affects skin tone, brightness, and overall harmony.

Labels:
- Use short Mongolian labels only (no paragraphs).
- Examples: "Тохирно" ✅, "Тохирохгүй" ❌, "Дулаан өнгө", "Хүйтэн өнгө", "Тод", "Бүүдгэр"

Enhancements:
- Add subtle glow or highlight on the best-matching colors.
- Slightly dull or gray out the less suitable colors.
- Keep the face identical in all comparisons (no distortion).

Goal:
- Make it instantly clear which colors suit the subject best at a glance.
- Prioritize visual clarity over text.
```
