# Хичээл 7 — Багшид

**Зорилго:** Хичээл 6-д AI Studio-д хийсэн portfolio → GitHub → компьютер дээр ажиллуулах → Vercel. Энэ урсгал цаашдын бүх хичээлд давтагдана.

**Гол санаа:** "Код минийх — GitHub-д, компьютер дээр минь байна", "Push хийвэл интернэт дэх сайт өөрөө шинэчлэгдэнэ".

## Хичээлийн өмнө

- Өөрийн апп-аар readme 2–5-р алхмыг **бүтнээр нь туршиж** үз:
  - AI Studio-гийн GitHub товч хаана, нэр нь (Push / Commit / Sync) — readme 2-т тааруул.
  - `npm run dev`-ийн port (ихэвчлэн `3000`) — readme 3-т тааруул.
  - Vercel build амжилттай эсэх (Gemini API-гүй бол түлхүүр хэрэггүй).
- Компьютер бүрт `git --version`, `node --version` ажиллаж байгааг шалга.
- GitHub бүртгэлгүй хүүхдийн тоог мэд (Хичээл 6 ГД 4).

## Түгээмэл алдаа

| Асуудал                                   | Засвар                                                                  |
| ----------------------------------------- | ----------------------------------------------------------------------- |
| GitHub "in sync" гэсэн ч өөрчлөлт ороогүй | github.com дээр шалга. Дахин Push. Болохгүй бол AI Studio-г refresh       |
| `git` / `npm` танигдахгүй                 | VSCode-г хааж дахин нээ. Болохгүй бол Node/Git суулгалтыг шалга           |
| `npm run dev` → "port already in use"    | Өмнөх Terminal-ийг **Ctrl+C**-ээр унтраа                                 |
| Terminal буруу хавтсанд байна             | `cd my-portfolio` хийсэн эсэх (`package.json` байгаа хавтас)             |
| `git pull` → conflict                     | Компьютер дээр засвар хийсэн. `git checkout .` → дахин `git pull`         |
| Vercel build failed                       | Алдааны мөрийг хуулаад AI Studio-д: "Vercel дээр энэ алдаа гарлаа, зас"   |
