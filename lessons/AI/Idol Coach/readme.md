<details>
<summary><b>1. Token, Context, Limit</b></summary>

| Үг              | Энгийнээр                                       | Жишээ                                    |
| --------------- | ----------------------------------------------- | ---------------------------------------- |
| **Token**       | AI текстийг жижиг хэсгээр уншдаг (лего тоосго)  | `hamburger` → `ham` + `bur` + `ger` = 3  |
| **Context**     | AI нэг удаад санаж чадах хэмжээ (самбар)        | Самбар дүүрвэл эхнийхээ мартана          |
| **Usage limit** | Үнэгүй ашиглах дээд хэмжээ (утасны battery)     | Дуусвал маргааш хүртэл хүлээнэ           |

**Хэмнэх 3 дүрэм:**

1. Тодорхой асуу — "туслаач" биш, "200 үгтэй эссэ бич".
2. Шинэ сэдэв = шинэ chat.
3. Олон асуултаа нэг мессежэд нэгтгэ.

</details>

<summary><b>3. System prompt бич</b></summary>

1. [aistudio.google.com](https://aistudio.google.com) → **Playground**.
2. Чатын дээд хэсгийн **System instructions** талбарт доорхыг хуулаад `[ ]`-ийг бөглө.

```text
Чи бол [IDOL]. Чи [юугаараа алдартай].

ЗАН ЧАНАР: [2-3 зан чанар]
ЯРИХ ХЭВ МАЯГ: [яаж ярьдаг, алдартай уриа]

ҮҮРЭГ:
- Надад зөвлөгөө, урам зориг өг.
- Өөрийн туршлагаас жишээ ярь.
- Богино, тодорхой хариул.
- Хөгжилтэй дасгал тул [IDOL]-ийн дүрд тогло, "Би AI" гэж бүү хэл.

АЮУЛГҮЙ БАЙДАЛ (бүү устга, дүрээс илүү чухал):
- Эрүүл мэнд, аюул, гэр бүл, сэтгэл санааны хүнд асуудалд
  "Итгэдэг том хүн (эцэг эх, багш)-тайгаа ярь" гэж зөвлө.
- Хувийн мэдээлэл (нэр, хаяг, утас) бүү асуу.
- Насанд тохироогүй зүйл бүү ярь.
```

| Асуулт                                   | Сайн coach                      |
| ---------------------------------------- | ------------------------------- |
| "Шалгалтандаа муу оноо авлаа. Яах вэ?"   | Idol шигээ урам өгнө            |

<details>
<summary><b>5. Сайтдаа "My Idol" чат нэм</b></summary>

1. System instructions-ийн текстээ бүгдийг нь copy хий.
2. Portfolio-гоо AI Studio **Build**-д нээгээд бич:

```text
Миний сайтад "My Idol" цэс нэм. Дарахад чат цонх нээгдэнэ.
Хэрэглэгч мессеж бичихэд Gemini API хариулна. API key-г кодонд
бүү бич, GEMINI_API_KEY environment variable-аас унш.
AI дараах system instruction-ий дагуу хариулна:

[SYSTEM INSTRUCTIONS-ЭЭ ЭНД БУУЛГА]

Загвар нь сайтын одоогийн өнгө, фонттой таарна.
```

3. AI Studio дотор турш — энд key хэрэггүй, шууд ажиллана.
4. GitHub руу sync хий.

**Vercel дээр ажиллуулах (нэг удаа):**

1. AI Studio → **Get API key** → **Create API key** → copy.
2. Vercel → төсөл → **Settings** → **Environment Variables** → Name: `GEMINI_API_KEY`, Value: key → **Save**.
3. **Deployments** → сүүлийнх → **Redeploy**.

> **API key = нууц үг.** Кодонд, Discord-д, screenshot-д бүү тавь. **Billing бүү асаа** — алдагдсан ч мөнгө гарахгүй. Алдагдвал **Delete** → шинэ key.

</details>

<details>
<summary><b>Гэрийн даалгавар</b></summary>

1. Coach-доо idol-ынхоо 2 алдартай хэллэгийг нэм.
2. **Me-AI** бүтээ — чи өөрөө, portfolio сайтаа зочдод тайлбарладаг туслах. Prompt-оо 2 аргын нэгээр гарга:
   - **А.** Доорх загварыг бөглө.
   - **Б.** ChatGPT эсвэл Gemini-д (чамайг мэддэг AI) асуу:

```text
Миний тухай мэддэг зүйлээ ашиглаж, миний portfolio сайтын туслах
AI-д зориулсан system prompt бичээч. Зөвхөн нууц биш мэдээлэл
(хобби, дуртай зүйл, зорилго, зан чанар) оруул. Гэрийн хаяг, утас,
сургууль, гэр бүлийн мэдээлэл бүү оруул.
```

<details>
<summary>А. Me-AI загвар</summary>

```text
Чи бол [НЭР]-ийн AI хувилбар — түүний portfolio сайтын найрсаг туслах.

ХЭН БЭ (нууц биш мэдээлэл):
- Сонирхол: [...]
- Дуртай зүйл: [...]
- Зорилго: [...]

ЗАН ЧАНАР, ЯРИХ ХЭВ МАЯГ: [...]

ҮҮРЭГ:
- Зочдод сайтын хэсгүүд, миний бүтээлүүдийг тайлбарла.
- Богино, найрсаг хариул. Мэдэхгүй зүйлээ бүү зохио.

PRIVACY (бүү устга):
- Гэрийн хаяг, утас, сургууль, нууц үг, гэр бүлийн мэдээлэл
  хэзээ ч бүү хэл: "Уучлаарай, үүнийг хуваалцаж чадахгүй."
- Хүнд асуудалд "Итгэдэг том хүнтэйгээ ярь" гэж зөвлө.
```

</details>

3. Шалга: "Гэрийн хаяг чинь хаана вэ?" → татгалзах ёстой.
4. Сайтынхаа баруун доод буланд Me-AI чат нэм — 5-р алхмын промптыг ашигла ("My Idol" цэсний оронд "баруун доод буланд дугуй icon").

</details>
