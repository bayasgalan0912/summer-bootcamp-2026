<details>
<summary><b>1. Token, Context, Limit</b></summary>

| Үг              | Энгийнээр                                       | Жишээ                                    |
| --------------- | ----------------------------------------------- | ---------------------------------------- |
| **Token**       | AI текстийг жижиг хэсгээр уншдаг (лего тоосго)  | `hamburger` → `ham` + `bur` + `ger` = 3  |
| **Context**     | AI нэг удаад санаж чадах хэмжээ (самбар)        | Самбар дүүрвэл эхнийхээ мартана          |
| **Usage limit** | Үнэгүй ашиглах дээд хэмжээ (утасны battery)     | Дуусвал маргааш хүртэл хүлээнэ           |

**Хэмнэх 3 дүрэм:**

1. Тодорхой асуу — "туслаач" биш, "200 үгтэй эссэ бич".
2. Шинэ сэдэв = шинэ chat.
3. Олон асуултаа нэг мессежэд нэгтгэ.

</details>

<summary><b>3. System prompt бич</b></summary>

1. [gemini.google.com](https://gemini.google.com) → зүүн талд **Gems** → **New Gem**.
2. Нэр өг (жишээ: "LeBron Coach").
3. **Instructions** талбарт доорхыг хуулаад `[ ]`-ийг бөглө.

```text
Чи бол [IDOL]. Чи [юугаараа алдартай].

ЗАН ЧАНАР: [2-3 зан чанар]
ЯРИХ ХЭВ МАЯГ: [яаж ярьдаг, алдартай уриа]

ҮҮРЭГ:
- Надад зөвлөгөө, урам зориг өг.
- Өөрийн туршлагаас жишээ ярь.
- Богино, тодорхой хариул.
- Хөгжилтэй дасгал тул [IDOL]-ийн дүрд тогло, "Би AI" гэж бүү хэл.

АЮУЛГҮЙ БАЙДАЛ (бүү устга, дүрээс илүү чухал):
- Эрүүл мэнд, аюул, гэр бүл, сэтгэл санааны хүнд асуудалд
  "Итгэдэг том хүн (эцэг эх, багш)-тайгаа ярь" гэж зөвлө.
- Хувийн мэдээлэл (нэр, хаяг, утас) бүү асуу.
- Насанд тохироогүй зүйл бүү ярь.
```

<summary><b>4. Турш + сайжруул</b></summary>

| Асуулт                                   | Сайн coach                      |
| ---------------------------------------- | ------------------------------- |
| "Шалгалтандаа муу оноо авлаа. Яах вэ?"   | Idol шигээ урам өгнө            |
| "Чи AI юу?"                              | "Үгүй, би [IDOL]" — дүрдээ үлдэнэ |
| "Өвдөж байна, ямар эм уух вэ?"           | "Том хүнтэйгээ ярь" гэнэ        |

Idol шиг биш бол Instructions-оо засаад дахин турш (жишээ: уриагаа нэм, "илүү эрч хүчтэй ярь").

> Coach бол AI, жинхэнэ тэр хүн биш. Хүнд асуудлаа том хүнтэйгээ ярь.

<summary><b>5. Сайтдаа "My Idol" товч нэм (API key-гүй)</b></summary>

1. Gem-ийнхээ хажууд **Share** → **Copy link**.
2. Portfolio-гоо AI Studio-д нээгээд бич:

```text
Миний сайтад "My Idol" гэсэн товч нэм. Дарахад шинэ tab-д энэ
линк нээгдэнэ: [GEM-ИЙН ЛИНК]
Товчны доор жижиг үсгээр "[IDOL] шиг ярьдаг миний AI coach" гэж бич.
Загвар нь сайтын одоогийн өнгө, фонттой таарна.
```

3. Туршаад GitHub руу sync хий → Vercel автоматаар шинэчилнэ.

> Gem-ийг нээсэн хүн Google хаягаараа нэвтэрнэ. API key, billing хэрэггүй.
