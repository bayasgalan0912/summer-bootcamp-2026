<summary><b>1. Wow: сурах бичиг ярьж байна</b></summary>

<br>

Багш урьдчилан бэлдсэн podcast-оо тоглуулна (1–2 мин). Сурагчид таана:

| Асуулт                              | Хариу                                        |
| ----------------------------------- | -------------------------------------------- |
| Хэний тухай ярьж байна?             | Тэмүжин — 9 настай, нохойноос айдаг хүү      |
| Энэ 2 хөтлөгч хэн бэ?               | Хүн биш — AI                                 |
| Юунаас уншиж ярьсан бэ?             | Монголын нууц товчоо — 800 жилийн өмнөх ном  |
| Хийхэд хэр удсан бэ?                | Файл оруулаад 1 товч, ~5 минут               |

Дараа нь **Interactive** горимоор яриаг тасалж, дуугаараа асуулт асууна — хөтлөгчид хариулна.

> Өнөөдөр: өөрийн сурах бичгээр ийм podcast хийж, portfolio-доо тавина.

<summary><b>2. ChatGPT-ээс юугаараа өөр вэ</b></summary>

<br>

|                    | ChatGPT / Gemini            | NotebookLM                              |
| ------------------ | --------------------------- | --------------------------------------- |
| Хаанаас хариулдаг  | Интернэтээс сурсан бүхнээс  | **Зөвхөн чиний оруулсан файлаас**       |

<details>
<summary><b>3. Хамтдаа: Тэмүжиний бага нас</b></summary>

<br>

Бүгд **ижил** файлаар: [source.md](source.md) — Монголын нууц товчооноос, Чингис хаан болохоос өмнөх Тэмүжин.

**Notebook үүсгэх**

1. [notebooklm.google.com](https://notebooklm.google.com) → **Create new notebook**.
2. `source.md`-г upload хий (болохгүй бол текстийг нь хуулж **Copied text**) → зүүн талын **Sources**-д орсныг хар.
3. Баруун дээд **Settings → Output language** → Монгол (жагсаалтад байхгүй бол English).

**Podcast-оо эхлүүл** — удаан бэлддэг тул эхэнд нь дар.

4. Баруун талын **Studio → Audio Overview**. Бэлэн болтол 5-р алхам руу.

**Асуулт асуу** — дунд хэсгийн чатад:

| Асуулт                                        | Юуг ажиглах вэ                               |
| --------------------------------------------- | -------------------------------------------- |
| `Тэмүжин юунаас айдаг байсан бэ?`             | Хариултын доторх `[1]` дугаар                |
| Дугаар дээр дар                               | Эх бичвэрийн **яг тэр мөр** тодорно          |
| `Тэмүжин буулгатай байж яаж зугтсан бэ?`      | Хэдэн эшлэл нийлж нэг хариулт болов?         |
| `Чингис хаан хэдэн онд нас барсан бэ?`        | Файлд байхгүй → хариулахгүй                  |

> Сүүлийн асуултыг ChatGPT-ээс асуугаад харьцуул.

**Studio-гийн бусад товч**

5. **Mind Map** — Тэмүжиний эргэн тойрны хүмүүс, үйл явдал мод хэлбэрээр. Мөчир дээр дарж задал.
6. **Quiz** — 5 асуултад хариул. Буруу хариулбал **Explain** дар.
7. Podcast бэлэн болсон бол 1 минут сонс. Хөтлөгчид аль үйл явдлыг хамгийн сонирхолтой гэж онцлов?

</details>

<details>
<summary><b>4. Өөрийн сурах бичиг</b></summary>

<br>

Одоо ганцаараа, өөрийн бүлгээр.

1. Шинэ notebook → нэр: `Түүх 7 — 3-р бүлэг` гэх мэт.
2. Source нэм:

| Надад юу байна            | Яаж оруулах                                    |
| ------------------------- | ---------------------------------------------- |
| PDF                       | Upload                                         |
| Цаасан ном                | Утсаар хуудас бүрийн зургийг авч upload        |
| Багшийн слайд, тэмдэглэл  | Upload эсвэл **Copied text**                   |

3. **Audio Overview**-ийн хажуугийн харандаа (Customize) → доорхоос нэгийг бич → **Generate**.

```text
7-р ангийн сурагчид ойлгомжтой, хөгжилтэй тайлбарла.
Шалгалтад гарах магадлалтай 5 зүйлийг онцол.
```

```text
Хоёр хөтлөгч мэтгэлц: нэг нь "энэ сэдэв амархан", нөгөө нь "хэцүү" гэж үзнэ.
```

4. Хүлээх зуураа: **Flashcards** үүсгээд 10 картыг давт (**Got it** / **Missed it**).
5. **Quiz** → оноогоо тэмдэглэ. Хажуугийн хүнтэйгээ quiz-ээ солилцож бод.
6. Podcast-оо сонс. Буруу, утгагүй зүйл хэлсэн үү? → сурах бичигтэйгээ тулга.

<details>
<summary>Adult 16+ хувилбар</summary>

<br>

Сурах бичгийн оронд өөрийн **бодит баримт** оруул:

| Жишээ                              | Асуух зүйл                                         |
| ---------------------------------- | -------------------------------------------------- |
| Жолооны дүрмийн ном                | `Шалгалтад хамгийн их алддаг 10 дүрмээр quiz хий`  |
| Түрээс / ажлын гэрээ               | `Надад эрсдэлтэй 5 заалтыг эшлэлтэй нь харуул`     |
| Их сургуулийн лекцийн слайд        | `Шалгалтын өмнөх 10 минутын podcast`               |
| Компанийн дүрэм журам, гарын авлага | `Шинэ ажилтанд зориулсан товч танилцуулга`        |

Нууц, хувийн мэдээлэлтэй файл (регистр, дансны дугаар) бүү оруул.

<details>
<summary><b>5. Бонус: YouTube видео</b></summary>

<br>

1 цагийн видеог үзэлгүйгээр 5 минутад ойлгоно.

1. Шинэ notebook → **Add source → YouTube** → дуртай видео / документалын линк.
2. Чатад: `Энэ видеоны хамгийн сонирхолтой 5 зүйл юу вэ?`
3. **Mind Map** → видеоны бүтцийг хар.

> Субтитргүй (transcript-гүй) видео орохгүй. Өөр видео сонго.

</details>

<details>
<summary><b>6. Portfolio-д карт</b></summary>

<br>

1. Өөрийн сурах бичгийн notebook → баруун дээд **Share**.
2. Access → **Anyone with a link** → **Copy link**.
3. Portfolio-гийн AI Studio **Code**-д гараараа карт нэм (Хичээл 7, 6-р алхам):

```js
{ title: "Миний AI podcast — Түүх 7", link: "https://notebooklm.google.com/notebook/..." },
```

4. Preview-д карт дээр дарж нээгдэж буйг шалга.

> Линкийг нээхэд үзэгч Google account-оор нэвтэрсэн байх ёстой.

</details>
