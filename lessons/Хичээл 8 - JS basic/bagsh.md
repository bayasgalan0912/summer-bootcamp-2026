## Блок схемийг яаж ашиглах

- Дасгал бүрийн өмнө схемийн дүрс **нэг бүрийг хуруугаар заагаад** "энэ ямар мөр болох вэ?" гэж асуу.
- **Дасгал 4 (солих)** — гол хэсэг. Хоёр аяга ундаа + хоосон аяга авчирч үзүүлбэл илүү ойлгомжтой. Самбарт `a`, `b`, `c`-г бичээд мөр бүрийн дараа утгыг нь арилгаж бич (шар нүд = өөрчлөгдсөн).
- Дасгал 3-т схем дутуу (бөглөх), Battle Раунд 2-т огт байхгүй — хүүхэд өөрөө зурна. Аажмаар бие даалгах зорилготой.

## Code Battle

Раунд 1, 2, 6 хүүхдийн `readme.md`-д байгаа. Раунд 3–5-ыг самбарт бич. Цаг дутвал 3–5-аас хас — 6 (хамгийн хэцүү) сүүлд үлдэнэ. Console-д зөв хариу гаргаад гараа өргөнө, багш дэлгэцийг нь харж баталгаажуулна. **3 · 2 · 1** оноо.

| # | Бодлого | Хариу |
| - | ------- | ----- |
| 1 | Нийт цаг: `honog = 2`, `tsag = 10` | `honog * 24 + tsag` → 58 |
| 2 | Амьдарсан хугацаа: `on = 12` | `odor = on * 365` → 4380, `* 24` → 105120, `* 60` → 6307200 |
| 3 | `doloHonog = 3` → хэдэн цаг вэ? | `doloHonog * 7 * 24` → 504 |
| 4 | `ner`, `hool` → "Бат пицца дуртай" | `ner + " " + hool + " дуртай"` — хоосон зай |
| 5 | Тэгш өнцөгт `urt = 5`, `urgun = 3` → периметр | `(urt + urgun) * 2` → 16, хаалтгүй бол 11 |
| 6 | Тонгорогсон тоо: `1234` → `4321` | `%`, `Math.floor` — доорх хариу |

## Түгээмэл алдаа

| Харагдах байдал | Шалтгаан |
| --------------- | -------- |
| Console хоосон | Ctrl+S, F5 хийгээгүй / `index.html` биш өөр файл нээсэн |
| `SyntaxError` | Хашилт `" "` эсвэл хаалт дутуу |
| `ner is not defined` | `Ner`, `ner` холилдсон эсвэл хашилтгүй `Бат` |
| `Identifier 'a' has already been declared` | `let a`-г хоёр удаа бичсэн. Дасгал бүрт өөр нэр хэрэглэ, эсвэл `let`-гүй бич |
| `НамайгБатгэдэг` | Хашилт доторх хоосон зай |
| `Console.log`, `Let` | Жижиг үсгээр |

## Хариу

```js
// 1
let ner = "Бат";
let nas = 12;
console.log("Намайг " + ner + " гэдэг. Би " + nas + " настай.");

// 3
let torsonOn = 2014;
let irehOn = 2040;
let nas2 = irehOn - torsonOn;
console.log(nas2);                 // 26

// 4
let a = "cola";
let b = "water";
let c = a;
a = b;
b = c;
console.log(a, b);                 // water cola
// Нэмэлт: let t = x; x = y; y = z; z = t;

// 5: A = 0 → 2, 3, 6 · A = 100 → 10, 10, 0 · A = 1 → 1, 3, 2 (олон хариутай)

// Battle 2
let on = 12;
let odor = on * 365;
let tsag2 = odor * 24;
let minut = tsag2 * 60;
console.log(on + " нас = " + odor + " өдөр = " + tsag2 + " цаг = " + minut + " минут");

// Battle 6
let too = 1234;
let n1 = too % 10;
let n2 = Math.floor(too / 10) % 10;
let n3 = Math.floor(too / 100) % 10;
let n4 = Math.floor(too / 1000);
console.log(n1 * 1000 + n2 * 100 + n3 * 10 + n4);   // 4321
```
