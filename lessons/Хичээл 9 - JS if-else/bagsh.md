## Блок схемийг яаж ашиглах

- Дасгал 1 — схем бэлэн, кодын `...`-г бөглөнө. Дасгал 3, 8 — "Ямар нөхцөл шалгах вэ?" гэж асуу. Схем заавал биш.
- Самбарт ромбо зурахдаа Тийм замыг **ногоон**, Үгүй замыг **улаан** шохойгоор.
- Дасгал 6 (алдаа ол) — 95-ыг самбарын схемийн дагуу хуруугаар явуулж үзүүл. Хүүхэд өөрөө "зогсчихлоо" гэж олох ёстой.

## Debug Battle

Алдаатай кодыг дэлгэцэнд үзүүл. Засаад Console-д зөв хариу гаргасан, **алдааг нэрлэж** чадсан хүн оноо авна. **3 · 2 · 1**.

| # | Алдаатай код | Юу буруу | Зөв |
| - | ------------ | -------- | --- |
| 1 | `let x = 4;`<br>`if (x = 10) { console.log("10 байна"); }` | `=` хийнэ, `===` асууна. Үргэлж "10 байна" гарна | `x === 10` |
| 2 | `let nas = 8;`<br>`if (nas >= 12); { console.log("Орно"); }` | `)`-ын араас `;` → `{ }` үргэлж ажиллана | `;`-ийг ав |
| 3 | `let too = "7";`<br>`if (too === 7) { console.log("Долоо"); } else { console.log("Өөр"); }` | `"7"` текст, `7` тоо → "Өөр" гарна | `let too = 7;` |

Нэмэлт раунд хэрэгтэй бол: `else if`-ийг `else`-ийн **араас** бичсэн (`SyntaxError`), `If` том үсгээр.

## Түгээмэл алдаа

| Харагдах байдал | Шалтгаан |
| --------------- | -------- |
| Нөхцөл үргэлж Тийм | `if (x = 5)` — `=` нэг |
| `{ }` үргэлж ажиллана | `if (...);` — цэгтэй таслал |
| `Unexpected token 'else'` | `}` дутуу, эсвэл `else`-ийн араас `else if` |
| Буруу дүн (95 → D) | `else if`-ийн дараалал — бага нь эхэнд |
| `"5" === 5` false | Текст ба тоо |
| `Identifier 'a' has already been declared` | Хичээл 8-тай адил: дасгал бүрт өөр нэр |

## Тэмдэглэл

- `if` дотор `if` (Дасгал 8) заагаагүй — ахисан хүүхэд өөрөө олбол сайн. Хүсвэл `else if (hasakh >= 5)` хэлбэрээр ч бичиж болно.
- `==` (хоёр тэнцүү) заахгүй — зөвхөн `===`. Хүүхэд AI-аас `==` харвал "төрлийг шалгадаггүй, бид `===` хэрэглэнэ" гэж хэл.
- `!` (үгүйсгэл) энэ хичээлд ороогүй.
- `prompt` / `alert` — зөвхөн Нэмэлт хэсэгт (ахисан хүүхдэд). `prompt` текст буцаадаг тул `Number(...)` заавал.
- Хуучин материалын зургууд `_huuchin/`-д. `images/`-ийн SVG-ийн текстийг шууд засаж болно.
