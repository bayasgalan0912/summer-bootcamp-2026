<details>
<summary><b>1. Жиших үйлдэл — хариу нь true эсвэл false</b></summary>

<br>

`let x = 3;` үед:

| Код | Утга | Хариу |
| --- | ---- | ----- |
| `x > 3` | их | false |
| `x >= 3` | их буюу тэнцүү | true |
| `x < 3` | бага | false |
| `x <= 3` | бага буюу тэнцүү | true |
| `x === 3` | тэнцүү | true |
| `x !== 3` | тэнцүү биш | false |

```js
console.log(10 > 7);     // true
console.log(5 === 6);    // false
```

<details>
<summary><code>=</code> ба <code>===</code> өөр</summary>

<br>

| Код | Утга |
| --- | ---- |
| `x = 3` | Хайрцагт 3 **хийнэ** |
| `x === 3` | Хайрцагт 3 байна **уу?** гэж асууна |

`"5" === 5` → **false**. Хашилттай `"5"` нь текст, `5` нь тоо — өөр төрөл.

</details>

</details>

<details>
<summary><b>2. Блок схемийн шинэ дүрс — ромбо</b></summary>

<br>

<img src="images/dursuud.svg" width="520" />

Ромбо = **нөхцөл** шалгах. Хариу нь Тийм (true) эсвэл Үгүй (false) — замаас **нэг** нь сонгогдоно.

</details>

<details>
<summary><b>3. if / else</b></summary>

<br>

<img src="images/if-else.svg" width="860" />

| Хэсэг | Утга |
| ----- | ---- |
| `if ( ... )` | Хаалтан дотор асуулт |
| `{ ... }` | Тийм бол энд байгаа код ажиллана |
| `else { ... }` | Үгүй бол энд. Хэрэггүй бол бичихгүй байж болно |

</details>

---

<details>
<summary><b>4. else if — олон зам, дараалал чухал</b></summary>

<br>

<img src="images/else-if.svg" width="900" />

Компьютер **дээрээс доош** шалгаж, **эхний** Тийм дээр зогсоно. Бусдыг огт харахгүй.

<details>
<summary>Дарааллыг сольвол юу болох вэ?</summary>

<br>

```js
let temp = 35;
if (temp > 10) {
  console.log("Өмд цамц");     // 35 > 10 → Тийм → энд зогсоно
} else if (temp > 30) {
  console.log("Шорт");         // хэзээ ч хүрэхгүй
}
```

Хамгийн **хатуу** нөхцөлийг эхэнд тавь.

</details>

</details>

---

<details>
<summary><b>5. && (бас) ба || (эсвэл)</b></summary>

<br>

| Код | Хэзээ true вэ? | Жишээ |
| --- | -------------- | ----- |
| `A && B` | **Хоёулаа** true | Кино: 12+ настай **бас** тасалбартай |
| `A \|\| B` | **Аль нэг нь** true | Амралт: бямба **эсвэл** ням |

```js
let nas = 13;
let tasalbar = true;

if (nas >= 12 && tasalbar === true) {
  console.log("Орж болно");
} else {
  console.log("Орж болохгүй");
}
```

<details>
<summary>Бүх хувилбар</summary>

<br>

| A | B | `A && B` | `A \|\| B` |
| - | - | -------- | ---------- |
| true | true | true | true |
| true | false | false | true |
| false | true | false | true |
| false | false | false | false |

</details>

</details>

---

<details>
<summary><b>Дасгал 1 — Аль нь их вэ?</b> · Анхан · хамт</summary>

<br>

**Даалгавар:** `a`, `b` хоёр тооны алийг нь их болохыг Console-д гарга.

<img src="images/d1-ih.svg" width="860" />

1. Зураг дээрх кодыг `main.js`-д хуул.
2. `if (...)`-ийн `...`-г нөхцөлөөр соль.
3. `else`-ийн `...`-д `console.log("b их");` бич.

| Оролт | Гаралт |
| ----- | ------ |
| `a = 56, b = 78` | b их |
| `a = 10, b = 9` | a их |
| `a = 7, b = 7` | Тэнцүү |

**Нэмэлт:** `a = 7, b = 7` үед одоо юу гарч байна? `else if` нэмж `"Тэнцүү"` гэж гаргадаг болго.

</details>

---

<details>
<summary><b>Дасгал 2 — Таамагла</b> · Анхан</summary>

<br>

**Даалгавар:** Мөр бүр `true` эсвэл `false` гаргана. Аль нь гарахыг ажиллуулахаас **өмнө** цээжээр таамагла.

1. Таамаглалаа хэлж эсвэл бичиж ав.
2. Кодыг `main.js`-д хуулж ажиллуул.
3. Console-ийн хариутай харьцуул. Хэдийг таасан бэ?

```js
console.log(8 > 8);
console.log(8 >= 8);
console.log(3 !== 4);
console.log("5" === 5);
console.log(10 % 2 === 0);
console.log(5 > 3 && 2 > 4);
console.log(5 > 3 || 2 > 4);
```

<details>
<summary>Хариу</summary>

<br>

| Код | Хариу | Яагаад |
| --- | ----- | ------ |
| `8 > 8` | false | Тэнцүү, их биш |
| `8 >= 8` | true | Тэнцүү байж болно |
| `3 !== 4` | true | Тэнцүү биш нь үнэн |
| `"5" === 5` | false | Текст ≠ тоо |
| `10 % 2 === 0` | true | Үлдэгдэл 0 |
| `5 > 3 && 2 > 4` | false | Хоёр дахь нь false |
| `5 > 3 \|\| 2 > 4` | true | Эхнийх нь true |

</details>

</details>

---

<details>
<summary><b>Дасгал 3 — Тэгш үү, сондгой юу?</b> · Анхан</summary>

<br>

**Даалгавар:** `x` хувьсагчийн утга тэгш бол `тэгш`, сондгой бол `сондгой` гэж Console-д гарга.

| Оролт | Гаралт |
| ----- | ------ |
| `x = 12` | тэгш |
| `x = 57349` | сондгой |

`%` — хуваахад үлдэх үлдэгдэл. Тэгш тоог 2-т хуваахад үлдэгдэл **0**.

| Код | Хариу |
| --- | ----- |
| `12 % 2` | 0 |
| `7 % 2` | 1 |

Ямар нөхцөл шалгах вэ?

</details>

---

<details>
<summary><b>Дасгал 4 — Нууц үг</b> · Дунд</summary>

<br>

**Даалгавар:** Нууц үг солихдоо 2 удаа бичдэг. Хоёр удаа бичсэн нь ижил эсэхийг шалга.

`password`, `password2` хоёр хувьсагч үүсгэ.

| Нөхцөл | Гаралт |
| ------ | ------ |
| Ижил | Нууц үг амжилттай солигдлоо |
| Өөр | Нууц үгээ зөв давтаж оруулаарай |

Дараах утгуудаар шалга:

| `password` | `password2` | Гаралт |
| ---------- | ----------- | ------ |
| `"abc123"` | `"abc123"` | Нууц үг амжилттай солигдлоо |
| `"abc123"` | `"abc124"` | Нууц үгээ зөв давтаж оруулаарай |
| `"Abc123"` | `"abc123"` | Нууц үгээ зөв давтаж оруулаарай |

Сүүлийнх нь яагаад өөр вэ? — том, жижиг үсэг өөр.

</details>

<details>
<summary><b>Дасгал 5 — Дүн</b> · Дунд</summary>

<br>

**Даалгавар:** `onoo` (0–100) хувьсагчийн утгаар үсгэн дүнг Console-д гарга.

| Оноо | Дүн |
| ---- | --- |
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 0–59 | F |

| Оролт | Гаралт |
| ----- | ------ |
| `onoo = 95` | A |
| `onoo = 78` | C |
| `onoo = 40` | F |

`else if` ашигла. **Хамгийн өндөр** (A) нөхцөлөөс эхлүүл.

</details>

<details>
<summary><b>Дасгал 6 — Алдааг ол</b> · Дунд</summary>

<br>

**Даалгавар:** Энэ код 95 оноонд `A`-ийн оронд `D` гэж гаргаж байна. Яагаад? Кодыг засаж 95 → `A` гаргадаг болго.

```js
let onoo2 = 95;

if (onoo2 >= 60) {
  console.log("D");
} else if (onoo2 >= 70) {
  console.log("C");
} else if (onoo2 >= 90) {
  console.log("A");
}
```

Засаад `onoo2 = 95 → A`, `75 → C`, `65 → D` гарч байгааг шалга.

<details>
<summary>Зөвлөгөө</summary>

<br>

95 >= 60 уу? Тийм → эхний `{ }` ажиллаад **зогсоно**. Бусад нь шалгагдахгүй. (4-р алхам)

</details>

</details>

<details>
<summary><b>Дасгал 7 — FizzBuzz</b> · Ахисан</summary>

<br>

**Даалгавар:** `n` тооны утгаас хамаарч доорх хүснэгтийн дагуу Console-д гарга.

| Нөхцөл | Гаралт |
| ------ | ------ |
| 3-т ч, 5-д ч хуваагдана | FizzBuzz |
| Зөвхөн 3-т хуваагдана | Fizz |
| Зөвхөн 5-д хуваагдана | Buzz |
| Алинд нь ч хуваагдахгүй | тоо өөрөө |

| Оролт | Гаралт |
| ----- | ------ |
| `n = 9` | Fizz |
| `n = 25` | Buzz |
| `n = 15` | FizzBuzz |
| `n = 79` | 79 |

"Хуваагдана" = үлдэгдэл 0 (`n % 3 === 0`). Аль нөхцөлийг **эхэнд** тавих вэ? 15-аар шалгаж үз.

</details>

<details>
<summary><b>Дасгал 8 — Замын цагдаа</b> · Ахисан</summary>

<br>

**Даалгавар:** Машины хурд `speed`-ээс хамаарч жолоочийн хасагдах оноог тооцож Console-д гарга.

- Дээд хурд **80** км/ц. 80 ба түүнээс бага → хэвийн.
- 80-аас **5 км/ц хэтрэх бүрт 1 оноо** хасна.
- **5 буюу түүнээс их** оноо алдвал жолооны эрх хасна.

| Оролт | Гаралт |
| ----- | ------ |
| `speed = 70` | Хурд хэвийн |
| `speed = 100` | 4 оноо алдсан. Эрх хасагдаагүй |
| `speed = 120` | 8 оноо алдсан. Эрх хасагдсан |

Хэдэн нөхцөл шалгах вэ?

<details>
<summary>Зөвлөгөө</summary>

<br>

Хасах оноо: `Math.floor((speed - 80) / 5)` — Хичээл 8-ын бонусын `Math.floor`. Жишээ: `(100 - 80) / 5 = 4`.

</details>

</details>

<details>
<summary><b>Бонус — Өндөр жил</b> · Ахисан</summary>

<br>

**Даалгавар:** `on` (он) хувьсагчийн утга өндөр жил бол `өндөр жил`, үгүй бол `энгийн` гэж гарга.

Өндөр жил (2-р сар 29 хоногтой) гэвэл:

- 4-т хуваагдана, **бас** 100-д хуваагдахгүй,
- **эсвэл** 400-д хуваагдана.

| Оролт | Гаралт |
| ----- | ------ |
| `on = 2024` | өндөр жил |
| `on = 2023` | энгийн |
| `on = 1900` | энгийн |
| `on = 2000` | өндөр жил |

`&&`, `||`-ийг **нэг** `if` дотор хамт хэрэглэ. Хаалт `( )` хэрэгтэй.

</details>

<details>
<summary><b>Нэмэлт — prompt / alert</b> · Ахисан</summary>

<br>

Утгыг кодонд биш, **гараас** оруулж болно.

```js
let nas = Number(prompt("Хэдэн настай вэ?"));

if (nas >= 12) {
  alert("Орж болно");
} else {
  alert("Орж болохгүй");
}
```

| Код | Утга |
| --- | ---- |
| `prompt("...")` | Цонх гаргаж, бичсэнийг **текст**ээр авна |
| `Number(...)` | Текстийг **тоо** болгоно |
| `alert("...")` | Цонхонд харуулна |

**Даалгавар:** Дасгал 3 эсвэл 5-аа `prompt` / `alert`-тэй болго.

<details>
<summary><code>Number</code>-гүй бол?</summary>

<br>

`prompt` үргэлж текст буцаана: `"13"`. `"13" === 13` → **false** (1-р алхам).

</details>
