<details>
<summary><b>2. for</b></summary>

<br>

```js
let n = 3;
let s = 0;

for (let i = 1; i <= n; i++) {
  s = s + i;
}

alert(s); // 6
```

| Хэсэг | Утга | Блок схем |
| ----- | ---- | --------- |
| `let i = 1` | 1-ээс эхэл | s = 0, i = 1 |
| `i <= n` | n хүртэл | ромбо |
| `i++` | 1-ээр нэм | i = i + 1 |
| `{ s = s + i }` | давтах үйлдэл | s = s + i |

`n = 3` үед алхам алхмаар:

| Удаа | `i` | `s` |
| ---- | --- | --- |
| эхэнд | 1 | 0 |
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |
| `i = 4` → `4 <= 3` худал → зогсоно | | **6** |

> **Хуудас гацвал** давталт тань хэзээ ч зогсохгүй байна (`i++`-ийн оронд `i--` г.м.). Табаа хаагаад кодоо засаад дахин нээ.

</details>

---

<details>
<summary><b>3. Хуримтлагч — тоо ч, текст ч</b></summary>

<br>

Цуглуулах хувьсагчаа давталтаас **өмнө** үүсгэ.

| Юу цуглуулах | Эхлэх утга | Давталт дотор |
| ------------ | ---------- | ------------- |
| Нийлбэр | `let s = 0` | `s = s + i` |
| Үржвэр | `let u = 1` | `u = u * i` |
| Тоо (хэд вэ) | `let too = 0` | `too = too + 1` |
| Текст | `let t = ""` | `t = t + "⭐"` |

</details>

<details>
<summary><b>4. prompt — гараас утга авах, alert — хариу харуулах</b></summary>

<br>

```js
let n = Number(prompt("Хэдэн хүртэл нэмэх вэ?"));
let s = 0;

for (let i = 1; i <= n; i++) {
  s = s + i;
}

alert("Нийлбэр: " + s);
```

| Код | Утга |
| --- | ---- |
| `prompt("...")` | Асуулттай цонх гаргаж, бичсэнийг авна |
| `Number(...)` | Бичсэнийг **тоо** болгоно. Тоо асуух бүрт заавал |
| `alert(...)` | Хариуг цонхонд харуулна |
| `"\n"` | Шинэ мөр. Олон мөрийг нэг `alert`-д: `t = t + ... + "\n"` |

<details>
<summary><code>Number</code>-гүй бол?</summary>

<br>

`prompt` бичсэнийг **текст**ээр авна: `"5"`. `"5" + 1` → `"51"` (Хичээл 8, текст нийлүүлэх).

</details>

</details>

<details>
<summary><b>Дасгал 1 — 1-ээс 100 хүртэл</b> · Анхан · хамт</summary>

<br>

**Даалгавар:** 1, 2, 3 … 100 гэж бүх тоог нэг `alert`-д гарга.

Алхам алхмаар бич:

| # | Код | Юу хийнэ |
| - | --- | -------- |
| 1 | `let t1 = "";` | Тоо цуглуулах хоосон текст |
| 2 | `for (let i = 1; i <= 100; i++) {` | `i` нь 1, 2, 3 … 100 |
| 3 | `  t1 = t1 + i + " ";` | Тоо бүрийг зайтай нэмнэ |
| 4 | `}` | Давталт дуусна |
| 5 | `alert(t1);` | Нэг удаа харуулна |

Ажилласны дараа: `100`-г `10` болговол юу гарах вэ? `1`-г `50` болговол?

</details>

| 5 | `}` | Давталт дуусна |
| 6 | `alert(s2);` | Хариуг харуулна |

| prompt-д бичвэл | alert |
| --------------- | ----- |
| 3 | 6 |
| 10 | 55 |
| 100 | 5050 |

<summary><b>Дасгал 10 — Чихэр хуваах</b> · Ахисан</summary>

<br>

**Даалгавар:** Хэдэн чихэр байгааг `prompt`-оор асууж (`chiher`), найзууддаа **тэнцүү, үлдэгдэлгүй** хуваах бүх хувилбарыг нэг `alert`-д гарга.

prompt-д `12` бичвэл:

```
1 хүнд 12 ширхэг
2 хүнд 6 ширхэг
3 хүнд 4 ширхэг
4 хүнд 3 ширхэг
6 хүнд 2 ширхэг
12 хүнд 1 ширхэг
```

**Нэмэлт:** Зөвхөн **2** хувилбар гарвал (1 хүнд эсвэл бүгдэд 1-ээр) тэр нь **анхны тоо**. `7` бичвэл хувилбаруудын доор `Анхны тоо` гэж нэм.

<details>
<summary>Зөвлөгөө</summary>

<br>

1-ээс `chiher` хүртэлх `i` бүрээр: `chiher % i === 0` бол хуваагдана. Нэмэлтэд: хуваагдах бүрт `huvaagch`-ийг 1-ээр нэмээд, давталтын дараа `huvaagch === 2` эсэхийг шалга.

</details>
