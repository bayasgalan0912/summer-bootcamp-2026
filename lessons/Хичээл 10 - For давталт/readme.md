<details>
<summary><b>2. for</b></summary>

<br>

```js
let n = 3;
let s = 0;

for (let i = 1; i <= n; i++) {
  s = s + i;
}

console.log(s); // 6
```

| Хэсэг | Утга | Блок схем |
| ----- | ---- | --------- |
| `let i = 1` | 1-ээс эхэл | s = 0, i = 1 |
| `i <= n` | n хүртэл | ромбо |
| `i++` | 1-ээр нэм | i = i + 1 |
| `{ s = s + i }` | давтах үйлдэл | s = s + i |

`n = 3` үед алхам алхмаар:

| Удаа | `i` | `s` |
| ---- | --- | --- |
| эхэнд | 1 | 0 |
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |
| `i = 4` → `4 <= 3` худал → зогсоно | | **6** |

> **Хуудас гацвал** давталт тань хэзээ ч зогсохгүй байна (`i++`-ийн оронд `i--` г.м.). Табаа хаагаад кодоо засаад дахин нээ.

</details>

<details>
<summary><b>3. Хуримтлагч — тоо ч, текст ч</b></summary>

<br>

Цуглуулах хувьсагчаа давталтаас **өмнө** үүсгэ.

| Юу цуглуулах | Эхлэх утга | Давталт дотор |
| ------------ | ---------- | ------------- |
| Нийлбэр | `let s = 0` | `s = s + i` |
| Үржвэр | `let u = 1` | `u = u * i` |
| Тоо (хэд вэ) | `let too = 0` | `too = too + 1` |
| Текст | `let t = ""` | `t = t + "⭐"` |

</details>

| `odor = 3` | 6000 | 1000 + 2000 + 3000 |

2-р алхмын кодоор, блок схемтэй харьцуулан хамт бичнэ. Өдөр бүр `i * 1000` нэмнэ.

<details>
<summary><b>Дасгал 8 — Чихэр хуваах</b> · Ахисан</summary>

<br>

**Даалгавар:** `chiher` ширхэг чихрийг найзууддаа **тэнцүү, үлдэгдэлгүй** хуваана. Хэдэн хүнд хувааж болох бүх хувилбарыг гарга.

`chiher = 12` үед:

```
1 хүнд 12 ширхэг
2 хүнд 6 ширхэг
3 хүнд 4 ширхэг
4 хүнд 3 ширхэг
6 хүнд 2 ширхэг
12 хүнд 1 ширхэг
```

**Нэмэлт:** Зөвхөн **2** хувилбар гарвал (1 хүнд эсвэл бүгдэд 1-ээр) тэр нь **анхны тоо**. `chiher = 7` үед хувилбаруудын доор `Анхны тоо` гэж гарга.

<details>
<summary>Зөвлөгөө</summary>

<br>

1-ээс `chiher` хүртэлх `i` бүрээр: `chiher % i === 0` бол хуваагдана. Нэмэлтэд: хуваагдах бүрт `huvaagch`-ийг 1-ээр нэмээд, давталтын дараа `huvaagch === 2` эсэхийг шалга.

</details>

</details>
