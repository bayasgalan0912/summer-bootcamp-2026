# Хичээл 10 — Багшид

**Зорилго:** `for`, хуримтлагч хувьсагч. Давталт хэдэн удаа ажиллаж, хувьсагч хэрхэн өөрчлөгдөхийг **хүснэгтээр мөшгиж** чаддаг болох.

**Гол санаа:** "Буцах сум = давталт", "Цуглуулах хайрцгаа давталтаас **өмнө** үүсгэ", "Нөхцөл хэзээ нэгэн цагт **худал** болох ёстой".

## Хичээлийн өмнө

- `index.html`, `main.js`-ийн линк readme-ийн 0-р алхамд байгаа.
- Самбарт буцах сумтай блок схем (readme 1) + хоосон мөшгих хүснэгт (`i`, `s`) зур.

## Түгээмэл алдаа

| Алдаа | Засвар |
| ----- | ------ |
| Хуудас гацна | Хязгааргүй давталт: `i--` / `i++` андуурсан. Таб хаа → засаад нээ |
| `let s = 0`-ийг давталтын **дотор** бичсэн | Давталт бүрт 0 болж байна — гадна гарга |
| `console.log` давталтын дотор | Хариу олон мөр гарна — давталтын **дараа** (Дасгал 5-аас бусад) |
| Факториал → 0 | Үржвэр 1-ээс эхэлнэ |
| Дасгал 1: 5 → 10 | `i < n` — `<=` хэрэгтэй |
| `Identifier 'n' has already been declared` | Өөр дасгалын хувьсагчийн нэр давхацсан — readme-д өгсөн нэрийг ашигла |
| Дасгал 3: `5 4 3 2 1  Хөөрлөө!` | Илүү зай — `t + i + " "` дараа нь `+ "Хөөрлөө!"` |

## Хариу

```js
// 1
let n = 5;
let s = 0;
for (let i = 1; i <= n; i++) {
  s = s + i;
}
console.log(s);

// 2
let od = 3;
let t = "";
for (let i = 1; i <= od; i++) {
  t = t + "⭐";
}
console.log(t);

// 3
let ehlel = 5;
let t3 = "";
for (let i = ehlel; i >= 1; i--) {
  t3 = t3 + i + " ";
}
console.log(t3 + "Хөөрлөө!");

// 4
let hyazgaar = 10;
let tegsh = 0;
for (let i = 1; i <= hyazgaar; i++) {
  if (i % 2 === 0) {
    tegsh = tegsh + 1;
  }
}
console.log(tegsh);

// 5
let too = 3;
for (let i = 1; i <= 10; i++) {
  console.log(too + " x " + i + " = " + too * i);
}

// 6
let f = 5;
let u = 1;
for (let i = 1; i <= f; i++) {
  u = u * i;
}
console.log(u);

// 7
let sarBur = 40000;
let sar = 3;
let mungu = 0;
for (let i = 1; i <= sar; i++) {
  mungu = mungu + sarBur;
  console.log(i + "-р сар: " + mungu);
}

// 8
let x = 97;
let huvaagch = 0;
for (let i = 1; i <= x; i++) {
  if (x % i === 0) {
    huvaagch = huvaagch + 1;
  }
}
if (huvaagch === 2) {
  console.log("Анхны тоо");
} else {
  console.log("Анхны биш");
}

// Бонус
let dees = 10;
let s35 = 0;
for (let i = 1; i <= dees; i++) {
  if (i % 3 === 0 || i % 5 === 0) {
    s35 = s35 + i;
  }
}
console.log(s35);
```

Дасгал 8-д 1-ээс `x` хүртэл бүх тоогоор хуваана — удаан ч ойлгомжтой. Ахисан хүүхдүүдтэй "2-оос эхлээд хуваагч олдвол зогсож болох уу?" гэж ярилц.
