# Хичээл 10 — Багшид

**Зорилго:** `for`, хуримтлагч хувьсагч, `prompt` / `alert`. Давталт хэдэн удаа ажиллаж, хувьсагч хэрхэн өөрчлөгдөхийг **хүснэгтээр мөшгиж** чаддаг болох.

**Гол санаа:** "Буцах сум = давталт", "Цуглуулах хайрцгаа давталтаас **өмнө** үүсгэ", "Нөхцөл хэзээ нэгэн цагт **худал** болох ёстой".

## Хичээлийн өмнө

- `index.html`, `main.js`-ийн линк readme-ийн 0-р алхамд байгаа.
- Самбарт буцах сумтай блок схем (readme 1) + хоосон мөшгих хүснэгт (`i`, `s`) зур.

## Түгээмэл алдаа

| Алдаа | Засвар |
| ----- | ------ |
| Хуудас гацна | Хязгааргүй давталт: `i--` / `i++` андуурсан. Таб хаа → засаад нээ |
| `let s = 0`-ийг давталтын **дотор** бичсэн | Давталт бүрт 0 болж байна — гадна гарга |
| `alert` давталтын дотор | Олон цонх гарна — текстэд `"\n"`-ээр цуглуулаад давталтын **дараа** нэг `alert` |
| `"5" + 1` → `51`, хариу хачин | `prompt`-ыг `Number(...)`-гүй авсан |
| F5 бүрт олон `prompt` | Дуусгасан дасгалаа Ctrl+/ -оор comment болго |
| Факториал → 0 | Үржвэр 1-ээс эхэлнэ |
| Дасгал 1: 5 → 10000 | `i < odor` — `<=` хэрэгтэй |
| `Identifier 't' has already been declared` (`main.js`-ийн эхний жишээнд `n`, `t` бий) | Өөр дасгалын хувьсагчийн нэр давхацсан — readme-д өгсөн нэрийг ашигла |
| Дасгал 3: `3 2 1  Шинэ жил мэнд!` | Илүү зай — `t3 + i + " "` дараа нь `+ "Шинэ жил мэнд!"` |

## Хариу

```js
// 1
let odor = Number(prompt("Хэдэн өдөр хадгалах вэ?"));
let niit = 0;
for (let i = 1; i <= odor; i++) {
  niit = niit + i * 1000;
}
alert("Нийт: " + niit + "₮");

// 2
let unelgee = Number(prompt("Үнэлгээ (1-5)?"));
let t2 = "";
for (let i = 1; i <= unelgee; i++) {
  t2 = t2 + "⭐";
}
alert(t2);

// 3
let ehlel = Number(prompt("Хэдээс тоолох вэ?"));
let t3 = "";
for (let i = ehlel; i >= 1; i--) {
  t3 = t3 + i + " ";
}
alert(t3 + "Шинэ жил мэнд!");

// 4
let honog = Number(prompt("Хэдэн хоног?"));
let uslah = 0;
for (let i = 1; i <= honog; i++) {
  if (i % 2 === 0) {
    uslah = uslah + 1;
  }
}
alert(uslah + " удаа услана");

// 5
let une = Number(prompt("Нэг бууз хэдэн төгрөг вэ?"));
let t5 = "";
for (let i = 1; i <= 10; i++) {
  t5 = t5 + i + " бууз: " + une * i + "₮\n";
}
alert(t5);

// 6
let naiz = Number(prompt("Хэдэн найз вэ?"));
let u = 1;
for (let i = 1; i <= naiz; i++) {
  u = u * i;
}
alert(u + " янзаар");

// 7
let sarBur = Number(prompt("Сар бүр хэдэн төгрөг хадгалах вэ?"));
let sar = Number(prompt("Хэдэн сар?"));
let mungu = 0;
let t7 = "";
for (let i = 1; i <= sar; i++) {
  mungu = mungu + sarBur;
  t7 = t7 + i + "-р сар: " + mungu + "₮\n";
}
alert(t7);

// 8
let chiher = Number(prompt("Хэдэн чихэр вэ?"));
let huvaagch = 0;
let t8 = "";
for (let i = 1; i <= chiher; i++) {
  if (chiher % i === 0) {
    t8 = t8 + i + " хүнд " + chiher / i + " ширхэг\n";
    huvaagch = huvaagch + 1;
  }
}
if (huvaagch === 2) {
  t8 = t8 + "Анхны тоо";
}
alert(t8);

// Бонус
let nud = Number(prompt("Хэдэн нүд вэ?"));
let budaa = 1;
let niitBudaa = 0;
for (let i = 1; i <= nud; i++) {
  niitBudaa = niitBudaa + budaa;
  budaa = budaa * 2;
}
alert(niitBudaa + " будаа");
```

- Дасгал 8: 1-ээс `chiher` хүртэл бүх тоогоор хуваана — удаан ч ойлгомжтой.
- Бонус: `nud = 64` → `18446744073709552000`. Жинхэнэ хариу …615 — JS ийм том тоог яг хадгалж чадахгүй. Домгийн утга: дэлхийн бүх будаанаас их.
