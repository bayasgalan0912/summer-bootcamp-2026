# Хичээл 10 — Багшид

**Зорилго:** `for`, хуримтлагч хувьсагч. Давталт хэдэн удаа ажиллаж, хувьсагч хэрхэн өөрчлөгдөхийг **хүснэгтээр мөшгиж** чаддаг болох.

**Гол санаа:** "Буцах сум = давталт", "Цуглуулах хайрцгаа давталтаас **өмнө** үүсгэ", "Нөхцөл хэзээ нэгэн цагт **худал** болох ёстой".

## Хичээлийн өмнө

- `index.html`, `main.js`-ийн линк readme-ийн 0-р алхамд байгаа.
- Самбарт буцах сумтай блок схем (readme 1) + хоосон мөшгих хүснэгт (`i`, `s`) зур.

## Түгээмэл алдаа

| Алдаа | Засвар |
| ----- | ------ |
| Хуудас гацна | Хязгааргүй давталт: `i--` / `i++` андуурсан. Таб хаа → засаад нээ |
| `let s = 0`-ийг давталтын **дотор** бичсэн | Давталт бүрт 0 болж байна — гадна гарга |
| `console.log` давталтын дотор | Хариу олон мөр гарна — давталтын **дараа** (Дасгал 5-аас бусад) |
| Факториал → 0 | Үржвэр 1-ээс эхэлнэ |
| Дасгал 1: 5 → 10000 | `i < odor` — `<=` хэрэгтэй |
| `Identifier 't' has already been declared` | Өөр дасгалын хувьсагчийн нэр давхацсан — readme-д өгсөн нэрийг ашигла |
| Дасгал 3: `3 2 1  Шинэ жил мэнд!` | Илүү зай — `t3 + i + " "` дараа нь `+ "Шинэ жил мэнд!"` |

## Хариу

```js
// 1
let odor = 5;
let niit = 0;
for (let i = 1; i <= odor; i++) {
  niit = niit + i * 1000;
}
console.log(niit);

// 2
let unelgee = 4;
let t = "";
for (let i = 1; i <= unelgee; i++) {
  t = t + "⭐";
}
console.log(t);

// 3
let ehlel = 10;
let t3 = "";
for (let i = ehlel; i >= 1; i--) {
  t3 = t3 + i + " ";
}
console.log(t3 + "Шинэ жил мэнд!");

// 4
let honog = 10;
let uslah = 0;
for (let i = 1; i <= honog; i++) {
  if (i % 2 === 0) {
    uslah = uslah + 1;
  }
}
console.log(uslah);

// 5
let une = 1500;
for (let i = 1; i <= 10; i++) {
  console.log(i + " бууз: " + une * i + "₮");
}

// 6
let naiz = 3;
let u = 1;
for (let i = 1; i <= naiz; i++) {
  u = u * i;
}
console.log(u);

// 7
let sarBur = 40000;
let sar = 3;
let mungu = 0;
for (let i = 1; i <= sar; i++) {
  mungu = mungu + sarBur;
  console.log(i + "-р сар: " + mungu + "₮");
}

// 8
let chiher = 12;
let huvaagch = 0;
for (let i = 1; i <= chiher; i++) {
  if (chiher % i === 0) {
    console.log(i + " хүнд " + chiher / i + " ширхэг");
    huvaagch = huvaagch + 1;
  }
}
if (huvaagch === 2) {
  console.log("Анхны тоо");
}

// Бонус
let nud = 4;
let budaa = 1;
let niitBudaa = 0;
for (let i = 1; i <= nud; i++) {
  niitBudaa = niitBudaa + budaa;
  budaa = budaa * 2;
}
console.log(niitBudaa);
```

- Дасгал 8: 1-ээс `chiher` хүртэл бүх тоогоор хуваана — удаан ч ойлгомжтой.
- Бонус: `nud = 64` → `18446744073709552000`. Жинхэнэ хариу …615 — JS ийм том тоог яг хадгалж чадахгүй. Домгийн утга: дэлхийн бүх будаанаас их.
