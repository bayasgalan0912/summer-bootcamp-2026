# Хичээл 6 — Багшид

**Зорилго:** "Гоё вэб гараар хийхэд урт хугацаа, их дадлага хэрэгтэй — AI-аар хэдхэн минут" гэдгийг **мэдрүүлэх** (wow). Дараа нь хүүхэд бүр загвар сонгож, Хичээл 5-ын `index.html`-ийн мэдээллээр AI Studio **Build**-д portfolio хийнэ. Цаашид энэ сайтаа AI Studio-д **vibe coding**-оор хөгжүүлнэ (HTML/CSS дасгал бага, JS + алгоритм орно). GitHub, Vercel — Хичээл 7.

**Гол санаа:** "AI-д юу хүсэхээ **би** хэлнэ", "Загвар — бусдынх, агуулга — минийх".

## Хичээлийн өмнө

- [motionsites.ai](https://motionsites.ai/) — үнэгүй (**Copy prompt**) загварууд хэвээр эсэхийг шалга. Өөрчлөгдсөн бол readme 3-р алхмын (Арга 1) хүснэгтийг шинэчил.
- Арга 2-ын сайтууд (urgoo.mn, tengis.mn, kinosan.mn, netflix, roblox, spotify) нээгдэж байгааг шалга.
- **Wow санаа:** urgoo.mn-ийн screenshot + өөрийн мэдээллээр "кино сайт шиг portfolio"-г урьдчилж хийж ав — хүүхэд өөрийгөө киноны од болгох нь хамгийн их сонирхол татна.
- Хүүхдүүд өөр сайт (кино үзэх зөвшөөрөлгүй сайт гэх мэт) санал болговол — хууль ёсны, насанд тохирсон сайтыг л сонгуул.
- Build-д **System instructions** хаана тохируулдгийг шалга (readme 2).
- Нэг загвар (жишээ нь RIVR) + Бат-ын `index.html` (`lessons/Хичээл 5/my-first-web/`)-ээр readme 4-р алхмыг **туршиж** үз. Үр дүнгийн screenshot-ыг `images/daraa.png` болгоод readme-ийн дээд хүснэгтэд гуравдах багана болгож нэмж болно — тэгвэл өмнө/дараа нь **яг энэ дасгалын** үр дүн болно.
- AI Studio апп-аа өөрөө хадгалдаг эсэх, хаанаас дахин нээхийг шалга (readme 5-ын төгсгөл).
- `example-site.png` (багшийн сайт) — Арга 2-ын жишээ, wow-д ч ашиглана.
