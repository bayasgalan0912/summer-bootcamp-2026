<details>
<summary><b>1. Массив гэж юу вэ</b></summary>

<br>

Олон утгыг `[ ]` дотор, `,`-оор салгаж **нэг** хувьсагчид хадгална.

```js
let anime = ["Naruto", "One Piece", "Dragon Ball"];
```

| Код | Утга | Хариу |
| --- | ---- | ----- |
| `anime[0]` | **1-р** элемент (тоолол **0**-ээс эхэлнэ) | `"Naruto"` |
| `anime[2]` | 3-р элемент | `"Dragon Ball"` |
| `anime.length` | Хэдэн элементтэй вэ | `3` |
| `anime[3]` | Байхгүй | `undefined` |

Тоо ч байж болно: `let onoo = [8, 10, 7];`

</details>

---

<details>
<summary><b>2. for + массив</b></summary>

<br>

```js
let anime = ["Naruto", "One Piece", "Dragon Ball"];
let t = "";

for (let i = 0; i < anime.length; i++) {
  t = t + anime[i] + "\n";
}

alert(t);
```

| Хичээл 10 | Өнөөдөр | Яагаад |
| --------- | ------- | ------ |
| `let i = 1` | `let i = 0` | Массив 0-ээс эхэлнэ |
| `i <= n` | `i < anime.length` | Сүүлийнх нь `length - 1` |
| `i` | `anime[i]` | `i`-р элементийг авна |

| `i` | `anime[i]` |
| --- | ---------- |
| 0 | Naruto |
| 1 | One Piece |
| 2 | Dragon Ball |
| `3 < 3` худал → зогсоно | |

</details>

---

<details>
<summary><b>3. Массивтай бодох 3 загвар</b></summary>

<br>

| Юу | Эхлэх утга | Давталт дотор |
| -- | ---------- | ------------- |
| Нийлбэр | `let s = 0` | `s = s + a[i]` |
| Тоолох | `let too = 0` | `if (a[i] >= 60) { too = too + 1 }` |
| Хамгийн их | `let max = a[0]` | `if (a[i] > max) { max = a[i] }` |

Дундаж = нийлбэр / `a.length`.

</details>

<details>
<summary><b>Дасгал 6 — Anime Guess</b> · Бүгд · хамт</summary>

<br>

2 массив. Ижил дугаартай элементүүд нэг асуулт болно: `emoji[0]` ↔ `answer[0]`.

```js
let emoji = ["🍥🦊🍜", "🏴‍☠️👒🍖", "🐉🟠⭐", "🧱👊⚔️", "👹🗡️🌸"];
let answer = ["Naruto", "One Piece", "Dragon Ball", "Attack on Titan", "Demon Slayer"];
```

**Даалгавар:** Emoji-г нэг нэгээр нь `prompt`-оор асууж, зөв бол оноо нэм. Төгсгөлд нь оноог гарга.

| # | Код | Юу хийнэ |
| - | --- | -------- |
| 1 | `let onoo = 0;` | Оноо 0-ээс |
| 2 | `for (let i = 0; i < emoji.length; i++) {` | Асуулт бүрээр |
| 3 | `  let hariu = prompt(emoji[i]);` | Emoji харуулж асууна |
| 4 | `  if (hariu === answer[i]) {` | Зөв үү? |
| 5 | `    onoo = onoo + 1;` | +1 оноо |
| 6 | `  }` | |
| 7 | `}` | |
| 8 | `alert("Оноо: " + onoo + " / " + emoji.length);` | Үр дүн |

Ажилласны дараа: массив бүрт **өөрийн** 1 anime нэм. Код өөрчлөхгүйгээр тоглоом 6 асуулттай болох уу?

<details>
<summary>Бонус 1 — Зөв хариуг харуулах · Ахисан</summary>

<br>

Буруу бол `alert("Буруу! Зөв нь: ...")` гэж зөв хариуг харуул. `else` хэрэгтэй.

</details>

<details>
<summary>Бонус 2 — Санамсаргүй асуулт · Ахисан</summary>

<br>

Шинэ зүйл: `Math.random()` — 0-ээс 1-ийн хооронд санамсаргүй тоо.

```js
let r = Math.floor(Math.random() * emoji.length); // 0 … 4
```

`emoji[r]`-ийг асууж, `answer[r]`-тэй харьцуул. F5 бүрт өөр асуулт гарна.

</details>

<details>
<summary><b>8. AI-ийн кодоос өөрийн массиваа олох</b></summary>

<br>

1. AI Studio → **Code** → **Ctrl+F** → `Naruto` гэж хай.
2. Таны `emoji`, `answer` массив AI-ийн код дотор байна уу?

> Таны бичсэн массив жинхэнэ апп-ын **дата** боллоо. Бүх кодыг өөрөө бичихгүй — **уншиж ойлгоод**, AI-аар сайжруулна.
