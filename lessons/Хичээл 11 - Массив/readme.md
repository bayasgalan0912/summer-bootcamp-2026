<details>
<summary><b>1. Массив гэж юу вэ</b></summary>

<br>

Олон утгыг `[ ]` дотор, `,`-оор салгаж **нэг** хувьсагчид хадгална.

```js
let anime = ["Naruto", "One Piece", "Dragon Ball"];
```

| Код | Утга | Хариу |
| --- | ---- | ----- |
| `anime[0]` | **1-р** элемент (тоолол **0**-ээс эхэлнэ) | `"Naruto"` |
| `anime[2]` | 3-р элемент | `"Dragon Ball"` |
| `anime.length` | Хэдэн элементтэй вэ | `3` |
| `anime[3]` | Байхгүй | `undefined` |

Тоо ч байж болно: `let onoo = [8, 10, 7];`

</details>

---

<details>
<summary><b>2. for + массив</b></summary>

<br>

```js
let anime = ["Naruto", "One Piece", "Dragon Ball"];

for (let i = 0; i < anime.length; i++) {
  console.log(anime[i]);
}
```

| Хичээл 10 | Өнөөдөр | Яагаад |
| --------- | ------- | ------ |
| `let i = 1` | `let i = 0` | Массив 0-ээс эхэлнэ |
| `i <= n` | `i < anime.length` | Сүүлийнх нь `length - 1` |
| `i` | `anime[i]` | `i`-р элементийг авна |

| `i` | `anime[i]` |
| --- | ---------- |
| 0 | Naruto |
| 1 | One Piece |
| 2 | Dragon Ball |
| `3 < 3` худал → зогсоно | |

</details>

---

<details>
<summary><b>3. for + if — шүүж тоолох</b></summary>

<br>

7 хоногийн температураас **хүйтэн** (0-ээс доош) өдрийг тоолъё.

```js
let temp = [5, -3, 8, -10, 2];
let huiten = 0;

for (let i = 0; i < temp.length; i++) {
  if (temp[i] < 0) {
    huiten = huiten + 1;
  }
}

console.log(huiten + " хүйтэн өдөр"); // 2
```

| `i` | `temp[i]` | `< 0`? | `huiten` |
| --- | --------- | ------ | -------- |
| | | | 0 |
| 0 | 5 | үгүй | 0 |
| 1 | -3 | **тийм** | 1 |
| 2 | 8 | үгүй | 1 |
| 3 | -10 | **тийм** | 2 |
| 4 | 2 | үгүй | **2** |

Бусад загвар:

| Юу | Эхлэх утга | Давталт дотор |
| -- | ---------- | ------------- |
| Нийлбэр | `let s = 0` | `s = s + a[i]` |
| Хамгийн их | `let max = a[0]` | `if (a[i] > max) { max = a[i] }` |

Дундаж = нийлбэр / `a.length`.

</details>
