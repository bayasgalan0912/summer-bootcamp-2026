## Түгээмэл алдаа

| Алдаа | Засвар |
| ----- | ------ |
| `i <= a.length` → сүүлд `undefined` | `<` байх ёстой |
| `let i = 1` → эхнийх алга | Массив 0-ээс |
| Дугаар `0. Dynamite` | `(i + 1)`. Хаалтгүй бол `"0" + 1` текст болно |
| Нийлбэрт `s = s + i` | `i` биш `a[i]` |
| Дундаж хачин | `s / a.length`-ийг давталтын **дараа** |
| Дасгал 6: `naruto` → буруу | `===` том, жижиг үсгийг ялгадаг. Яг бичих. AI Studio-д ялгахгүй болгосон |
| Дасгал 6: emoji, answer дараалал зөрсөн | `emoji[i]` ↔ `answer[i]` ижил байрлалд |
| AI Studio-д массив олдохгүй | AI өөр файлд (`data.ts` г.м.) хийсэн байж болно. Ctrl+F эсвэл AI-аас "Массив хаана байна?" гэж асуу |
