<summary><b>1. Copilot Agent mode</b></summary>

<br>

**Chat** нээ: `Ctrl+Alt+I` → доод хэсэгт горимыг **Agent** болго.

| Горим     | Юу хийдэг                                 |
| --------- | ----------------------------------------- |
| **Ask**   | Зөвхөн хариулна, файл өөрчлөхгүй          |
| **Agent** | Файл **үүсгэж, засна** — чи зөвшөөрнө     |

| Товч       | Хэзээ                                     |
| ---------- | ----------------------------------------- |
| **Keep**   | Өөрчлөлт таалагдсан                       |
| **Undo**   | Таалагдаагүй → буцаана                    |

<details>
<summary><b>2. Нэг prompt — бүх апп</b></summary>

<br>

Chat-д (Agent) хуулж явуул:

```text
Энэ хавтасны .js файл бүр нэг JavaScript бодлого (prompt-оор утга авч, alert-оор хариу өгдөг).
Тэдгээрийг HTML, CSS ашиглан UI-тай вэб апп болго.

- index.html — нүүр хуудас: "Миний JavaScript апп-ууд" гарчиг, бодлого бүр карт
  (нэр, 1 өгүүлбэр тайлбар, аль хичээл). Карт дарахад тухайн бодлогын хуудас нээгдэнэ.
- Бодлого бүрт тусдаа хуудас: prompt-ын оронд input, alert-ын оронд хуудсан дээр хариу.
  Хуудас бүрт "← Бүх апп" линк.
- Тооцоог .js файлаас ЯГ хэвээр ав. Анхны .js файлуудыг бүү өөрчил.
- Хоосон эсвэл буруу оролтод улаан анхааруулга.
- Бүх хуудас ижил загвартай, тод өнгө, утсан дээр ч гоё харагдана.
```

Copilot файлууд үүсгэнэ → **Keep** → `index.html`-ийг браузерт нээ.

<details>
<summary>Тооцоогоо AI-ийн кодоос ол</summary>

<br>

AI-ийн үүсгэсэн JS файлд **Ctrl+F** → `Math.floor((speed - 80) / 5)` эсвэл `% 10` гэж хай. Чиний бодсон мөр AI-ийн код дотор байна уу?

AI `document`, `querySelector` гэх мэт бичнэ — ойлгох шаардлагагүй. **Тооцоо = чиний JS.**

</details>

</details>

<summary><b>5. Netlify Drop</b></summary>

<br>

1. [app.netlify.com/drop](https://app.netlify.com/drop) → нэвтэр.
2. `js-projects` хавтсаа **чирж** оруул.
3. **Make public** дар.

5. Линкээ утсаараа нээ → 8 апп бүгд ажиллаж байна уу?

> Энэ бол `my-first-web`-ээс **тусдаа** шинэ сайт.

<summary>Дараа нь өөрчлөх бол</summary>

<br>
