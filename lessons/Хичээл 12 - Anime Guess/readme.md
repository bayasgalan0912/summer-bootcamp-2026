<details>
<summary><b>1. Anime Guess — JS</b> · хамт</summary>

<br>

Emoji-г нэг нэгээр нь `prompt`-оор асууж, зөв бол оноо нэм. Төгсгөлд нь оноог `alert`-оор гарга.

| # | Код | Юу хийнэ |
| - | --- | -------- |
| 1 | `let onoo = 0;` | Оноо 0-ээс |
| 2 | `for (let i = 0; i < emoji.length; i++) {` | Асуулт бүрээр |
| 3 | `  let hariu = prompt(emoji[i]);` | Emoji харуулж асууна |
| 4 | `  if (hariu === anime[i]) {` | Зөв үү? |
| 5 | `    onoo = onoo + 1;` | +1 оноо |
| 6 | `  }` | |
| 7 | `}` | |
| 8 | `alert("Оноо: " + onoo + " / " + emoji.length);` | Үр дүн |

> `===` том, жижиг үсгийг ялгадаг: `naruto` ≠ `Naruto`.

<details>
<summary>Бонус 1 — Зөв хариуг харуулах · Ахисан</summary>

<br>

Буруу бол `alert("Буруу! Зөв нь: ...")`. `else` хэрэгтэй.

</details>

<details>
<summary>Бонус 2 — Санамсаргүй 3 асуулт · Ахисан</summary>

<br>

Давталт 3 удаа. Удаа бүр `let r = Math.floor(Math.random() * emoji.length);` → `emoji[r]`-ийг асууж, `anime[r]`-тэй харьцуул.

</details>

<details>
<summary><b>2. Сайтдаа гаргах (AI Studio)</b></summary>

<br>

Portfolio-гоо AI Studio-д нээгээд:

```text
Сайтдаа "Миний тоглоомууд" цэс нэм. Дотор нь "Anime Guess" тоглоом.
Доорх миний JavaScript кодын anime, emoji массивыг яг хэвээр ашигла.
- Emoji-г том харуулж, хариуг input-д бичүүлнэ.
- Зөв бол +1 оноо. Буруу бол зөв хариуг харуул.
- Том, жижиг үсгийг ялгахгүй (naruto = Naruto).
- Бүх асуулт дуусахад оноог харуулж "Дахин тоглох" товч гарга.

[1-Р АЛХАМЫН КОДОО ЭНД БУУЛГА]
```

**Шалга:** emoji гарна · оноо нэмэгдэнэ · төгсгөлд оноо гарна.

<details>
<summary><b>3. AI-ийн кодоос өөрийн массиваа олох</b></summary>

<br>

1. AI Studio → **Code** → **Ctrl+F** → `Naruto` гэж хай.
2. Таны `anime`, `emoji` массив AI-ийн код дотор байна уу?
3. Тэнд **гараараа** 1 anime нэм → тоглоомд гарч байна уу?
4. `for`, `if`, `length` гэсэн үгсийг хайж ол. Юу хийж байгааг таа.

> Таны бичсэн массив жинхэнэ апп-ын **дата** боллоо. Бүх кодыг өөрөө бичихгүй — **уншиж ойлгоод**, AI-аар сайжруулна.
