## Хуваалтын тэмцээн

Проектор дээр бодит сайтын screenshot үзүүл. Баг бүр цаасан дээр хайрцаг зурж **→ / ↓** тэмдэглэнэ. 2 минут. Хамгийн олон зөв хайрцаг = 1 оноо.

| #   | Сайт                | Анхаарах                                         |
| --- | ------------------- | ------------------------------------------------ |
| 1   | Google нүүр         | Бүгд **↓** + голдоо — хамгийн амархан            |
| 2   | Netflix             | Олон **→** мөр дээрээс доош (↓ дотор →)          |
| 3   | Instagram           | Зүүн цэс ↓, гол хэсэг ↓, story-нууд →            |
| 4   | Roblox / тоглоомын сайт | Картууд → + `flex-wrap`                      |

> "↓ дотор → байж болно" гэдгийг ойлгуул — хайрцаг бүр өөрийн чиглэлтэй.

## Түгээмэл алдаа

| Алдаа                                         | Засвар                                              |
| --------------------------------------------- | --------------------------------------------------- |
| Кодоос эхлэх, зурахгүй                         | Цаасан хүснэгтээ эхлээд үзүүл                       |
| `.album`-д `display: flex` бичээд column мартах | Зураг, нэр, текст **хажуу хажууд** болно → column  |
| `.cover`-ийн emoji голдоо орохгүй             | Хоёулаа: `justify-content` + `align-items: center` |
| `.app` ↓ гэж бодох                            | Цэс ба гол хэсэг **хажуу хажууд** → row            |
