# Хичээл 5 — Багшид

**Зорилго:** Хоосон файлаас бүтэн хуудас бүтээж сурах — **эхлээд хуваалт, дараа нь элемент**. Эцэст нь бүх хуудсаа холбоод интернэтэд гаргаж, HTML/CSS хэсгийг бодит бүтээлээр дуусгана.

**Гол санаа (дахин дахин хэл):** "Эхлээд **хайрцаг**, дараа нь **агуулга**", "Алхам бүрийн дараа **хадгалаад браузерт хар**".

## Яагаад хуваалт эхлээд?

| Элемент эхлээд                                          | Хуваалт эхлээд ✅                                        |
| ------------------------------------------------------- | ------------------------------------------------------- |
| Бүх зүйл доош цувна → дараа нь `div`-д хийх хэрэгтэй   | Хайрцаг бэлэн → агуулгаа **зөв газарт нь** бичнэ         |
| Таг хайчилж зөөхөд `</div>` алдагдаж хуудас эвдэрнэ    | Хаалт аль хэдийн байрандаа                              |
| Эхний 40 минут хуудас муухай → урам хугарна            | 10 минутад YouTube-ийн хэлбэр харагдана                 |

Улаан хүрээ (`div { border }`) нь хайрцаг бүрийг **нүдэнд харагдуулна** — нэг мөрөөр нэмж, нэг мөрөөр арилгана.

## Түгээмэл алдаа

| Алдаа                                           | Засвар                                            |
| ----------------------------------------------- | ------------------------------------------------- |
| `header`, `main` гэсэн үгийг устгахаа мартсан   | Хуудасны дээд буланд "header" гэж харагдана → устга |
| Видео 1 мөрөнд багтахгүй, хажуу тийш гүйнэ      | `.videos`-д `flex-wrap: wrap`                     |
| Хуулсан видео `.videos`-ийн гадна гарсан         | Улаан хүрээгээр шалга — бүгд нэг хүрээн дотор уу? |
| Netlify дээр нүүр хуудас гарахгүй               | `my-first-page.html` → `index.html` болгосон уу? Цэсний `href` ч мөн |
| Видео дарахад юу ч болохгүй                     | `<a class="video" href="...">` — хаяг бүтэн, `</a>`-аар хаагдсан уу |
| Icon гарахгүй                                    | Хаягийн дундах нэр зөв эсэх (`music_note`, зайгүй)  |
| Netlify дээр зураг гарахгүй                     | `src="C:\..."` → `src="job.jpg"`, зураг хавтсанд байгаа эсэх |
