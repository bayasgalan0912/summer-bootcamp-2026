<summary>3️⃣ <b>🌍 Апп хөгжүүлэлтийн ертөнц</b> ⏱ 15 мин</summary>

**Утасны апп хаанаас ирдэг вэ?**

```
Хөгжүүлэгч код бичнэ  →  App Store / Play Store  →  чиний утас
```

**3 төрлийн апп:**

| Төрөл | Тайлбар | Жишээ |
| --- | --- | --- |
| 🌐 **Web app** | Браузераар нээдэг. Суулгах шаардлагагүй | Round 1-д хийсэн сайт |
| 📱 **Native app** | Утсанд суудаг. iPhone-д Swift, Android-д Kotlin — **2 өөр код бичнэ 😩** | Instagram, TikTok |
| ⚡ **Cross-platform** | **1 код → 2 платформ.** Энэ бол манай зам | React Native + Expo |

**Яагаад Expo?**

- 1 удаа бичээд iPhone, Android хоёуланд нь ажиллана
- **Expo Go** — App Store-т тавихгүйгээр утсан дээрээ шууд туршина
- Код өөрчлөгдөх бүрт утас чинь **2–3 секундэд** шинэчлэгдэнэ

**Апп бүтээх багт хэн байдаг вэ?**

| Үүрэг | Юу хийдэг вэ |
| --- | --- |
| 🎯 Product owner | «Юу бүтээх вэ, хэнд зориулах вэ» гэдгийг шийднэ |
| 🎨 Designer | Дэлгэц ямар харагдахыг зурна |
| 💻 Developer | Код бичнэ |
| 🧪 Tester | Эвдэрч байна уу гэдгийг шалгана |

> 🔑 **Round 2-ийн гол зүйл:** Чи **Product owner + Designer + Tester**.
> Чиний **agent** бол **Developer**. Код чи биш, тэр бичнэ.

✅ Web app, native app, cross-platform 3-ын ялгааг найздаа тайлбарлаж чадна

</details>

<details>
<summary>4️⃣ <b>🤖 Agentic AI гэж юу вэ?</b> ⏱ 15 мин</summary>

Round 1-д AI Studio-той **чатлаж** байсан. Agent бол өөр.

| | 💬 Чат AI (Round 1) | 🤖 Agent (Round 2) |
| --- | --- | --- |
| Юу хийдэг | Хариу **бичиж өгнө** | Файлыг **өөрөө засна** |
| Терминал | Ашиглаж чадахгүй | **Команд ажиллуулна** |
| Шалгалт | Чи хуулж тавина | **Өөрөө ажиллуулж шалгана** |
| Алдаа | Чи олно | **Алдаагаа өөрөө уншиж заслаа** |

**Агентын 4 алхамын гогцоо — хичээл бүрт хэрэглэнэ:**

```
1️⃣ PROMPT    → Юу хүсэж байгаагаа agent-д тодорхой хэл
2️⃣ BUILD     → Agent код бичнэ, утас чинь 2 секундэд шинэчлэгдэнэ
3️⃣ VERIFY    → 👀 УТСАН ДЭЭРЭЭ шалга — хүссэн шиг болов уу?
4️⃣ RE-PROMPT → Болоогүй бол «би юу харж байна»-г хэл, засуул
```

> ⚠️ **Agent чиний утсыг мэдрэх чадваргүй.** Товч хэт жижиг үү, чирэхэд гацаж байна уу — үүнийг зөвхөн **ЧИ** мэднэ. Тиймээс **tester** нь чи.

✅ Чат AI болон agent-ийн 3 ялгааг хэлж чадна

## 🛡️ AI Smart & Safe — «Зөвшөөрөх үү?» ⏱ 10 мин

Agent ажиллахдаа чамаас зөвшөөрөл асууна. Хаа сайгүй **Yes** дарж болохгүй.

| Agent юу гэж асуувал | Хариу |
| --- | --- |
| «Энэ файлыг засах уу?» (төслийн доторх) | ✅ Тийм |
| «`npm install ...` ажиллуулах уу?» | ✅ Тийм |
| «Файл **устгах** уу?» | 🟡 Юуг устгахыг нь **уншаад** шийд |
| «Бүх зөвшөөрлийг автоматаар өг үү?» (auto-approve) | ❌ **ҮГҮЙ** |
| Төслөөс **гадуурх** файлд гар хүрэх | ❌ **ҮГҮЙ** — багшид хэл |

> 🧠 Дүрэм: **Ойлгоогүй зүйл дээр Yes дарж болохгүй.** Асуу.

`✅ I can…` Agent-ын зөвшөөрлийн асуултад юунд Тийм, юунд Үгүй гэхээ мэднэ.
