# Claude Code: Кодын агент

## 1. Удиртгал (Introduction)

- Slide: _(нэмэгдэнэ)_

### 1.1 Claude Code-ийн тухай

- **Кодын агент:** Терминал, IDE (VS Code, JetBrains) болон вэб дээр ажилладаг, таны кодын сантай (repo) шууд ажиллах чадвартай AI агент.
- **Ялгаа:** Зөвхөн код санал болгодог autocomplete биш — файл уншиж, засаж, тест ажиллуулж, git commit хийж, бүхэл даалгаврыг эхнээс нь дуустал гүйцэтгэдэг.
- **Хэн ашиглах вэ:** Зөвхөн хөгжүүлэгч биш — вэб хуудас, автоматжуулалтын скрипт, өгөгдөл боловсруулалт хийхийг хүссэн хэн бүхэнд.

### 1.2 Тохиргоо (Setup)

- [**Download**](https://claude.com/download) — Desktop апп доторх Claude Code таб, эсвэл терминалд `npm install -g @anthropic-ai/claude-code`
- IDE extension: VS Code / JetBrains-д суулгаж болно.

## 2. Үндсэн ойлголтууд (Key Concepts)

### 2.1 CLAUDE.md

Төслийн зааварчилгааны файл. **Дүрмээ нэг удаа бичихэд Claude бүх ажиллагаанд мөрдөнө.**

```markdown
# CLAUDE.md (жишээ)

- Монгол хэлээр тайлбарла (код, нэршил англиар)
- Өөрчлөлт хийхээс өмнө төлөвлөгөөгөө танилцуул
- Файл устгахын өмнө заавал асуу
```

### 2.2 Context Window

Claude таны репог самбар шиг уншина. **Хэт их эмх замбараагүй мэдээлэл = муу үр дүн.** Тодорхой контекст → сайн код. Шаардлагагүй файлуудыг цэвэрлэж, даалгавраа тодорхой өг.

### 2.3 Plan Mode

Claude код бичихээс өмнө шийдлээ бүхэлд нь төлөвлөнө. **Архитектур эхэнд, гүйцэтгэл дараа нь.** Том даалгавар дээр эхлээд Plan Mode ашиглавал алдаа эрс багасна. (Cowork-ийн [PRD-first](./claude-cowork.md) зарчимтай ижил санаа.)

### 2.4 MCP (Model Context Protocol)

Claude-г GitHub, Slack, өгөгдлийн сан зэрэг хэрэгсэлтэй холбоно. **Нэг интерфэйс, бүх stack холбогдоно.**

### 2.5 Subagents

Claude судлах, хайх, тест хийх зэрэгт **зэрэгцээ ажиллах жижиг агентуудыг** үүсгэнэ. Том кодын санг судлахад цаг хэмнэнэ.

## 3. Дасгал ажил (Exercises)

| # | Дасгал | Түвшин | Ашиглах ойлголт |
|---|--------|--------|-----------------|
| 1 | Файл цэгцлэгч скрипт | ⭐ | Энгийн даалгавар, файлтай ажиллах |
| 2 | Хувийн Portfolio вэб хуудас | ⭐⭐ | CLAUDE.md, Plan Mode |
| 3 | Шалгалтын бэлтгэл Quiz апп | ⭐⭐⭐ | Plan Mode, iteration |

### Дасгал 1: Файл цэгцлэгч (Downloads Organizer) ⭐

- **Даалгавар:** Downloads хавтас доторх файлуудыг төрлөөр нь (зураг, PDF, видео...) автоматаар хавтаслан цэгцэлдэг скрипт бичүүлж ажиллуулах.
- **Яагаад:** Өдөр тутмын бодит асуудал — кодын мэдлэг шаардахгүйгээр Claude Code-ийн "файлтай шууд ажиллах" чадварыг мэдрэх.

**Алхам алхмаар:**

1. **Claude Code нээх** — Downloads хавтас руу чиглүүлнэ.
2. **Даалгавраа өгөх** — доорх prompt-ыг ашиглана.
3. **Төлөвлөгөөг нь шалгах** — юу хийхээ эхлээд жагсаахыг хүс (ямар файл хаашаа шилжих).
4. **Зөвшөөрч ажиллуулах** — үр дүнг Finder дээр шалгана.
5. **Сайжруулах** — "7 хоногоос хуучин screenshot-уудыг тусад нь архивла" г.м. нэмэлт дүрэм өгнө.

**Жишээ Prompt:**

```text
Downloads хавтсыг цэгцэл:
- Зургуудыг Images/, PDF-үүдийг Documents/, видеог Videos/ хавтсанд
- Устгахгүй, зөвхөн шилжүүл
- Эхлээд ямар файл хаашаа шилжихийг жагсааж, надаас зөвшөөрөл ав
```

### Дасгал 2: Хувийн Portfolio вэб хуудас ⭐⭐

- **Даалгавар:** Өөрийн CV/portfolio-г нэг хуудас вэбсайт болгон барьж, локал дээр нээж үзэх.
- **Ашиглах ойлголт:** CLAUDE.md (2.1), Plan Mode (2.3).

**Алхам алхмаар:**

1. **Шинэ хавтас үүсгэх** — `my-portfolio` гэх мэт.
2. **CLAUDE.md бичих** — хэл, стиль, дүрмээ тодорхойлно (жишээ 2.1-т).
3. **Plan Mode-оор эхлэх** — код бичихээс өмнө бүтэц, хэсгүүдийг төлөвлүүлнэ.
4. **Мэдээллээ өгөх** — нэр, туршлага, төсөл, холбоо барих мэдээлэл.
5. **Барьж, нээж үзэх** — HTML файлыг browser дээр шалгана.
6. **Давталтаар сайжруулах** — "Dark mode нэм", "Мобайлд тохируул" г.м.

**Жишээ Prompt:**

```text
Надад зориулж нэг хуудас portfolio вэбсайт барь (Plan Mode-оор эхэл):
- Хэсгүүд: Танилцуулга, Туршлага, Төслүүд, Холбоо барих
- Цэвэрхэн, минимал дизайн, мобайлд тохирсон
- Нэг index.html файл, гадны сан ашиглахгүй
Эхлээд бүтцээ танилцуулаад, миний зөвшөөрлөөр код бич.
```

### Дасгал 3: Шалгалтын бэлтгэл Quiz апп ⭐⭐⭐

- **Даалгавар:** Лекцийн тэмдэглэл, конспектоос автоматаар асуулт үүсгэдэг интерактив Quiz апп барих.
- **Ашиглах ойлголт:** Plan Mode, файл боловсруулалт, iteration.
- **Хэнд хэрэгтэй:** Оюутан, суралцагчид — өөрийн хичээлийн материалаар шалгалтад бэлдэх.

**Алхам алхмаар:**

1. **Материалаа бэлдэх** — лекцийн тэмдэглэл (PDF, markdown, текст)-ээ нэг хавтсанд хийнэ.
2. **Plan Mode-оор төлөвлүүлэх** — асуулт үүсгэх логик, аппын бүтцийг эхлээд гаргуулна.
3. **Асуулт үүсгүүлэх** — материалаас 20-30 сонгох асуулт (multiple choice) гаргуулна.
4. **Quiz апп барих** — асуултуудыг ашигладаг интерактив HTML апп бүтээлгэнэ.
5. **Туршиж сайжруулах** — оноо тооцох, буруу хариулсан асуултыг давтуулах функц нэмнэ.

**Жишээ Prompt:**

```text
notes/ хавтас доторх лекцийн тэмдэглэлүүдээс шалгалтын бэлтгэл
Quiz апп барь:
1. Материалаас 25 сонгох асуулт үүсгэ (4 хариулттай, 1 зөв)
2. Интерактив HTML апп: асуулт бүрийн дараа зөв хариу + тайлбар
3. Төгсгөлд нь оноо + сул сэдвүүдийн дүгнэлт харуул
Plan Mode-оор эхэлж, бүтцээ танилцуул.
```

## 4. Дүгнэлт

Claude Code бол зөвхөн хөгжүүлэгчийн хэрэгсэл биш. CLAUDE.md-ээр дүрмээ тогтоож, Plan Mode-оор төлөвлүүлж сурвал өдөр тутмын файл цэгцлэлтээс эхлээд бүрэн хэмжээний апп барих хүртэл ажлыг даалгаж болно.
