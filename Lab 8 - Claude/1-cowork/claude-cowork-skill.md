# Claude AI "Skill" ашиглан өдөр тутмын ажлаа автоматжуулах нь: Алхам алхамаар зааварчилгаа

Энэхүү хичээлээр Claude AI-ийн "Skill" функцийг ашиглан давтагддаг ажлуудыг хэрхэн нэг удаагийн заавраар автоматжуулах талаар суралцах болно.

---

## 1. Claude Skill гэж юу вэ?

**Claude Skill** гэдэг нь таны өдөр тутам хийдэг, дахин дахин давтагддаг үйлдлүүдийг (жишээ нь: ижил форматаар текст бичих, зурагт зориулсан промт бэлдэх гэх мэт) ганцхан удаа зааварчилгаа болгон хадгалж, дараа нь богино командаар шууд ажиллуулах боломжтой функц юм,.

Энэхүү файл нь дотроо тайлбар (description) болон зааварчилгаа (instruction) гэсэн хэсгүүдээс бүрддэг.

## 2. Skill үүсгэх цэс рүү орох

1.  **Claude.ai** вэбсайт руу нэвтэрнэ.
2.  Зүүн доод буланд байх өөрийн нэр дээр дарж **"Customize Claude"** цэсийг сонгоно.
3.  Нээгдэх цонхноос **"Skills"** хэсгийг сонгоно.
4.  Шинээр үүсгэх бол **"+" (нэмэх)** тэмдэг дээр дарж, **"Create Skill"** сонголтыг дарна.

## 3. Skill-ийг интерактив хэлбэрээр бүтээх

Skill-ийг өөрөө гараар бичих эсвэл Claude-той хамтран (Create) үүсгэж болно. Хамтарч үүсгэх нь илүү хялбар байдаг.

1.  **"Create"** товчийг дарж **"Skill Creator"**-той яриа өрнүүлж эхэлнэ,.
2.  **Ажлаа тайлбарлах:** Claude танаас "Ямар ажлыг автоматжуулахыг хүсэж байна вэ?" гэж асууна.
    - _Жишээ нь:_ "Би бүтээгдэхүүний зураг оруулахад түүнд зориулсан 3 төрлийн (синематик, лайфстайл, студи) пострын промт бэлддэг Skill үүсгэмээр байна" гэж хэлж болно,.
3.  **Асуултад хариулах:** Claude таны ажлын стандартыг ойлгохын тулд дараах зүйлсийг асууна:
    - Ямар загвар, хэв маягтай байх вэ?
    - Зургийн хэмжээ, харьцаа ямар байх вэ? (Жишээ нь: Instagram 1:1)
    - Ямар хэл дээр гаргах вэ? (Жишээ нь: Монгол тайлбартай, англи промт),

## 4. Skill-ийг турших, хадгалах

1.  **Туршилт:** Claude таны өгсөн мэдээлэлд үндэслэн Skill-ийг бэлдэж өгнө. Та шууд файл (зураг эсвэл текст) аплоуд хийж, Skill хэрхэн ажиллаж байгааг шалгана,.
2.  **Засах:** Хэрэв үр дүн таалагдахгүй бол "Ийм нэмэлт заавар оруулъя" эсвэл "Энэ хэсгийг нь өөрчилье" гэж Claude-д хэлж шинэчлүүлнэ.
3.  **Хадгалах:** Бүх зүйл бэлэн болмогц баруун дээд буланд байх **"Save Skill"** товчийг дарна.

## 5. Skill-ийг ашиглах

Skill-ээ хадгалсны дараа та үндсэн чат дээрээ дараах байдлаар ашиглана:

1.  Шаардлагатай файлаа (жишээ нь бүтээгдэхүүний зураг) хавсаргана.
2.  Чатны хэсэгт **"/" (slash)** тэмдэг дарахад таны үүсгэсэн Skill-үүдийн жагсаалт гарч ирнэ.
3.  Хэрэгтэй Skill-ээ сонгоод илгээхэд Claude автоматаар зааврын дагуу ажлыг гүйцэтгэнэ.

## 6. Skill-ийг бусадтай хуваалцах (Экспортлох)

Та өөрийн бүтээсэн Skill-ээ файл хэлбэрээр татаж аваад өөр хүнд өгөх эсвэл өөр аккаунт дээрээ суулгах боломжтой.

- **Татаж авах:** Skill-ийн тохиргоо доторх **"Download"** товчийг дарж `.skill` өргөтгөлтэй файл болгон авна.
- **Суулгах:** Өөр хүн "Create Skill" цэс рүү ороод **"Upload Skill"** товчийг дарж таны өгсөн файлыг уншуулснаар шууд ашиглах боломжтой болно.

---

## 7. Дасгал: Хувцасны зураг авалтын постер prompt үүсгэгч Skill

**Зорилго:** Skill Creator-той ярилцаж өөрийн мэргэжлийн Skill үүсгэх → хадгалах →
дуудаж ашиглах → гарсан prompt-оор **Gemini** дээр бодит зураг гаргах. Нэг дасгал дотор
Skill-ийн бүтэн мөчлөг (үүсгэх → хадгалах → ашиглах → өөр AI руу дамжуулах) туршигдана.

**Кейс:** Та хувцасны дизайнер. Хийсэн хувцасныхаа зураг болон загвар өмсөх моделийн
зургийг өгөхөд зураг авалтын постерын **2–3 өөр хувилбарын prompt** бэлдэж өгдөг Skill.
Үр дүн нь: (1) Claude дотор шууд харагдах **зураг/artifact**, (2) Gemini-д хуулж тавихад
бэлэн **англи prompt**.

---

### Алхам 1 — Skill Creator нээх

1. Claude.ai → зүүн доод буланд нэр дээрээ дарж **Customize Claude**.
2. **Skills** → **"+"** → **Create Skill** → **Create** товч (Skill Creator-той яриа эхэлнэ).
3. Skill Creator эхлээд асууна: _"Ямар skill хийхийг хүсэж байна вэ? Юу хийдэг, хэзээ
   ашиглах skill байх ёстойг товч тайлбарлаж өгөөч."_

### Алхам 2 — Skill Creator-т өгөх эхний prompt

```text
Би хувцасны дизайнер мэргэжилтэй. Дараах ажлыг автоматжуулах skill үүсгэмээр байна:

Оролт (input):
- Миний хийсэн хувцасны зураг (1 буюу хэд хэдэн)
- Загвар өмсөх моделийн зураг эсвэл моделийн тайлбар (нас, хүйс, өндөр, төрх)
- Нэмэлт: улирал, брэндийн өнгө аяс, зорилтот хэрэглэгч

Гаралт (output):
1. Зураг авалтын постерын 2-3 өөр КОНЦЕПЦ (жишээ: студи минимал, гудамжны lifestyle,
   редакшн/editorial). Концепц бүрд: сэдэв, байршил, гэрэлтүүлэг, өнгөний палитр,
   камерын өнцөг/линз, моделийн поз, ерөнхий сэтгэгдэл.
2. Концепц бүрийн бэлэн PROMPT — англи хэлээр, Gemini (Nano Banana) дээр шууд
   хуулж тавихад ажиллах, зургийн харьцаа (aspect ratio) заасан байх.
3. Монгол хэлээр богино тайлбар: яагаад энэ концепц энэ хувцаснд тохирч байгаа.

Дүрэм:
- Хувцасны бодит хэлбэр, өнгө, материалыг ӨӨРЧЛӨХГҮЙ — зөвхөн орчин, гэрэл, поз солино.
- Моделийн царай, биеийн хэлбэрийг гажуудуулахгүй.
- Prompt бүр 60-120 үгийн хооронд, хэт ерөнхий үг (beautiful, amazing) хэрэглэхгүй.
- Гаралтын формат: концепц бүрийг тусад нь гарчиглаж, prompt-ыг code block дотор өгнө.
```

### Алхам 3 — Тодруулах асуултад хариулах

Skill Creator дараах маягийн асуулт асууна — хариулах тусам заавар нарийсна:

| Асуулт | Жишээ хариулт |
|---|---|
| Ямар харьцаатай зураг гаргах вэ? | Instagram пост 4:5, story 9:16 |
| Ямар хэв маяг давамгайлах вэ? | Цэвэрхэн, editorial, хэт филтэргүй |
| Гаралт ямар хэл дээр байх вэ? | Prompt англи, тайлбар монгол |
| Хэдэн хувилбар гаргах вэ? | Үргэлж 3 |
| Юуг зайлсхийх вэ? | Хиймэл plastic арьс, хувцасны хэлбэр гажих |

### Алхам 4 — Турших ба хадгалах (Save Skill)

1. Skill Creator markdown зааврыг бэлдэж өгнө — уншиж шалгана.
2. **Тэр даруй турших:** хувцасныхаа зураг + моделийн зургийг чат руу хавсаргаад
   "Үүн дээр туршаад үз" гэнэ. 3 концепц + 3 prompt гарч ирэх ёстой.
3. Таарахгүй бол засварлана: _"Prompt-уудыг илүү тодорхой болго"_, _"Байршлыг
   Монголын хотын орчноор өг"_, _"Гэрэлтүүлгийн тайлбарыг дэлгэрүүл"_.
4. Тохирсон үед баруун дээд булангийн **"Save Skill"** товчийг дарж хадгална.
   Нэр: `fashion-shoot-prompt`.

### Алхам 5 — Skill-ээ ашиглаж prompt авах

1. **Шинэ чат** нээнэ (Skill шинэ чатад л цэвэр ажиллана).
2. Хувцасны зураг + моделийн зургаа хавсаргана.
3. Чат бичих хэсэгт **`/`** дараад `fashion-shoot-prompt` Skill-ээ сонгоно.
4. Богино нэмэлт мэдээлэл өгнө:

```text
/fashion-shoot-prompt
Хавсаргасан: хүрэн ноосон пальто (миний дизайн) + моделийн зураг.
Улирал: намар-өвөл. Зорилтот хэрэглэгч: 25-35 насны хотын эмэгтэй.
Брэндийн өнгө аяс: дулаахан, тайван, эрхэмсэг. Instagram 4:5.
```

5. Claude 3 концепц + 3 англи prompt-ыг code block-той гаргана. Prompt-уудаа хуулж авна.

### Алхам 6 — Prompt-оор Gemini дээр зураг гаргах

1. [gemini.google.com](https://gemini.google.com) руу орно.
2. Шинэ чат нээж, **хувцасны зураг болон моделийн зургаа хавсаргана**
   (зөвхөн текст prompt өгвөл өөр хувцас зурчихна).
3. Claude-аас авсан **1-р prompt**-оо хуулж тавиад илгээнэ.
4. Гарсан үр дүнг харж, дараагийн prompt-уудаа мөн туршина (нийт 2-3 постер).
5. Засвар шаардвал Gemini дотроо шууд залруулна:
   _"Keep the coat exactly as in the reference photo, change only the background to a
   rainy Ulaanbaatar street at dusk."_

---

### Хүлээгдэж буй үр дүн (Deliverable)

- ✅ Хадгалагдсан `fashion-shoot-prompt` Skill (Skills жагсаалтад харагдана)
- ✅ Skill-ээс гарсан **3 англи prompt** (текстээр хадгална)
- ✅ Gemini дээр гаргасан **2-3 постерын зураг**
- ✅ Skill-ийн `.skill` файл (**Download** товчоор татаж, хажуугийн оюутантай солилцоно)
