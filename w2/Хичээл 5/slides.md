### Слайд 5 — 🐛 "Алдаатай JSON" ЗАСАХ тэмцээн (⏱️ 8 мин)

🏁 **[jsonlint.com](https://jsonlint.com)** — 4 үе, бүгд эвдэрсэн. Зас → Validate → 🟢

| Үе   | Алдаа                          |
| ---- | ------------------------------ |
| 🥊 1 | Таслал `,` алга                |
| 🥊 2 | Хашилтгүй key + дан хашилт     |
| 🥊 3 | `]` хаагаагүй                  |
| 🥊 4 | Илүү таслал (trailing comma) ×2 |

🏆 4/4 → **🧩 JSON Detective цол**

**🔧 Багшид:** Үеийг **дэлгэцээр нэг нэгээр** гарга, хос бүр өөрийн компьютер дээр засна. Үе тутам ~1.5 мин цаг барь, давсан хосын тоог самбарт тэмдэглэ.

### Слайд 7б — 🖼️ Интернэтээс ЗУРАГ нэмэх (ХЭСЭГ 2.4)

**Зургийг татахгүй — ХАЯГИЙГ л авна:**

1️⃣ Зураг дээр **баруун товч** → **Copy image address**
2️⃣ ✅ **Шинэ tab-д paste хийж ШАЛГА** — зөвхөн зураг гарвал зөв
3️⃣ Sheets-ийн `image` баганад тавь

> ## 💡 **Google-ээс авсан зураг олон дор АЖИЛЛАХГҮЙ**
>
> Сайтууд зургаа гадны хуудсанд харуулахыг блоклодог.
> → **[Wikipedia](https://www.wikipedia.org)**-ээс ав! `upload.wikimedia.org` хаяг бараг үргэлж ажиллана. ✅

🛡️ Кредит өг · насанд тохирсон зураг · **жинхэнэ хүний хувийн зураг БОЛОХГҮЙ**

**🔧 Багшид:** Wikipedia-аас зураг авахыг **дэлгэцээр 1 удаа үзүүл** (3 товшилт). Бас зориуд Google-ээс авсан **ажиллахгүй** зургийг үзүүлж, яагаад болохгүйг харуул — тэгвэл дараа нь өөрсдөө шийднэ. Цаг хүрэхгүй бол **3–5 асуултад л** зураг нэмүүл.

### Слайд 9 — 🕹️ Шинэ горим = шинэ ДАТА (ХЭСЭГ 4)

⚽ Хөлбөмбөг · 🎬 Кино · 🎵 Хөгжим · 🇲🇳 Монголын түүх · 🎮 Тоглоом/meme

→ "Шинэ горим гаргахад **кодоо дахин бичихгүй**. Зөвхөн **шинэ дата** нэмнэ."

> 🖼️ **Энэ горимд зураг нь ГОЛ атраксион.** Аниме бол emoji-гоор таахад хялбар — харин Messi, кино poster, album cover бол **зураг**. Wikipedia дээрээс ав!

**🪆 2 горимын дата хэрхэн зэрэгцэх вэ?** → **Object дотор array-ууд:**

```text
{ "anime": [ {…}, {…} ], "football": [ {…}, {…} ] }
```

→ "Яг Boss Battle Үе 3, 4 шүү дээ! 😏"
