## 🎤 Live scripts (анги дунд хэлэх)

**Хүснэгт = JSON (Слайд 4) — хамгийн чухал 30 секунд:**

> "Excel эсвэл Google Sheets хэрэглэж үзсэн хүн гараа өргө… За. Тэгвэл та нар JSON-ыг аль хэдийн мэддэг байна. Хараарай — хүснэгтийн **нэг мөр** бол JSON-ий **нэг `{ }`**. Бүтэн хүснэгт бол **нэг `[ ]`**. Болоо. Тэр л байна. Тиймээс өнөөдөр бид гараар JSON бичихгүй — **хүснэгтээр** бичээд, нэг товч дараад JSON болгоно."

**Алдаатай JSON тэмцээний өмнө:**

> "Одоо би та нарт **эвдэрсэн** JSON өгнө. Компьютер уншиж чадахгүй. Та нарын ажил бол эмч болж эмчлэх. JSONLint дээр Validate дарвал алдаа хаана байгааг **мөрийн дугаараар** хэлж өгнө. 1.5 минут. Хэн 🟢 гаргах бол?"

**Үе 4-ийн дараа (iterate-ийг заах):**

> "Ажигласан уу — JSONLint эхлээд зөвхөн **1 алдаа** заасан. Зассаны дараа дахин Validate дархад **2 дахь нь** гарч ирсэн. Жинхэнэ програмчлагч ингэж ажилладаг: зас → шалга → зас → шалга. Нэг дор бүгдийг олох гэж бүү зүтгэ."

**ХЭСЭГ 3-ын Checkpoint (заавал):**

> "Бүгдээрээ зогсоо. Тоглоомоо тогло. Зөв хариулахад оноо нэмэгдэж байвал **гараа өргө**." → **Гар өргөөгүй хосыг тоол.** 3-оос дээш байвал бүх ангийг зогсоож хамт зас. Ажиллаагүй тоглоом дээр механик нэмбэл юу ч болохгүй.

**GAME FEEL SHOP-ийн өмнө (гол сургалтын мөч):**

> "Одоо би та нарт промпт **өгөхгүй**. Зөвхөн зорилго өгнө. Яагаад гэвэл жинхэнэ ур чадвар бол код бичих биш, **AI-д юу хүсэж байгаагаа тодорхой хэлж чадах**. Гацвал hint нээж болно — гэхдээ эхлээд **өөрөө 2 удаа** туршиж үз."

**ХЭСЭГ 5.3 — ангийг зогсоо:**

> "Гараа авраад над руу хар. Чиний тоглоом одоо 2 горимтой. Гэхдээ чи 2 дахь тоглоом бичсэн үү? Үгүй. Хугацаа, амь, оноо, товч, дизайн — **бүгд ижил код**. Зөвхөн **дата** өөр. **Код бол дүрэм. Дата бол агуулга.** Minecraft-д шинэ mod, Roblox-д шинэ map нэмэхэд тоглоомыг дахин бичдэггүй — яг ийм учраас."

## ✅ Session-ийн амжилтын шалгуур

Хос бүр session төгсөхөд:

1. `{ }` object ба `[ ]` array-ийн ялгааг **өөрийн үгээр** тайлбарлаж чадна.
2. "Хүснэгтийн 1 мөр = 1 `{ }`" зүйрлэлийг хэлж чадна.
3. Алдаатай JSON-ыг JSONLint-ээр **өөрөө засаж** чадна (таслал, хашилт, хаалт, trailing comma).
4. Sheets → CSVJSON → JSONLint урсгалыг **бие даан** гүйцэтгэж чадна (ХЭСЭГ 4-т үүнийг заавар бага уншиж хийсэн).
5. 🖼️ Интернэтээс **зургийн хаяг авч** датадаа нэмж, тоглоомд гаргаж чадсан (Wikipedia vs Google-ийн ялгааг мэднэ).
6. **Тоглогддог** тоглоомтой: 2 горим, горим тутамд 8+ асуулт, оноо/амь/хугацаа, зураг ажиллана.
7. Өөрийн **3 локал асуулт** нэмсэн — хилийн дүрэм зөрчөөгүй.
8. Дор хаяж **1 механикийн промптыг өөрөө бичсэн** (hint нээгээгүй). ⭐
9. **"Код = дүрэм, дата = агуулга"**-г өөрийн үгээр хэлж чадна. ⭐
10. 🥉 Bronze quest бүрэн дүүрсэн + Vercel дээр publish → Discord.

> 📊 **Багш дүгнэхдээ:** 3, 4, 5, 8, 9 бол өнөөдрийн **гол** зорилтууд. Тоглоом гоё болсон ч эдгээр гүйцэгдээгүй бол хичээл бүтэлгүйтсэн гэж үз — тоглоом бол хэрэгсэл, JSON дата бол сургалтын агуулга.
