<details>
<summary><b>🧠 AI-н нууц: Token, Context, Limit (унш заавал биш, гэхдээ ойлгоход амар)</b></summary>

### Token гэж юу вэ?

**Token** = AI үгийг бүхлээр нь биш, **жижиг хэсгүүдэд** хувааж уншдаг. **Лего** шиг бод — үг бүр нэг буюу хэдэн "тоосго"-оос бүрдэнэ. 🧱

```
"AI"            → 1 token   🧱
"pizza"         → 2 token   🧱🧱  (piz + za)
"hamburger"     → 3 token   🧱🧱🧱 (ham + bur + ger)
"Сайн байна уу" → ~4 token  🧱🧱🧱🧱
```

**📏 Хэр их вэ? (ойролцоогоор):**

| Текст | ~Token |
| --- | --- |
| 1 эможи эсвэл богино үг | ~1 |
| 1 өгүүлбэр (chat мессеж) | ~15–20 |
| 1 догол мөр | ~100 |
| 1 хуудас эссэ | ~500 |
| 📕 Harry Potter ном 1 | ~100,000 |

> 🔑 Чи бичих болгонд, AI хариулах болгонд token зарцуулна. **Урт яриа = их token = limit хурдан дуусна.**

<details>
<summary>🧩 Context гэж юу вэ?</summary>

**Context** = AI нэг удаад "санаж" чадах хэмжээ.

🧠 **Зүйрлэл:** Context-ийг **самбар** гэж бод. Асуулт, өмнөх яриагаа дээр нь бичнэ. Самбар дүүрвэл хамгийн эхэнд бичсэн зүйл **арилж** эхэлдэг — AI тэгэхээр эхэн үеэ "мартдаг".

**📏 Хэр том вэ?** Gemini нэг удаад **~1,000,000 token** (≈ 📕 Harry Potter **~10 ном** зэрэг!) санаж чадна — самбар чинь **асар том**. Гэхдээ маш урт ярианд бүрэн дүүрч, эхнийхээ мартаж эхэлнэ.

</details>

<details>
<summary>🚦 Usage limit гэж юу вэ?</summary>

**Usage limit** = AI Studio-г **үнэгүйгээр** ашиглах дээд хэмжээ. Чи өөрийн Google хаягтай учир **өөрийн гэсэн** limit-тэй — найзуудтайгаа хуваалцдаггүй.

📌 **Нэг "асуулт" гэж юу вэ?** Чи нэг мессеж бичээд илгээх бүр = **1 асуулт**. AI-н хариулт тусад нь тоологддоггүй.

📊 **Хязгаарын 2 төрөл:**

- ⏱ **RPM — минутад хэдэн асуулт** (~10 орчим). Хэт хурдан дараалуулбал түр зогсоод "жоохон хүлээ" гэнэ.
- 📈 **TPM — минутад хэдэн token** болон **RPD — өдөрт хэдэн асуулт** гэсэн тогтсон тоо бас бий. Урт яриа TPM-д хурдан тулдаг.

⚠️ **"Их л байна аа" гэж бүү бод — хязгаар бодит, бас загвар бүрт ӨӨР:**

- 🪶 Хөнгөн загвар (Gemini **Flash**) → өдөрт **~500+** асуулт.
- 🧠 Хүчтэй загвар (Gemini **Pro**) → өдөрт ердөө **~10–25** асуулт!

📅 **Өдрийн квот (RPD) дуусвал** Номхон далайн цагаар шөнө дунд (Монголд ойролцоогоор үд дунд) **дахин 0-ээс** сэргэнэ — түүнийг хүртэл хүлээх хэрэгтэй.

🔄 **Эдгээр тоо байнга өөрчлөгддөг** (Google шинэ загвар гаргах бүрт). Тиймээс яг тоонд бүү найд — **хэмнэж хэрэглэх** нь хамгийн найдвартай.

🔋 **Зүйрлэл:** Утасны battery шиг — өөрийн чинь хувийн, хэт их хэрэглэвэл дуусч, дахин цэнэглэгдэх хүртэл хүлээнэ.

Яагаад хязгаартай вэ? → AI ажиллахад мөнгө/эрчим хүч их ордог + бүх хэрэглэгчид шударга байх ёстой.

> 💡 Хичээл дээр чи голдуу **минутын (RPM)** хязгаарт тулна. Тайвширч, тодорхой асуувал асуудалгүй — доорх **хэмнэх дүрмүүд** тусална.

</details>

<details>
<summary><b>💰 AI хэрэглээгээ хэмнэх арга (Usage limit) — чухал!</b></summary>

Чи өнөөдөр олон удаа турших болно. Limit-д хүрэхгүйн тулд:

| ✅ Хий                                 | ❌ Бүү хий                             |
| -------------------------------------- | -------------------------------------- |
| 🎯 Тодорхой асуу: "200 үгтэй эссэ бич" | Тодорхой бус асуулт: "туслаач" → "юунд?" → ... |
| 🆕 Шинэ сэдэвт шинэ chat нээ           | Бүх зүйлээ нэг chat-д хольж асуух      |
| ✂️ Зөвхөн хэрэгтэй текстээ оруул       | Бүтэн номыг хуулж тавих                |
| 📦 Олон асуултаа нэгтгэ                | Нэг нэгээр нь 10 удаа асуух            |
| 📏 "Богино хариул" гэж хэл             | Хязгааргүй урт хариулт гуйх            |

</details>

**Idol-ийн санаа:** 🏀 LeBron James · ⚓ Luffy (One Piece) · ⚽ Messi · 🏀 Kobe "Black Mamba" · эсвэл өөрийн дуртай хэн ч (Чингис хаан…)

<details>
<summary>1️⃣ Алхам — Google AI Studio-гаа бэлд</summary>

1. 🌐 [aistudio.google.com](https://aistudio.google.com) → Google хаягаараа нэвтэр.
2. Зүүн талаас **Playground** дар (эсвэл голын **"Code and Chat"** картыг сонго). Чат бичих талбар нээгдэнэ. (Загвар сонгох шаардлагагүй — үндсэн загвар хангалттай.)
3. Чат талбарын дээд хэсэгт **System instructions** гэсэн талбар бий. Энэ бол coach-ийнхоо **"тархи"** — энд яаж ярих, хэн байхыг нь зааварлана. (Дараагийн **Алхам 3**-д үүнийг бичнэ.)

> 💡 Хийсэн ажлаа алдахгүйн тулд дунд-дунд **Save** дарж нэр өг (ж: "LeBron Coach").

✅ **Checkpoint:** AI Studio нээгдсэн, System instructions талбараа олсон.

</details>

<details>

- Ямар зан чанартай вэ? (зоригтой, хошин, хатуу…)

<details>
<summary>3️⃣ Алхам — System prompt бич (ХАМГИЙН чухал)</summary>

AI Studio-ийн **System instructions** талбарт coach-ийнхоо зааварчилгааг бич:

```
Чи бол [IDOL-ийн нэр]. Чи [хэн болох, юугаараа алдартай].

ЗАН ЧАНАР:
- [зан чанар 1]
- [зан чанар 2]

ЯРИХ ХЭВ МАЯГ:
- [яаж ярьдаг, ямар үг хэллэгтэй]

ҮҮРЭГ:
- Надад зөвлөгөө, дэмжлэг, урам зориг өг.
- Өөрийн туршлага, амьдралын жишээн дээр тулгуурла.
- Үргэлж [IDOL]-ийн өнцгөөс хариул.

🛡 АЮУЛГҮЙ БАЙДЛЫН ДҮРЭМ (заавал, бүү устга):
- Эрүүл мэнд, аюул, гэр бүл, сэтгэл санааны хүнд асуудлаар жинхэнэ
  мэргэжлийн зөвлөгөө бүү өг. Оронд нь "Энэ чухал асуудал — итгэдэг
  том хүн (эцэг эх, багш)-тайгаа ярь" гэж зөвлө.
- Хор хөнөөлтэй, аюултай, насанд тохироогүй зүйл хэзээ ч бүү заа.
- Хэрэглэгчийн хувийн мэдээллийг (нэр, хаяг, утас) бүү асуу.

ХЯЗГААР:
- Хөгжилтэй дасгалын хувьд [IDOL]-ийн дүрд тогло, "Би AI" гэж бүү хэл.
- Гэхдээ дээрх аюулгүй байдлын дүрэм ҮРГЭЛЖ дүрээс илүү чухал.
- Найрсаг, эерэг байх.
```

> 🛡 **Чухал:** Энэ бол ЗУГААТАЙ дасгал. Coach чинь idol шиг ярьдаг ч жинхэнэ тэр хүн БИШ, AI гэдгийг санаарай. Хүнд бодит асуудлаа үргэлж итгэдэг том хүнтэйгээ ярь.

✅ **Checkpoint:** Бүх [хаалт]-ыг өөрийн idol-аар бөглөж, аюулгүй байдлын дүрмийг үлдээсэн.

</details>

- ✅ Сайн coach: "Энэ чухал асуудал — итгэдэг том хүн (эцэг эх, багш)-тайгаа ярь."
