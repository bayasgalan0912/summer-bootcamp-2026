<details>
<summary>📚 <b>Glossary — шинэ үгс</b></summary>

| Үг               | Тайлбар                                       |
| ---------------- | --------------------------------------------- |
| **JSON**         | Дата хадгалах, хуваалцах стандарт хэлбэр      |
| **Object `{ }`** | НЭГ зүйл, key–value талбартай (карт шиг)      |
| **Array `[ ]`**  | ОЛОН зүйлийн жагсаалт (playlist шиг)          |
| **Key / Value**  | Шошго → утга (`"answer": "One Piece"`)        |
| **Valid JSON**   | Дүрэм зөрчөөгүй, компьютер уншиж чадах JSON   |
| **Nested**       | Хайрцаг дотор хайрцаг (🪆 матрёшка)           |
| **Горим (mode)** | Тоглоомын өөр хувилбар — өөр дата, ижил дүрэм |
| **Дата пак**     | Тоглоомын агуулга — кодоос салангид           |

</details>
