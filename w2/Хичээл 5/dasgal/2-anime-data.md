| ✅ Болно                         | ❌ Болохгүй                             |

<details>
<summary>🖼️ <b>Дасгал 2.4 — Интернэтээс ЗУРАГ нэмэх</b> · ⏱️ ~6 мин · ✨ шинэ</summary>

> 🎯 Зөв хариулсны дараа тухайн анимийн **зураг** гарч ирвэл тоглоом хамаагүй гоё болно. Датадаа `image` талбар нэмнэ.

### 1️⃣ Зургийн ХАЯГ (URL) хэрхэн авах вэ?

Зургийг **татаж авахгүй** — интернэт дээрх **хаягийг** л авна.

1. Google Images-д хай (ж: `One Piece logo`)
2. Зураг дээр дарж **томруул**
3. Томруулсан зураг дээр **баруун товч** → **Copy image address**
   _(Монголоор: "Зургийн хаягийг хуулах")_
4. ✅ **ЗААВАЛ шалга:** шинэ tab нээж paste → Enter. **Зөвхөн зураг** гарвал зөв. Вэб хуудас гарвал буруу хаяг авсан.

> ✅ **Зөв URL:** `https://` -ээр эхэлж, `.jpg` `.jpeg` `.png` `.webp` -ээр дуусна
> ❌ **Буруу URL:** `https://www.google.com/search?...` эсвэл `data:image/...` -ээр эхэлсэн

### 2️⃣ 💡 Хамгийн найдвартай эх сурвалж — Wikipedia

Google-ээс авсан зураг **олон тохиолдолд ажиллахгүй** — сайтууд өөрсдийн зургийг гадны хуудсанд харуулахыг блоклодог. **[Wikipedia](https://www.wikipedia.org)** бол найдвартай:

1. Wikipedia-д тухайн аниме/баатрыг хай
2. Хуудасны зураг дээр дар → **баруун товч** → **Copy image address**
3. Хаяг нь `https://upload.wikimedia.org/...` -ээр эхэлнэ → ✅ бараг үргэлж ажиллана

### 3️⃣ Sheets-д `image` багана нэм

| id  | emojis  | answer    | options              | image                                        |
| --- | ------- | --------- | -------------------- | -------------------------------------------- |
| 1   | 🏴‍☠️🍖👒 | One Piece | One Piece\|Naruto\|… | https://upload.wikimedia.org/…/one-piece.png |
| 2   | 🍥🍜🦊  | Naruto    | Naruto\|Bleach\|…    | https://upload.wikimedia.org/…/naruto.png    |

> ⏱️ **Цаг хүрэхгүй бол** зөвхөн **3–5 асуултад** зураг нэм. Бусдыг **хоосон** үлдээ — тоглоом зүгээр л алгасна.

### 4️⃣ JSON-д ямар харагдах вэ?

```json
{
  "id": 1,
  "emojis": "🏴‍☠️🍖👒",
  "answer": "One Piece",
  "options": ["One Piece", "Naruto", "Bleach", "Dragon Ball"],
  "image": "https://upload.wikimedia.org/…/one-piece.png"
}
```

> 💡 `image` бол зүгээр л **нэг текст талбар** — object-д шинэ шошго нэмсэн, өөр юу ч биш. 🎴

### 5️⃣ Тоглоомд харуулах

Зургийг **ХЭСЭГ 3**-ын промптод хамт хэлнэ (тэнд бэлэн байгаа). Хэрэв дараа нь нэмэх бол:

```text
Асуултын "image" талбарт зургийн хаяг байвал зөв хариулсны дараа тэр
зургийг харуул. Талбар хоосон эсвэл зураг ачаалагдахгүй бол зүгээр л
алгасаад зөвхөн emoji харуул — хоосон, эвдэрсэн зургийн хүрээ бүү үлдээ.
```

---

> ## 🛡️ Кредит ба аюулгүй байдал
>
> - Зураг бол **бусад хүний бүтээл** — тоглоомынхоо доод талд _"Зургийн эх сурвалж: Wikipedia"_ гэж бич.
> - Зөвхөн **насанд тохирсон, эелдэг** зураг. 
> - **Хүний хувийн зураг** (найз, ангийнхан, багш) хэрэглэж болохгүй — тоглоом ил байршина.

<details>
<summary>🆘 <b>Зураг гарахгүй бол?</b></summary>

| Шалтгаан                             | Шийдэл                                                              |
| ------------------------------------ | ------------------------------------------------------------------- |
| Сайт гадны хуудсанд зургаа блоклосон | **Wikipedia**-аас өөр зураг ав (хамгийн түгээмэл шалтгаан)           |
| URL нь вэб хуудас, зураг биш         | Дахин **"Copy image address"** хий — "Copy image" биш                |
| `http://` -ээр эхэлсэн               | `https://` -тэй зураг ол (сайт чинь https тул http зураг блоклогдоно) |
| Зураг устсан / хаяг өөрчлөгдсөн      | Шинэ зураг ол                                                       |

Мөн AI-д хэлж болно:

```text
Зарим асуултын зураг ачаалагдахгүй байна. Зураг ачаалагдахгүй бол
автоматаар нуугдаж, зөвхөн emoji харуулдаг болгоод засаач.
```

</details>

<details>
<summary>🔄 <b>Дасгал 2.5 — Хүснэгтээ JSON болго</b> · ⏱️ ~3 мин · 🔑 гол мөч</summary>

1. Sheets-ийн **бүх хүснэгтээ** (баганы нэртэй хамт) сонгож **copy**.
2. **[CSVJSON](https://csvjson.com/csv2json)** нээ → зүүн талд **paste** → **Convert** дар.
3. Баруун талд **JSON array** гарч ирнэ. 🤯

> ### 🔑 Ажигла!
>
> Хүснэгтийн **1 мөр → 1 `{ }`** · бүх хүснэгт → **1 `[ ]`**
>
> Яг ХЭСЭГ 1-д үзсэн зүйл. Одоо өөрийн датагаараа харлаа.

4. Гарсан JSON-оо **copy** хийгээд **[JSONLint](https://jsonlint.com)** руу буулгаад **Validate** → 🟢 **Valid JSON** байх ёстой.

5. ✅ **Valid болсон JSON-оо хадгал** — Discord-д өөртөө хувийн мессежээр тавь эсвэл шинэ файлд хий. **ХЭСЭГ 3-д хэрэгтэй!**

<details>
<summary>🆘 <b>Emoji хачин тэмдэгт болвол?</b></summary>

Sheets-ээс CSV файл **татахгүй** — шууд **copy-paste** хий. Болохгүй бол JSON-оо AI-д өгөөд _"emoji-нүүд гажсан байна, зөв болгооч"_ гэж хэл.

</details>

<details>
<summary>🆘 <b>Зургийн хаяг тасарсан бол?</b></summary>

Урт URL хүснэгтэд буухдаа тасарч мэднэ. JSON дотор `"image"` бүр `https://`-ээр эхэлж, дундаа зай (space) байхгүй эсэхийг шалга.

</details>

<details>
<summary>✍️ <b>Дасгал 2.6 — <code>answers</code> array нэмэх (нэмэлт)</b> · ⏱️ ~3 мин</summary>

Тоглогч `one piece` эсвэл `ван пийс` гэж **бичвэл** яах вэ? → **`answers` array** нэмнэ.

```json
{
  "id": 1,
  "emojis": "🏴‍☠️🍖👒",
  "answer": "One Piece",
  "answers": ["one piece", "onepiece", "ван пийс"],
  "options": ["One Piece", "Naruto", "Bleach", "Dragon Ball"]
}
```

Sheets-д **`answers`** гэсэн багана нэмээд `|`-ээр салгаж бич, дараа дахин Convert хий.

> 💡 Энд `answers` нь дахиад л **array `[ ]`** — олон зөв хувилбарын жагсаалт. Гурав дахь удаа харж байна! 😏

</details>
