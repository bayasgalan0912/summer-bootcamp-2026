# 🕹️ ХЭСЭГ 4 — Шинэ горим + шинэ дата · ⏱️ ~18 мин

> 🎯 **Зорилго:** Өөрийн дуртай сэдвээр **2 дахь горим** нэмэх — түүний датагаа өөрөө бэлдэх.

> 🔑 **Гол ойлголт:** Шинэ горим гаргахад **кодоо дахин бичдэггүй**. Зөвхөн **шинэ дата** нэмнэ. Тиймээс JSON ур чадвар чинь одоо жинхэнээсээ хэрэг болно. 💪

<summary>📦 <b>Дасгал 4.2 — Шинэ горимын датагаа бэлд</b> · ⏱️ ~12 мин</summary>

> ХЭСЭГ 2-той **яг адилхан** алхам. Одоо чи үүнийг **өөрөө**, заавар бага уншиж хийнэ. 😎

1. **Шинэ Sheets хуудас** (эсвэл шинэ tab) → **5 багана**: `id`, `emojis`, `answer`, `options`, `image`
2. **8–10 асуулт** бич. Санаа дуусвал AI-аас гуй:

```text
[СЭДЭВ]-ийн emoji таавар 10 асуулт бэлдээч. Хүснэгт хэлбэрээр,
багана нь: id, emojis, answer, options. options-ийг | тэмдгээр
салгасан 4 сонголт. Зөвхөн алдартай, хүн бүр мэддэг зүйл.
```

3. Асуулт бүрийг **өөрөө уншиж шалга** (AI эндүүрдэг!)
4. 🖼️ **`image` багана бөглө** — ХЭСЭГ 2.4-тэй яг адил (`Copy image address` → шинэ tab-д шалга)
5. **[CSVJSON](https://csvjson.com/csv2json)** → Convert
6. **[JSONLint](https://jsonlint.com)** → 🟢 **Valid JSON**
7. ✅ **Хадгал** — ХЭСЭГ 5-д хэрэгтэй

| ⚽ Хөлбөмбөг      | Тоглогчийн нэр (ж: `Lionel Messi`)           |

<details>
<summary>🪆 <b>Дасгал 4.3 — 2 горимын дата хэрхэн зэрэгцэх вэ?</b> · ⏱️ ~5 мин · 🔑 шинэ ойлголт</summary>

Одоо `data.json` дотор **2 өөр жагсаалт** байх ёстой. Яаж? → **Object дотор array-ууд.**

```json
{
  "anime": [
    { "id": 1, "emojis": "🏴‍☠️🍖👒", "answer": "One Piece" },
    { "id": 2, "emojis": "🍥🍜🦊", "answer": "Naruto" }
  ],
  "football": [
    { "id": 1, "emojis": "🇦🇷🐐🏆", "answer": "Messi" },
    { "id": 2, "emojis": "🇵🇹🐐👑", "answer": "Ronaldo" }
  ]
}
```

> ### 🪆 Ажигла — 3 үе давхарласан:
>
> `{ }` object → дотор нь **горим бүрийн нэр** (`"anime"`, `"football"`)
> тэр бүрийн утга нь `[ ]` **array**
> тэр array дотор нь дахиад `{ }` **object**-ууд
>
> Яг JSON Boss Battle **Үе 3, 4** шүү дээ! 😏

**✍️ 1 минутын дасгал:** Дээрх хэлбэрийг [JSONLint](https://jsonlint.com) дээр өөрийн 2 горимын нэрээр бичээд 🟢 Valid гарга. (Асуулт бүрийг биш — тус бүр 1 асуулт хүрэлцэнэ.)

<details>
<summary>❓ Яагаад array дотор array биш вэ?</summary>

```text
[ [ ...anime... ], [ ...football... ] ]
```

Ингэж ч болно — гэхдээ дараа нь "0 дугаартай нь аниме" гэж **санаж** байх хэрэгтэй болно. `"anime"` гэсэн **шошготой** байвал уншихад тодорхой. Тиймээс object илүү дээр.

</details>
