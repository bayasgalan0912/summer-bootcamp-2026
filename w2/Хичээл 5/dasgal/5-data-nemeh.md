# 🔗 ХЭСЭГ 5 — Шинэ датагаа тоглоомд нэмэх · ⏱️ ~10 мин

> 🎯 **Зорилго:** ХЭСЭГ 4-т бэлдсэн датагаа тоглоомд нэмж, **горим сонгох цэс** гаргах.

---

<details open>
<summary>🚀 <b>Дасгал 5.1 — Датагаа нэмэх промпт</b> · ⏱️ ~5 мин</summary>

AI Studio-д төслөө нээгээд доорх промптыг **бөглөж** буулга:

```text
Тоглоомдоо "[СЭДЭВ] таавар" гэсэн 2 дахь горим нэмээч.

ДАТА:
- data.json-ыг ингэж цэгцэлье: гадна талд object, дотор нь горим
  бүрийн нэрээр array. Одоогийн аниме асуултуудыг "anime" гэсэн
  array дотор оруул, доорх шинэ асуултуудыг "[СЭДЭВ]" гэсэн array
  дотор нэм.
- options талбарын "|"-ээр салгасан текстийг 4 элементтэй array болго.

ЦЭС:
- Тоглоом эхлэхэд "Ямар горимоор тоглох вэ?" гэж асууж, 2 горимын
  товч гарга. Сонгосон горимын асуултууд л гарна.
- Тоглоом дуусахад горим сонгох цэс руу буцах товч байг.

ДҮРЭМ:
- Хугацаа, амь, оноо хоёр горимд адилхан ажиллана.
- "image" талбар шинэ горимд ч аниме горимтой адилхан ажиллана: зөв
  хариулсны дараа зураг гарна, зураггүй эсвэл ачаалагдахгүй бол алгасна.

Шинэ асуултуудын JSON:

[ЭНД ХЭСЭГ 4-Т БЭЛДСЭН JSON-ОО БУУЛГА]
```

> 🛡️ **Сана:** Нэг зүйл нэм → тогло → ажиллавал дараагийнх. Одоо горим нэмж байгаа — өнгө, дуу, animation-ыг ХЭСЭГ 6-д нэмнэ.

</details>

<summary>✅ <b>Дасгал 5.2 — Шалгах (checkpoint)</b> · ⏱️ ~3 мин</summary>

- [ ] Тоглоом эхлэхэд **2 горимын товч** гарна
- [ ] 🍥 Аниме горим сонгоход **аниме асуулт** л гарна
- [ ] Шинэ горим сонгоход **шинэ асуулт** л гарна
- [ ] Хоёр горимд оноо, амь, хугацаа **адилхан** ажиллана
- [ ] 🖼️ Хоёр горимд зураг **адилхан** гарна
- [ ] Тоглоом дуусахад **цэс руу буцаж** чадна

<details>
<summary>🆘 <b>Асуултууд хольж гарвал?</b></summary>

```text
Горим сонгоход хоёр горимын асуулт хольж гарч байна. Сонгосон
горимын array-аас л асуулт авдаг болгоод засаач.
```

</details>

<details>
<summary>🆘 <b>Аниме горим эвдэрсэн бол?</b></summary>

data.json-ы бүтэц шинэчлэгдэхэд эвдэрсэн байх. Агуулгыг [JSONLint](https://jsonlint.com) руу буулгаад Validate дар. Бүтэц ийм байх ёстой:

```json
{
  "anime": [{ "id": 1, "answer": "One Piece" }],
  "football": [{ "id": 1, "answer": "Messi" }]
}
```

</details>

<details>
<summary>🎉 <b>Дасгал 5.3 — Хамтдаа ойлгоцгооё</b> · ⏱️ ~2 мин · 🧠 өнөөдрийн гол сургамж</summary>

Одоо чиний тоглоом **2 горимтой**. Гэхдээ нэг зүйлийг ажигла:

> ## 🧠 КОД = тоглоомын **ДҮРЭМ**
>
> ## 📦 ДАТА = тоглоомын **АГУУЛГА**

- Хугацаа, амь, оноо, товч, дизайн — **бүгд ижил код**.
- Аниме vs хөлбөмбөг — **зөвхөн дата өөр**.
- Чи 2 дахь тоглоом бичээгүй. Зөвхөн **шинэ дата** нэмсэн.

> 💡 **Яг ийм учраас** том тоглоомууд шинэ level, шинэ дүр, шинэ map нэмэхдээ тоглоомоо дахин бичдэггүй. Roblox-ийн шинэ map, Minecraft-ийн шинэ mod — бүгд **дата**.
>
> 🚀 Чи одоо энэ дүрмийг мэдэж байна. Тоглоомдоо 3, 4, 5 дахь горим нэмэх нь зөвхөн **шинэ хүснэгт бөглөх** ажил.

</details>
