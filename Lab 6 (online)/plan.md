## 🎯 Яагаад чухал вэ? (rationale — сурагчдад бүү хэл)

- **Token/limit ойлголт** = сурагчид limit-д хүрээд "AI ажиллахаа боллоо" гэж сандрахгүй, өөрсдийгөө зөв удирдаж сурна. Энэ нь дараагийн бүх session-д хэмнэлттэй ажиллах суурь.
- **System prompt** = vibe coding-ийн гол ур чадвар. Idol Coach бол system prompt-ийг хөгжилтэй, сэтгэл хөдөлгөм аргаар заах "Тройн морь". Хүүхдүүд биширдэг хүнээ дуурайлгах гэж урам зоригтой суралцана.
- **"Чи AI юу?" тест** = prompt сул байвал AI дүрээсээ гардгийг өөрсдөө нээж, prompt-оо сайжруулж сурдаг (iterate).

### 🔧 AI Studio setup (хичээлийн өмнө шалга)

- **URL:** [aistudio.google.com](https://aistudio.google.com) → Google-аар нэвтрэх. (13-аас доош насанд хязгаартай тул сурагчид өөрийн/гэр бүлийн зөвшөөрөлтэй хаягтай эсэхийг шалга.)
- **Model:** Сурагчдад загвар сонгуулахгүй — **үндсэн (default) загвар** хангалттай. (Default нь Flash, үнэгүй квот өндөр; Pro руу бүү шилжүүл, limit-д хурдан хүрнэ.)
- **Бодит limit (нэг хаягт, үнэгүй):** RPM (~10/мин) + TPM + RPD хязгаартай. Загвар бүрт өөр — Flash ~500+/өдөр, Pro ердөө ~10–25/өдөр. RPD дуусвал Номхон далайн цагаар шөнө дунд сэргэнэ. Тоонууд байнга өөрчлөгддөг тул "хэмнэх" зарчмыг гол болго; сурагч голдуу RPM (хэт хурдан спам)-д тулна.
- **Орох зам:** Зүүн талын **EXPLORE → Playground** (эсвэл голын "Code and Chat" карт). UI шинэчлэгдсэн — хуучин "Chat" цэс байхгүй.
- **System instructions:** Playground дотор чат талбарын дээд хэсэгт. Сурагчдад **screen share-ээр урьдчилан** хаана байгааг үзүүл.
- **Save:** Дунд-дунд хадгалуулах — браузер хаагдвал ажил алдагдахгүй.

> ⚠️ Хичээлийн өмнө өөрийн хаягаар нэг бүрэн coach үүсгэж туршаад үз — UI өөрчлөгдсөн эсэхийг шалгана.

**Context-ийг тайлбарлахдаа (live demo):**

**Idol Coach-ийн өмнө:**
> "Одоо чи AI-д шинэ зан чанар өгнө. Энэ бол vibe coding — чи код бичихгүйгээр AI-н зан байдлыг үгээр л өөрчилнө."

- **Бага нас (mid-school):** Idol-оор алдартай, мэддэг хүн сонгуул (anime, спортын од). System prompt template-ийг хамт нэг мөр нэг мөрөөр бөглөх.
- **Ахлах нас / Stretch:** ХЯЗГААР хэсгийг нарийсгах; 2 idol хийгээд хариултын ялгааг шинжлэх; "First principles" гэх мэт idol-ийн сэтгэлгээний хэв маягийг prompt-д тусгах.

## ⚠️ Нийтлэг алдаа (instructor watch-outs)

- **"Би AI" гэж хариулах:** Хамгийн түгээмэл. → ХЯЗГААР хэсэгт "Хэзээ ч би AI гэж бүү хэл" мөрийг нэмүүлэх.
- **Хэт ерөнхий system prompt:** "Чи Elon" гэж л бичээд орхих. → Зан чанар, ярих хэв маягийг тодорхой бичүүлэх.
- **Limit-д хүрэх:** Олон удаа турших үед зарим сурагч limit-д хүрч магадгүй. → Хэсэг 2-ийн хэмнэх дүрмийг сануулах; Gemini 2.5 Flash дээр байгаа эсэхийг шалгах; шаардвал түр завсарлага.
- **Буруу idol сонголт:** Маргаантай эсвэл насанд тохироогүй хүн. → Эерэг, аюулгүй idol сонгуулах.
- **🛡 Аюулгүй байдлын дүрэм устгах:** Сурагч "илүү жинхэнэ" болгох гэж АЮУЛГҮЙ БАЙДЛЫН ДҮРЭМ хэсгийг авч хаяж магадгүй. → Энэ хэсэг **заавал үлдэх** ёстойг тодорхой хэл; шалгах тестийн асуулт 5-аар бүгдээр нь шалгуул.
- **Coach-д хүнд асуудал ярих:** Хүүхэд жинхэнэ эрүүл мэнд/сэтгэл санааны асуудлаа AI-д ярьж магадгүй. → "AI бол найз биш, мэргэжилтэн биш. Хүнд асуудлаа итгэдэг том хүнтэйгээ ярь" гэдгийг анги дунд тод хэл.

## 🔒 Privacy / эцэг эхэд

- Сурагчид хувийн мэдээллээ (нэр, сургууль, хаяг) coach-тойгоо бүү хуваалцаарай гэж сануулах.
- Idol Coach бол хөгжилтэй дасгал — эрүүл мэнд, аюултай асуудлаар жинхэнэ зөвлөгөө биш гэдгийг тодорхой хэл. AI төгс биш.
- Эцэг эхэд: "Хүүхэд тань биширдэг хүнээ дуурайсан AI зөвлөгч бүтээж, prompt бичих ур чадвар эзэмшсэн."

### 🏠 Гэрийн даалгаврын тэмдэглэл (homework.md)

- 3 хэсэгтэй: (1) Idol Coach төгөлдөржүүлэх, (2) **Me-AI** (өөрийн portfolio туслах) бүтээх, (3) хоёуланг нь **portfolio веб рүү цэс болгон** нэмэх.
- **Сайтад шууд суулгана (B арга):** Хичээл 2-ын deploy хийсэн сайтад "My Idol" цэс + баруун доод popup туслах нэмнэ. Чат нь **Gemini API key**-ээр ажиллана; key нь ил сайтад орох тул **зөвхөн billing-гүй үнэгүй key** ашиглуул (алдагдвал квот л эрсдэнэ, мөнгө биш). Key = нууц үг гэдгийг сануул, алдагдвал Delete → шинэ key.
- **"Get code" хэрэггүй:** system prompt бол зүгээр текст — Playground-ийн System instructions-ээ copy хийгээд build prompt-д буулгахад л Build кодод `systemInstruction` болгон бичнэ.
- **Me-AI privacy:** зөвхөн нууц БИШ мэдээлэл + portfolio сайтын тухай. System prompt-ийн 🛡 PRIVACY хэсэг заавал үлдэх ёстой — "Чиний гэрийн хаяг хаана вэ?" гэж асуугаад татгалзаж байгааг шалгуул.

## ✅ Session-ийн амжилтын шалгуур

Сурагч бүр session төгсөхөд:
1. Token / context / limit-ийн ялгааг энгийнээр тайлбарлаж чадна.
2. Бүрэн system prompt-той (зан чанар + хэв маяг + үүрэг + **аюулгүй байдлын дүрэм** + хязгаар) Idol Coach-той.
3. "Чи AI юу?" тестийг давсан coach-той.
4. 🛡 Аюулгүй байдлын тест (асуулт 5)-ыг давсан — хүнд асуудлыг том хүн рүү чиглүүлдэг coach-той.
5. Баасангийн Idol-Coach Showdown-д бэлэн.
