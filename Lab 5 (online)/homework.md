---

## 🎯 Зорилго

Өөрийн **Me-AI** туслахыг бүтээ, portfolio сайтдаа **popup чат** болгон нэм. Шинэ апп хийхгүй — байгаа сайтаа л өргөтгөнө. 🚀

> **Me-AI гэж юу вэ?** Чиний portfolio сайтын найрсаг туслах — чиний зан чанар, үзэл бодлоор ярьж, зочдод сайтыг чинь тайлбарлана. Idol биш, **чи өөрөө**. Зөвхөн **нууц БИШ** мэдээллээр ярина.

---

## 1️⃣ Өөрийн Me-AI бүтээ

> 💡 **Эхлээд өөрийгөө "тодорхойл".** Чиний байнга хэрэглэдэг LLM (ChatGPT, Gemini, Claude…)-д ингэж асуу — доорх template-ээ хурдан бөглөх материал гарч ирнэ:
>
> _"Намайг portfolio сайтын AI туслах болгож тодорхойлоход тусал. Доорх асуултаар надаас ярилцлага авч (нэг нэгээр нь), хариултаас минь зан чанар, ярих хэв маяг, сонирхол, зорилгыг минь товч жагсаа: [сонирхол? зорилго? найзууд намайг яаж дүрсэлдэг вэ? яаж ярьдаг вэ?]. Зөвхөн нийтэд ил, нууц БИШ зүйл асуу."_

AI Studio → **Playground** (шинэ чат) → **System instructions**-д бич:

```
Чи бол [Нэр]-ийн AI хувилбар — түүний portfolio сайтын найрсаг туслах.
Чи [Нэр] шиг бодож, ярьдаг.

ХЭН БЭ (зөвхөн нийтэд ил, нууц БИШ мэдээлэл):
- Нэр: [...]
- Сонирхол / хобби: [...]
- Зорилго / мөрөөдөл: [...]

ЗАН ЧАНАР / ЯРИХ ХЭВ МАЯГ:
- [өөрийнхөө 2-3 зан чанар; яаж ярьдаг — найрсаг, хошин…]

ҮҮРЭГ:
- Зочдод миний portfolio сайтыг тайлбарла, төслийн талаар найрсаг хариул.

🛡 PRIVACY (заавал, бүү устга):
- Хувийн нууц мэдээлэл (гэрийн хаяг, утас, сургуулийн нэр, нууц үг)
  ХЭЗЭЭ Ч бүү хэл. Асуувал эелдгээр татгалз.
- Эрүүл мэнд, хүнд асуудлаар жинхэнэ зөвлөгөө бүү өг —
  "итгэдэг том хүнтэйгээ ярь" гэж зөвлө.
```

**Турш:** "Чи юу сонирхдог вэ?" → ил мэдээллээ хэлэх ёстой · 🛡 "Чиний гэрийн хаяг хаана вэ?" → **татгалзах** ёстой!

✅ **Checkpoint:** Me-AI сайтаа тайлбарлаж, нууц мэдээллээс татгалзаж байна.

---

## 2️⃣ Сайтдаа popup болгон нэм

Хичээл 2-ын deploy хийсэн сайтад баруун доод буланд **Messenger-style icon** нэм — дарвал **popup чат** нээгдэж, зочид Me-AI-аас асууна.

**🔑 API key:** AI Studio → **Get API key** → **Create API key**. (Billing **бүү ас** — зөвхөн үнэгүй эрх. Key = нууц үг.)

Portfolio-гоо AI Studio-д аваад ингэж бич:

```
Сайтын баруун доод буланд Messenger-style icon нэм. Дарвал popup
чат нээгдэж, AI Gemini API-аар хариулна. AI дараах зааврын дагуу хариулна:

[Me-AI-ийн System instructions текстээ энд буулга]

Gemini API key-ийн талбар үлдээ — би өөрийн key-ээ тавина.
Загвар нь сайтын одоогийн өнгө, фонттой таарна.
```

Кодод өөрийн **API key**-ээ тавиад (`apiKey = "..."`) сайтаа дахин deploy хий.

> 🛡 Key чинь ил сайтад орох тул **зөвхөн үнэгүй, billing-гүй key** ашигла. Алдагдвал **Delete** хийгээд шинийг үүсгэ.

✅ **Checkpoint:** Popup туслах сайтад ажиллаж байна.
